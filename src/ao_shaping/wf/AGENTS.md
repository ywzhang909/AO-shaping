# wf/ - Wavefront Control

Wavefront sensing and control algorithms.

## FILES

| File | Purpose |
|------|---------|
| `rl_wfs.py` | Reconstructor-less WFS |
| `lr_wfs.py` | Linear reconstructor WFS |
| `DM_wfs.py` | DM-based WFS |

## CONVENTIONS

- NumPy arrays with explicit `dtype`
- Phase units: radians
- Coordinate system: pixel-centered
