# wfless/ - Wavefrontless Methods

Wavefrontless AO control using deep learning.

## FILES

| File | Purpose |
|------|---------|
| `lr.py` | Learning-based approach |
| `gready_cam.py` | Gerchberg-Saxton algorithm |
| `adc_dm_adam.py` | ADC DM with Adam optimizer |
| `phase retrieve.py` | Phase retrieval |

## CONVENTIONS

- PyTorch for neural networks
- NumPy for array operations
- Explicit dtype for arrays
