# 1300 陶瓷单元查看器 UI (ceramic_viewer.py) — 用户手册

## 1. 概述

`ceramic_viewer.py` 是 1300 陶瓷单元查看工具的 Streamlit 前端页面。支持 36×36 网格浏览陶瓷单元（IP、序号、引脚位置）与自动图片展示。

启动方式：

```bash
streamlit run src/ao_shaping/gui/r50/ceramic_viewer.py
```

完整技术细节见 [`ceramic_viewer_srs.md`](./ceramic_viewer_srs.md)。

---

## 2. 快速上手

### 2.1 网格浏览

1. 页面加载后自动显示 36×36 陶瓷单元网格。
2. 每个单元显示 IP、序号、引脚位置信息。
3. 选择不同的颜色方案（无 / 按 IP 组 / 按所属组 / 按序号 / 按引脚编号）查看单元分布。

### 2.2 图片展示

1. 选择 IP 与序号。
2. 系统自动根据 IP 组 + 序号推导图片路径。
3. 对应单元图片自动展示。

---

## 3. 配置常数

| 常数 | 值 | 说明 |
|------|-----|------|
| 网格大小 | 36×36 | 陶瓷单元网格维度 |
| IP 范围 | 101 ~ 126 | 单元 IP 地址范围 |
| 序号范围 | 0 ~ 49 | 单元序号范围 |
| 引脚最大值 | 316 | 单元引脚最大编号 |
| 默认 IP | 101 | 默认选中的 IP |
| 默认序号 | 0 | 默认选中的序号 |

---

## 4. 颜色方案

| 方案 | 说明 |
|------|------|
| 无 | 不着色，所有单元同色 |
| 按 IP 组 | 按 IP 地址所属组着色 |
| 按所属组 | 按逻辑所属组着色 |
| 按序号 | 按序号数值着色 |
| 按引脚编号 | 按引脚编号着色 |

---

## 5. 关键设计规则

| 规则 | 说明 |
|------|------|
| 只读浏览 | UI 仅读取 CSV 与图片文件，不修改单元数据 |
| 路径自动推导 | 根据 IP 组 + 序号自动推导图片路径 |
| 文件缺失容错 | 图片/CSV 文件缺失时显示友好提示，不导致页面崩溃 |
