# AO Shaping 可视化控制系统

这是一个基于PyQt6的可视化应用程序，用于控制和监控AO Shaping自适应光学整形系统。

## 功能特性

- 变形镜单元可视化控制
- 多种优化算法支持：
  - 波前优化 (wf)
  - 轴向光束优化 (pib)
  - 组合优化 (combine)
  - 贝叶斯优化 (bayes-opt)
  - 启发式搜索 (heuristic)
- 实时参数调整
- CCD相机参数设置
- 变形镜参数配置
- 实时可视化显示

## 安装依赖

```bash
pip install PyQt6 numpy matplotlib
```

## 运行应用程序

```bash
python -m src.ao_shaping.gui
```

或者直接运行主窗口文件：

```bash
python src/ao_shaping/gui/main.py
```

## 使用说明

### 主界面

应用程序主界面分为三个主要部分：

1. **左侧控制面板**：包含所有参数设置和控制按钮
2. **右侧变形镜面板**：显示64个变形镜单元的实时状态
3. **底部可视化面板**：显示各种图表和数据可视化

### 控制面板

控制面板采用选项卡设计，包含以下设置：

- **算法设置**：选择优化算法和相关参数
- **CCD设置**：配置相机参数
- **变形镜设置**：调整变形镜相关参数
- **优化器设置**：设置优化器参数
- **贝叶斯优化**：配置贝叶斯优化参数

### 变形镜面板

变形镜面板显示64个圆形按钮，每个按钮代表一个变形镜单元：

- **左键点击**：增加单元电压值
- **右键点击**：减少单元电压值
- **颜色编码**：
  - 绿色：电压值为0
  - 红色：正电压值
  - 蓝色：负电压值

### 可视化面板

可视化面板包含多个选项卡，显示不同类型的数据图表：

- **电压历史**：显示当前电压分布柱状图
- **电压分布**：显示电压分布热力图
- **RMS历史**：显示RMS值变化历史
- **PIB历史**：显示PIB值变化历史

## 开发说明

### 添加新算法

1. 在`control_panel.py`中添加算法选项
2. 在`simulation_manager.py`中实现算法模拟
3. 在`runner_manager.py`中集成真实运行器

### 自定义可视化

1. 在`visualization_panel.py`中添加新的图表类型
2. 在主窗口中连接相应的数据源

## 注意事项

1. 确保`data/layouts/XuWeiDM64_UnitsPos.txt`文件存在以正确显示变形镜布局
2. 应用程序支持模拟模式，可以在没有硬件设备的情况下进行测试
3. 所有参数设置都会实时影响模拟运行

## 故障排除

### 导入错误

如果遇到导入错误，请确保：
1. 已安装所有依赖包
2. Python路径正确设置
3. 项目结构完整

### 显示问题

如果变形镜面板显示异常：
1. 检查`XuWeiDM64_UnitsPos.txt`文件是否存在且格式正确
2. 确保窗口大小足够显示所有单元
