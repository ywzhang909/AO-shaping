# P1' 判别结论（已实测复核，20261019_161559）
支撑 = 1024 远场格上的 288 px = 7.91%。逐族（重建 vs 记录，重建对低带宽族吻合 ±0.04）：
- smooth  n=18  全域 0.788  支撑内 0.767  上限 1.000  支撑内能量 99.5%  通量/平场 0.87
- zernike n=2   全域 0.814  支撑内 0.798  上限 1.000  支撑内能量 96.9%  通量/平场 0.94-1.02
- freeform n=2  全域 0.113  支撑内 0.154  上限 0.477  支撑内能量 10.7%  通量/平场 0.072
结论（三条互相独立、都不依赖模型优劣）：
1. 自由相位族上限 0.449/0.504 < 0.5 -> 完美模型也过不了门槛。门槛按构造不可达。
2. 扣掉平场本底后自由相位支撑内相关性 -0.03 -> 相机窗内几乎没有模型能认出的信号；
   原来的 0.15 主要来自共有本底（两个自由相位帧互相相关 0.843）。
3. 自由相位只有平场通量的 7.2% -> 93% 光离开 0 级；两帧曝光都顶在会话上限 20 ms。
-> 不存在可由「迁移学习/振幅模型」修复的模型缺陷。相机能观测的两族已是 0.79-0.81、
   上限≈1.0。真正的阻塞是把一个不可观测的族放进验收门槛。
