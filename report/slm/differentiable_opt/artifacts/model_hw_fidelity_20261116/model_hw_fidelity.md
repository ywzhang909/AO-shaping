## 0. 范围与方法

* 数据来源: 已落盘的运行目录 (`model_farfield.npy` + `measured_model_grid.npy` + `run_config.json` + `history*.csv`), 全程离线, 未占用 SLM / CCD / 激光。
* 轴向口径 (转置 / 镜像) 不假设, 按 8 个候选择优, 并与 `run_config.json` 里记录的口径对账; 线性相关系数要与记录的 `comparison.best.intensity_correlation` 对到 1e-06 以内。
* 尺度扫描: 把实测绕**阵列中心 (光轴)** 用 `scipy.ndimage.zoom` (order=1) 重采样, s ∈ [0.40, 4.00], 步长 0.05; 不做任何平移对齐, 所以 s = 1 就是未缩放基线 (`corr(s=1)` 恒等于全网格相关系数)。不用强度质心做枢轴: 实测网格的弱背景会把质心拖偏几十个采样, 绕质心重采样会把中心光斑整体挪位。区间上限特意超过任务书的 2.50: 只有越过它, 才能把「s* 真落在 3 附近 (几何 K 标定)」与「s* 只是顶在端点上」分开; 报告同时给出限制在 2.50 以内的 s*。
* 判定口径 (与仓库一致): ≥0.8 高度一致 / 0.4–0.8 中度一致 / <0.4 不一致;「几乎一致」再要求 FWHM 比 ∈ [1/1.25, 1.25] 且**光斑峰值**偏移 ≤ 3.0 个远场采样。
* 归一化 RMS 误差 (NRMSE) 先把模型(归一化强度)与实测(counts)各自除以**全局峰值**, 再算 `‖test̂-参考̂‖₂/‖参考̂‖₂` —— 不这样做, 单位换算本身就会把误差顶到 1e5 量级。

参考实现: 已按路径 import ⇒ 相关系数引擎: reference_module。

## 7. 一致性变过吗 (跨日期)

变了。2026-10-23 的运行相关系数 [0.811, 0.814, 0.814, 0.719] (均值 0.790), 2026-11-16 的运行 [0.605, 0.663, 0.599, 0.599, 0.605, 0.663] (均值 0.623), 降幅约 0.167; 模型/实测 FWHM 比同时从 [1.569, 1.605, 1.599, 2.025] 变成 [3.216, 2.688, 3.229, 3.229, 3.216, 2.688] —— 模型远场几乎没变 (同一 GS 初值, 模型 FWHM 都是 ~31 个采样), 变的是实测在模型网格上的尺度 (实测 FWHM 从 ~19 掉到 ~10 个采样), 即几何尺度失配在 11-16 明显变大。记录在案的配置差异里, **焦距补偿**跟着一起变: 10-23 是有限焦距 (['1601', '1607', '1610', 'n/a']), 11-16 是 ['-4.33e+04', 'inf'] (inf / 极大焦距 ⇒ 补偿面板实质为零); 同时 iters [150]→[20, 120]、gs_iters [100]→[50]、k_mean [7520.690, 7523.440, 7522.675]→[7566.404, 7569.270, 7560.107, 7560.107, 7566.404, 7569.270]、优化后曝光 [7.403, 8.196]→[0.085, 0.095, 0.182] ms 也都变了。 这些候选**分不开**: 只有 5–7 个运行、且它们几乎同时变了 (焦距补偿、iters、gs_iters、k_mean、曝光), 没有哪个运行单独只改了其中一项, 所以现有数据只能指出「焦距补偿从有限变成实质为零」是与这次变化最同向的记录差异, 不能证明它是原因; 6 个样本的相关系数比较本身也是弱证据。
