- **模型-硬件差距系统性且跨起步方式一致**：随机起步下模型 CV 降至 0.66（模型认为接近收敛），实测 CV 仍 5.0，差距 7.5×；零相位下模型 3.89 vs 实测 6.05，差距同样存在。这不是起步盆地问题，也不是单次种子噪声。

## 4. 模型-硬件差距归因

### 4.1 排除掩膜坐标错配

`model_cv`（`model_cv()`，line 547）与 `measured_cv_window`（`sample_ccd_to_window` + `monitor_cv`，line 545-546）共用同一 `objective.core` 布尔掩膜、同一相机窗网格。两者分叉 ~7.5×，排除了掩膜坐标空间错配（若坐标错配，两者应同时偏高或同时偏低，不会一个 0.66 一个 5.0）。

### 4.2 排除起步盆地

零相位困焦斑盆地是已记录的起步问题（见 `shape_transition_timing_20261107.md`）。随机起步 RMS1.5 已规避此问题——模型 CV 从 3.89（零相位）降至 0.66（随机起步），证实起步已改善。但实测 CV 从 6.08（零相位）仅降至 5.01（随机起步），改善幅度远小于模型侧。**起步不是当前阻塞因素。**

### 4.3 指向 FrozenDefocusForward 绝对强度表征误差

> **归因修正（2026-11-16，12-bit 重采后，见 `model_optim_efficiency_20261116` §5.1）**：
> 本节及其标题的"表征误差"归因**已作废**。7.5× 分叉的直接来源是**采集环节伪影**——
> 两次锚定运行位深为 8-bit（0.5 ms），零级饱和、整形光被量化掩埋，实测 CV 地板恒在 ~5
> （6.077 / 5.006），而 `model_cv` 是模型自身尺度上的真值；5.006/0.664 ≈ 7.5× 是
> "实测地板 / 模型真值"，不是模型预测错。12-bit 满量程契约修复（`96e285ee`）后重采
> （`absolute_fidelity_12bit_fixed_20261116`）：`corr(model_cv_core, measured_cv_core_window)`
> 由 −0.51 转为 **+0.95**，模型核心 CV 恢复 0.40–4.17 物理区间。剩余差距的归因是
> checkpoint gain（`bias_counts=0`）的**量纲不可跨曝光迁移**（§5.3），
> 不是前向模型的表征缺陷。下文原文保留为当时分析记录。

方向 cosine 门禁（≥0.50）度量的是梯度方向对齐度，即"往哪个方向调相位能让 CV 下降"的方向是否正确。它不度量绝对强度预测精度，即"模型预测的强度分布与实测强度分布有多接近"。M3 方向 cosine 0.616/0.696/0.657 通过门禁，说明梯度方向大致正确；但模型 CV 0.66 与实测 CV 5.0 的 7.5× 差距说明绝对强度表征存在显著误差——模型认为已接近均匀（CV 0.66），实际光斑仍高度不均匀（CV 5.0）。

这与 2026-11-07 报告（`shape_transition_timing_20261107.md` §2）的发现同源：当时 model640 checkpoint 模型 CV 0.099 vs 实测 0.53，5× 残差归因于 FrozenDefocusForward 表征误差。本次 M3 checkpoint 的差距更大（7.5×），可能与 grid 128 / FFT 512 的较低分辨率、或 phase_sign −1.0 的极性处理有关，需进一步离线诊断。

### 4.4 背景/增益/非线性的角色（复用 2026-11-12 方向诊断结论）

- **背景误差不能单独解释**：方向诊断已证明背景/增益对方向度量精确不变（bg0/bg10 与基线逐位相同）。但方向度量不变 ≠ 绝对强度不变——背景误差仍可能通过绝对强度项影响 CV，只是不通过方向 cosine 体现。
- **幅值非线性无单调签名**：M3 median 0.616/0.696/0.657 在 0.02/0.05/0.10 rad 下无单调趋势，弱反对幅值非线性主导，非定论。
- **PSF/defocus/照明包络仍主导**：M3（离焦+照明包络）是唯一通过方向门禁的变体，说明 PSF/defocus/照明包络是方向可信度的主控因素。但方向可信 ≠ 绝对强度可信。

## 5. 对 issue 的影响

- **#233（幅值非线性）**：本次实测未显示幅值非线性主导的签名，方向诊断的弱反对结论在实测侧得到旁证。
- **#234（方向可信度）**：M3 通过方向门禁但实测 CV 未达 ≤0.10，证实方向 cosine ≥0.50 是必要条件非充分条件。后续需引入绝对强度保真度量（如模型 vs 实测强度直方图/相关系数）作为方向门禁的补充。
- **#236（掩膜 CV 实测）**：本次运行未使用掩膜（`--mask-core-half` 未传），不直接覆盖 #236。但 #236 的掩膜 CV 判据与本次全帧 CV 判据同源，若模型-硬件差距在掩膜判据下同样存在，则 #236 也会受阻于同一表征误差。

## 6. 后续建议

1. **离线绝对强度保真诊断**：对 M3 checkpoint 做模型 vs 实测强度直方图/相关系数诊断，量化绝对强度表征误差，区分"方向对但幅度错"与"方向+幅度都错"。
2. **分辨率/极性敏感性**：对比 M3（grid 128 / FFT 512 / phase_sign −1.0）与 model640（grid 640 / FFT 2048 / phase_sign null）的绝对强度保真度，定位差距放大的来源。
3. **补充绝对强度门禁**：在方向 cosine ≥0.50 之外，增加模型 vs 实测强度相关系数 ≥0.8 的绝对强度门禁，避免"方向对但幅度错"的假阳性。
