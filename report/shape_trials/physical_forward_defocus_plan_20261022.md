## 2. 要回答的问题和实验分支

首要问题：在不移动相机的条件下，少参数物理预测模型能否预测独立相位的 CCD 强度，
并使可微优化产生的相位在当前相机平面改善均匀度？

| 分支 | 显示在 SLM 上的固定基线 | 作用 |
| --- | --- | --- |
| U：未补偿 | 当前平相位/既定载波 | 主实验，模型吸收当前有效离焦，目标定义在当前 CCD 面 |
| C：补偿 | 本次探测得到的聚焦及必要去倾斜相位 | 配对对照，检验减去主离焦后模型预测和优化是否更容易 |

两分支使用同一设备、相机位置、相位族和探针种子，交替测量，分别保存实际总相位。
模型版本之间使用同一批原始帧离线比较；U/C 的相位不同，属于配对采集，不能称同帧对照。
若只有 C 成功，只能说明补偿路线有效，不能宣称 U 已适应当前离焦。

## 3. 物理参数化：只保留一个有效离焦自由度

先采用低参数模型：

\[
u_p=A_{\eta}(x,y)\exp\{i[\Phi_{SLM}(\phi_{cmd})+
\phi_{known}+a_d Z_4+\sum_{j\ne1,2,3,4}c_jZ_j]\},
\qquad I=|\mathcal P_G(u_p)|^2.
\]

也可改用焦面复场再传播至 CCD 的参数 `delta_z` 表达离焦。
在理想、标度一致的近轴傅里叶系统，两种表达有相应的等效关系；
现有 `ModelErrorTerms` 与数字孪生已有相关实现，但有限窗口、采样、精确角谱和光路非理想
可能使数值关系有偏差。先用相同几何和相位验证等效程度，不把代码注释当作实验真值。
同一轮拟合只选 `a_d` 或 `delta_z` 一个变量，避免与 Noll 4 重复解释。
活塞固定；倾斜与几何平移只选一个表示。已知补偿固定，残余离焦相对该基线定义。

相机侧为响应映射、曝光积分、像素积分/重采样、增益及加性背景（杂散光）项。
相机数字偏置与随曝光变化的光学背景分开；有零级重叠时检验相干项，
不能把所有残差无条件解释为非相干常数背景。训练阶段调整参数，验证阶段不逐帧移动或缩放预测。

## 4. 阶段一：当前会话健康度与离焦探测（先做，约 10–20 分钟）

1. 查询设备、波长/LUT、相机位深、增益及曝光范围，记录相机位置变更但不再次移动。
   不继承历史 `0.2/0.5 ms` 或 `20/50 ms` 为当前永久上限。
2. 固定相位拍多曝光重复帧；先确认存在空间结构和可靠信号，再拟合曝光响应。
   曝光变更后丢弃陈旧帧并验证稳定，记录设备回读及帧序号。无有效信号时停止，不能继续拟合。
3. 固定相位重复 10 组、每组 3 帧，建立 CV、能量、质心及宽度的噪声与漂移基线。
4. 全板粗定位后局部细化照明中心/覆盖范围；半径为零或边缘未测出时，标记不可辨识，
   不将默认半径标为实测。CCD 中心单独测量，不能等同面板中心。
5. 使用已有 `focus_probe` / `alignment_probe` 正负焦度粗扫 9–13 点，
   最优点在边界则扩展，再细扫；每点 3 帧、每 3 点插入参考。
   用峰值/曝光、环围宽度、FWHM 及饱和情况共同择优，环形光斑不只看 FWHM。
6. 焦度变化同时记录 x/y 质心；标定两个斜坡方向到 CCD 的映射，
   检查二次相位去倾斜。彗差只在聚焦后仍有稳定不对称时追加，不先扩大自由度。
7. 固定曝光按 U-C-C-U 顺序重放至少 3 组，得到当前补偿焦度、中心、宽度和重复性。

曝光响应初查建议选 5 档、每档 3 帧，档位按画面选取，覆盖实际训练工作区间。
局部响应相对线性偏差建议控制在 `5%` 内，否则先标定响应或缩小工作区间。
该数值是本方案拟定门槛，不是已有实验结论。无法遮光时明确缺少真实暗场证据。

## 5. 阶段二：几何测量与相位多样性数据（约 20–40 分钟）

先标定 x/y 斜坡，至少两个方向、三个频率、正负符号，检验平移线性与旋转/镜像。
固定照明、相机和采样定义，U/C 使用相同物理传播尺度；分别估计中心和有效离焦。
若必须用不同经验尺度才能解释两分支，回到传播/重采样模型排查，不能将失配隐藏于独立缩放。
建议几何重复测量尺度差小于 `5%`，相机网格中心残差小于 `1 px`；
尺度交叉核对仍相差数倍时停止进入目标优化。

冻结数据划分，初始设计每分支 64 个探针，每探针 3 帧：

| 用途 | 数量 | 内容 |
| --- | ---: | --- |
| 训练集 | 32 | 8 个离焦/像散/彗差组合、8 个多阶 Zernike、8 个平滑随机相位、8 个具有指定空间带宽的相位网格 |
| 验证集 | 16 | 每类 4 个不同种子/幅度，用于选择模型和超参数 |
| 锁定测试集 | 16 | 每类 4 个全新种子，模型确定后只做最终评估 |

以上为计划样本预算，可先完成每类少量探针排查明显失配；设备耗时取决于稳定等待，
不保证在估计时间内完成。像差参数统一使用 rad，Zernike 统一规范入口。
离焦探针围绕当前实测补偿量分布，并包含正负残差；随机相位带宽覆盖后续可微优化的范围。
不同集合相位不重合；重复帧不拆到不同集合。每 8 个探针插入一次参考，U/C 块顺序交替。
最终测试另含实际优化产生的新相位，以检测优化器是否利用了模型的误差。

记录总相位、指令到面板映射、曝光回读、原始帧、固定 ROI、载波/零级掩码、
UTC 微秒格式时间、单调时钟、相位下发与采集起止、设备/响应/几何/代码版本指纹。
时间戳精度与相机同步精度分别说明；若相机提供帧号/硬件时间戳则一并保存。

## 6. 阶段三：逐项增加参数的迁移学习（优先离线，同帧比较）

| 版本 | 可调整项 | 用途与停止规则 |
| --- | --- | --- |
| M0 | 已测几何和照明，理想相位响应 | 冻结基线，不用宽度拟合代替预测验证 |
| M1 | 单一有效离焦 + 训练集共享增益/背景 | 验证主要变化是否确由离焦解释；粗扫初值再局部拟合 |
| M2 | M1 + 少量残余像散/彗差等低阶项 | 只在验证集残差有稳定结构时增加，固定活塞/倾斜冗余 |
| M3 | M2 + 偏心椭圆高斯照明约 5 个形状参数 | 处理照明半径不可辨识与偏心；固定振幅归一化以免与增益简并 |
| M4 | M3 + 实测 SLM 相位响应 | 若复杂相位残差仍大，独立标定相位调制深度/非线性，再固定到模型 |

M1 优先，不直接训练高阶像差或 U-Net。初始低阶阶数可取 `n_max=4`，
是否扩展按验证集误差及参数稳定性决定；历史阶数扫描是“拟合整形相位”，
不等于当前“辨识传播像差”的最优阶数。
`A_eta` 联合训练及所有参数自动迁移尚需核对/补充接口，不能当作当前 CLI 已全部支持。
`ModelErrorTerms`、公共复场传播、优化器误差项及孪生存在未提交更新，
应先离线验证 Step A/Step B 使用同一传播链、单位和梯度，再接设备。

每个版本先用训练集拟合，只用验证集择优；锁定测试集禁止逐样本拟合增益、平移、
模糊或重新定位。额外给出的最佳配准相关性只能作为诊断，不能作为主验收指标。
先用当前几何构造孪生的正/负离焦、偏心和响应非线性案例，
确认参数符号、可辨识范围及可微梯度；孪生结论不能代替实验结果。

SLM 响应已有新工具 `ao_shaping.tools.slm.calibration.diffraction_efficiency`，
`measure` 要先有光路标定 `.npz`。先检查当前离焦下 ±1 级是否可分离、积分窗口是否覆盖能量，
必要时在 C 分支测器件响应再固定用于 U；否则离焦引起的能量截断会污染响应拟合。
复用离散器件模型，不能直接假设连续理想闪耀效率；相位响应反演有周期歧义时要独立验证。

### 拟定模型验收标准（实验前登记，可按重复测量噪声修订）

- 主指标在固定 CCD 网格计算：测试集相关性中位数至少 `0.85`，每类中位数至少 `0.80`，
  最差样本至少 `0.65`；中心误差不超过 `1 px`，环围宽度相对误差不超过 `10%`。
- 同时报告预测 CV/EE 与实测差值，建议绝对误差分别不超过 `0.05`；
  目标区域固定，能量分母覆盖同一视场，不能逐帧 peak 归一化后比较绝对能量。
- 最优参数跨独立重复块稳定；多曝光同一相位校正后预测一致。
  达不到上述门槛先解释失败相位族，不能仅放宽当前软件 `0.5` 门槛后宣布可用。
- 这些是拟定工程验收值，不是统计显著性结论；最终以锁定测试与真实优化候选共同验收。

## 7. 阶段四：可微优化与 CCD 配对验收（约 20–40 分钟）

模型通过后，先做单一方形目标，目标边长由当前焦斑宽度和可用视场决定，
建议先从聚焦 FWHM 的约 `3–5` 倍选取，并确保传感器上有足够像素。
不直接沿用旧 `10 px` 目标或把离焦环的 FWHM 当作聚焦分辨率。
矩形/三角形/星形放在方形路线通过后验证。

对每个分支从相同规则的初相位、相同种子出发，进行：

1. 冻结通过验收的模型，粗到细优化受带宽约束相位；初期只做 `100–200` 步短块，
   每块显示候选并测 CCD，信赖域内更新，失败则恢复此前已验证相位。
2. 同时比较“已有非均匀方斑相位保持不变”“直接可微匀化”“加平滑/梯度约束的可微匀化”。
   同一初相位才能用于检验相位梯度假设，不能用低阶拟合不同初相位替代。
3. 主目标优先最小化固定内部区域 CV，同时设置非退化 EE 下限与形状要求。
   平滑正则作用于复相位邻接差或未包裹指令的适当表示，避免把包裹切口当物理高频。
4. 每个候选检查完整区域 CV、去零级 CV、EE、IoU、边缘及原始信号。
   零级掩码检测规则和面积预先固定；主结果保留未剔除指标。
5. 用新候选相位做前向预测验证；若优化后才出现严重预测偏差，停止扩大相位自由度，
   将该类相位加入下一次训练并重新采集独立测试，不能在同一测试集上持续调参。

最终基线/候选按 A-B-B-A 固定曝光重放，每种方法至少 3 个独立优化种子。
拟定匀化验收：CV 相对初始方斑降低至少 `10%` 且超过配对测量噪声，
EE 不低于初始的 `95%`，IoU 下降不超过 `0.02`；如应用采用其他限制，先登记再实验。
报告全部种子及失败数，比较到达相同 CV/EE 条件的墙钟时间、CCD 次数与模型参数量。
样本少时给出全部配对值及不确定性，不以 3 个种子声称稳健显著性；
如做正式检验使用公共 `src/ml/zernike/eval_stats.py`，不复制统计实现。

## 9. 结果如何解释

- M1 同时改善 U/C 的独立预测且 U 整形通过：支持主要变化可由单一有效离焦适配。
- C 成功、U 失败：保留补偿方案，同时检查离焦传播采样和视场，不能只增加像差阶数。
- 两者都失败而几何重复性差：先修正尺度、中心和照明探测，暂不比较深度模型。
- M3 显著改善、M1 改善有限：离焦之外照明表达也重要，不能继续沿用纯离焦归因。
- 前向测试通过、优化候选失败：优先排查训练带宽覆盖、梯度与实际面板映射、零级及响应；
