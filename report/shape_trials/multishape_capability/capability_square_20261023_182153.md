## 摘要

当前配置下（正方形边长 84.85 px（面积未记录）、载波周期 32 px、轴 x、同帧定心、闭环不加倾斜）跑完 5 个闭环块，目标掩膜上**零级重叠处**的最佳实测 CV 为 **1.4628**（块 5）；末尾叠加倾斜后整形光斑实测移至**−y 方向 234.5 px（另一轴 +7.0 px）**，零点 20 px 内能量占比 0.0372 → 0.0020（约 19× 下降）；落点处目标掩膜 CV = 1.7562，但该帧 peak = 255.0（接近饱和）⇒ **不作为质量读数**。**模型方向尚未验证，本报告只陈述实测。**

![逐块曲线（±3σ 带）](figures/20261023_capability_square_20261023_182153_blocks.png)

## 1. 方法与边界

* **同帧定心**：先显示初值相位抓一帧，用**该帧**的 argmax 定位零级实测位置
  (1213, 956)（col, row），同时用它建模型掩膜与实测掩膜——不再按历史 spot
  定方向后再在设备侧重定中心。
* **闭环不加倾斜**：优化在零级位置上做正方形；倾斜（载波周期 32 px，
  轴 x）只在末尾展示时叠加，使整形光斑与零级分离（零级由未调制光直接透过，留在原位）。
* **判据**：本次等效面积掩膜的 3σ = 0.01084（run.json 的
  `three_sigma_resolution`，来自当次实测的噪声地板）；Δ÷3σ 只作噪声参考。
* **一次运行的局限**：单一会话、单一初值相位、单一 seed；冻结物理预测模型检查点
  `D:\Projects\TIFO\AO-shaping\data\debug\physical_forward_defocus\refit_after_focus_20261023_145446`；运行起始 2026-10-23T10:22:08.094040+00:00（UTC）。

## 4. 观察与限制

1. **目标掩膜口径**：测量框边长 79 px（旧版 run 未记录掩膜像元数）。零级掩膜（r = 20 px 圆盘，面积 ≈ 1257 px²）占目标掩膜面积 20.1% —— 目标掩膜 CV 是“正方形 + 零级”的复合指标，不是目标形状单独的均匀度。

2. **零级扣除的必要性**：本次零级能量占比 ≈ 0.0372（目标框内），零级峰正对框中心，不扣除零级时任何均匀度读数都被零级主导（本次逐块实测 CV ≈ 1.47 即源于此）；本运行只给出“带零级”与“载波分离后”两种读数，未做逐帧零级扣除，方斑单独的 CV 尚不能从本运行给出。

3. **单次运行不做显著性**：5 个块同一次会话、同一初值、同一 seed，“Δ÷3σ”只是相对本次掩膜噪声地板的参考刻度，不构成显著性检验；跨会话/跨光路比较需要独立的重复运行。

4. **闭环内未加倾斜 ⇒ 目标位置与零级重叠**：优化在零级位置上做目标形状，目标框中心即零级中心，闭环逐块的 CV 因此含零级贡献；倾斜只在末尾展示时叠加，分离后的读数（§3）才是“方斑离开零级”的状态。

5. **模型方向未验证**：模型 CV 逐块基本平走（2.170 → 2.052），与实测同量级但无方向性信息——本运行不能证明冻结物理预测模型的梯度方向正确，摘要的声明以本节为准。

6. **位移方向必须实测，不能由斜坡轴向推断**：本实验系统的 SLM **竖向安装**，面板 x 向斜坡在 CCD 上给出的是 **y 向**位移（本报告实测 +7.0, -234.5 px，|Δ| = 234.6 px，与 |K/周期| = 234.8 px 的标量一致）。⚠️ 2026-10-23 早前版本按 x 轴摆了 `at_plus`/`at_minus` 两个框，量到的是**背景不对称**，那两组数与由此得出的「＋x 侧」结论已作废；本版改为从两帧差分实测位移后再取读数。

7. **载波可能伤均匀度（提示，非结论）**：best@零点 CV = 1.4623，载波@实测落点 CV = 1.7562。两列口径不同（零点那列含零级峰，落点那列是纯图案 + 载波量化误差），**不能直接相减归因**。但周期 32 px 的斜坡在面板上约只有 32 个灰阶/2π，量化偏粗、易生谐波；若下一步要同时满足「与零级分离」和「形状均匀」，应先换更长周期（P = 64/96 ⇒ 位移约 117/78 px，仍在视场内）再比一次。
