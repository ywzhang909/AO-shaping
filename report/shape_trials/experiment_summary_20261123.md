## 1. 口径与分类规则

- **已验证有效**：预注册判据（或功能验收）通过，且越界门未触发；可给出稳定复现读数。
- **无效**：判据明确未过（双门 fail）或收益置信区间含 0（无收益），且有明确的失败机制或判定来源。
- **不可判定**：越界门（漂移 / 组内 sd / 曝光能量）优先于 matched/mismatched 结论；越界部分不解释、不外推、不改判据。
- **优化余量**只在「已验证有效」项下给出可执行方向；「无效 / 不可判定」项只写**重取数据的前置条件**，不暗示当前数据可优化到达标。

## 3. 逐项详情

### 3.1 效率匹配 ηs/ηd —— 不可判定

- **口径**：ηs = (S − S0) / F0、ηd = G1 / F0；判据 |mean d| ≤ 0.05 且 CI95(high) ≤ 0.08，组内 sd ≤ 0.03。
  曝光由 0.05 下调至 0.04 ms，暗帧复用相机暗帧库。
- **实测**：`analysis.json` 直接复核——mean d = **−0.6666953979091095**，
  CI95 = [−0.7067766114475275, −0.6388137953830176]，sd_eta_s = 0.05524298511883272，
  sd_eta_d = 0.010636135731252836，F0 = 649699.25 ± 0.0，S0 = 631990.0625 ± 0.0。
  16 帧、0 饱和。ηs 逐帧为负（−0.103…−0.183，即 S < S0），ηd ≈ 0.530–0.553。
- **越界门**：`energy_out_of_range` / `group_sd` / `drift_rounds` 三个门触发；
  `drift_rounds = 4 > 1`，质心位移最大 **3.123 px > 2 px**，F0 相对变化 **0.0450–0.0944 > 0.05**。
  时序：16 帧落在 05:07:42–05:09:01 UTC（约 79 s），帧间 min 0 / median 1.32 / max 22.12 s，两遍各 8 帧。
- **判定**：越界门优先级高于 matched/mismatched → **不可判定（`undeterminable`）**。
  修复仅限分析器路径解析与暗帧去重，未放宽任何阈值；43 用例通过、self-test 四场景 PASS、ruff clean。
- **优化余量**：**当前数据无优化空间**——漂移使 F0 基准在 79 s 内变化最高 9.44%，再好的估计量也无法补偿基准漂移。
  前置条件：重采需在 F0 相对变化 ≤ 0.05、质心位移 ≤ 2 px、drift_rounds ≤ 1 下完成。本轮不实验。

### 3.2 T4/T5 动态解耦采集 —— 有效（性能有上限）

- **实测**：30 条 transition 全 `ok`；实测 fps min **2.196** / 中位 **2.284** / max **2.542** / 均值 **2.319**，
  对比计划 10 fps；实下发 12–14 帧/条、耗时中位 5.611 s；曝光 0.08 ms、0 饱和。
- **瓶颈**：SLM 写入 + 换槽中位 0.312 s（max 0.562 s）主导，CCD 读出 0.075 s，像素翻转 7.8 ms。
- **记录瑕疵**：`panel` 记录不一致（`summary.json` 为 `[1200,1920]`，plan/run_plan 为 `[1920,1200]`，
  即(H,W)与(W,H)顺序差异）；无本项 verdict 字段，model 相位仅作诊断。
- **判定**：采集链功能**有效**（30/30、0 饱和、设备锁正常释放）；但帧率未达计划，不得宣称 10 fps。
- **优化余量**：唯一有效方向是缩短 SLM 写入/换槽（换槽与写入并行、减少 settle 等待）；
  理论上限 ≈ 1/0.312 s ≈ 3.2 fps，除非更换写入路径，算法侧优化不会改变该天花板。

### 3.3 #238 二值灰度 g₂π —— 有效（收益未证明，不可定标）

- **run1（周期 16 px）**：fold g₂π = **962.6658663463752**，CI95 = [959.1763484684697, 966.1040925689836]
  （报告口径 964 ± 13），漂移 −0.56%；理想 e-fit 898.03 因与设备回读及折叠结构矛盾，**降级为诊断**，不作结论。
- **run4（周期 32/48 px）**：period32 fold **952.6013935905339** CI [947.82, 956.16]；
  period48 fold **946.8858920659582** CI [945.39, 950.23]；回读 993；束功率漂移 +31.53% / −13.33%；
  `status=ok`、969 帧/段、0.08 ms。两周期点差 5.7 灰度。
- **局限**：run2 缺 936..1023，不可用于收紧；run3 抢锁失败、无数据。
- **判定**：fold 方法给出跨周期自洽的稳定读数 → **方法有效**；但 fold 值（946.9–962.7）与回读 993 存在系统差、
  且束功率漂移显著 → **收益未证明、仍不可定标、不改 LUT**，维持 OPEN。
- **优化余量**：不来自本批数据。需补采覆盖 936..1023 的完整序列并保持束功率稳定，才可能收紧；
  在任何标定决策前须另行授权窗口。

### 3.4 #235 零级定心四法 —— 有效（边界通过）

- **实测**：四法中心 (cy,cx) — argmax (1106,1229)、centroid (1106,1226)、box_centroid (1106,1226)、ellipse (1106,1227)；
  六对距离 3.0 / 3.0 / 2.0 / 0.0 / 1.0 / 1.0 px，`max_pairwise_distance_px = 3.0` = tol 3.0，
  `all_pairs_within_tolerance = true`，`verdict = ellipse_centre_usable`。
- **口径瑕疵（已登记、未改判）**：归档 `box_centroid` 用采集脚本内 0.15 阈值浮点 helper 得 (1106.23, 1225.99)，
  与 argmax 直接相减 Δx ≈ 3.008 微超 3 px；本对账统一按生产函数（半高连通域后取整）口径 → 3.0 通过。
  `summary_crosscheck` 如实记录该差异。
- **坐标系**：中心 (1106,1227) 与刀口 panel 中心分属 CCD 2592×1944 与 panel 1920×1200 两个坐标系，**不相减、不参与对账**。
- **判定**：四法一致性子项**有效（边界通过）**，默认椭圆中心可用；判据为既定口径，本次只执行、未新设或放宽阈值。
- **优化余量**：有限——仅 1 帧、无置信区间、无重复性统计；若要提高定心可信度需多帧重复采，但该子项已判可用，非必需。

### 3.5 P2a / P2b 方向门与强度门 —— 无效

- **P2a（14 帧，amp 0.03，曝光 0.1 ms，0 饱和）**：以实测峰为中心复核，逐对 Pearson 中位
  M0 0.00123、M1_defocus −0.00093、M3_illumination 0.02617，`count_ge_0_50 = 0`；
  锚点 gain 13.59、correlation −0.160、relative_l2 0.199；方形 bbox 内功率仅 19.9%，无方形结构。
  注册前提未核实（冻结 checkpoint `origin_xy` 与现场几何差约 (dy,dx) = (+163.7,−41.7) px），
  故本次方向失败**不能当模型的最终判决**。
- **P2b（amp03 / amp10，各 14 帧，0 饱和）**：方向门 N4/RX/RY 中位 amp03 = 0.027/−0.036/−0.003、
  amp10 = −0.048/−0.073/0.000，两档均 **0/3 ≥ 0.50**；Zernike 屏回放 fresh 0.491/0.538/0.445、
  旧 M3+11/18 残差 0.504/0.568/0.493，均未达 10/14；强度门混合参数 mean corr 0.665、
  CV_pred 2.206、CV_measured 3.832、CV abs 1.626、relL2 0.735（原 11/18 fit 0.844/3.291/3.832/0.842/0.529）。
- **机制归因**：21 变体消融无一超 5/7；噪声相关上限 0.914–0.981 ≫ 实测；补齐 14 对仍不过门
  → 失败是**模型类系统性方向错配**，非样本不足。双门严格互斥（无残差候选方向门升到 5/7，
  但强度门 relL2 0.355→0.582、corr 0.931→0.804）。
- **判定**：方向门与绝对强度双门均未过 → **不运行 `shape_transition_timing_20261106.py --execute`、
  不报告 core CV ≤ 0.10 验收、不放行硬件闭环**。强度指标是数据集窗口诊断，非目标形状 core CV。
- **优化余量**：**当前数据无优化空间**。下一步最小实验：在当前 epoch 同时采集 fresh 单模 Zernike 屏与绝对强度标定，
  先做六步光路预检；不得将 11/07 单模屏与 11/18 残差 fit 混作 epoch-matched 证明。

### 3.6 S7b 轴失配三变体回验 —— 无效（无收益）

- **采集**：grid=320、ramp_periods=[64,128]、count=24、frames=3、seed=20261118、曝光 effective 0.043 ms；
  light_check peak 149 counts、noise 3.4652、ok=true；曝光全 ok、峰 78–199 counts、0 饱和；
  held-out 12 帧未削减；参考漂移 0.11/0.20 px。fit iterations=200、early-stop 171、loss 0.191718。
- **前向 held-out（12 帧按帧配对）**：baseline corr 0.84352 / r² 0.67354 / relL2 0.52912；
  corrected 0.84115 / 0.66998 / 0.53247；axis 0.84115 / 0.67006 / 0.53244。
- **配对 bootstrap（20000，seed 20261118，直接复核 `paired_bootstrap_heldout.json`）**：
  `axis − baseline` corr −0.0023682596151844057 CI95 [−0.005199901631591713, +0.0005746443204138377]；
  r² −0.003481319854538506 CI95 [−0.008243937749345039, +0.0015981692009631504]；
  relL2 +0.0033175778166918226 CI95 [−0.0013381294139792376, +0.007855396209126737]；
  三项 `ci_excludes_zero = false`、`verdict = inconclusive`。逆向 60 步 CV baseline 0.83303 / corrected 0.82624 / axis 0.82605。
- **判定**：判据为「CI 不含 0 且逆向不恶化才判有收益」→ 三项 CI 全含 0 → **证据不足、无收益**；
  不得用训练集指标或单个 CV 值宣布胜出。
- **语义边界**：本次 baseline 用的是**本会话自身** ramp 标定矩阵，回答的是「要不要把该矩阵正交化并按 1.0859 改 y/x 尺度」，
  而**非**「物理上是否存在 xy 轴失配」。结论只否定「直接替换矩阵」，不否定物理失配假设。已判不需重跑。
- **优化余量**：本计划内无。若要检验物理 xy 轴失配，需另立计划做独立测量（旋转标定板或正交光栅双向扫描），
  不复用 `20261117_202916` 的 `capture/`（`exist_ok=False`）。

## 6. 结论与不可解释事项

1. 六项中 **3 项已验证有效**（各有明确边界：帧率上限 / 不可定标 / 边界通过），
   **2 项无效**（双门 fail、无收益），**1 项不可判定**（效率匹配漂移越界）。
