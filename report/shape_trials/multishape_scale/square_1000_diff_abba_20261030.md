## 2. 可微优化无效的原因

### 2.1 优化目标与形状形成不一致

10-29 的 `--objective cv` 走 `cv_only=True`：只优化 CV² 与相位平滑项，
能量、形状以及分区/外围/边界/净信号下限均未参与目标。历史归档显示，
600 px square 的 CV 从 1.121 降到 0.788，而填充率从 0.0155 降到 0.0019；
这证明“CV 降低”不能替代“目标形成”，详见后续质量方案 §1.2。

需要精确区分两个开关：**`formation=False` 本身并不意味着所有形状项为零**。
当 `cv_only=False, formation=False` 时，基础 `shape_loss` 和能量项仍有效；
恒为零的是 `l_partition / l_peripheral / l_floor / l_boundary`。
只有 CV-only 模式才连基础形状损失也不计入总目标。不能把所有失败都归为同一种配置。

新入口明确固定 `ShapeObjective(..., formation=True)`，冻结权重为：

| 项 | 权重 |
|---|---:|
| `cv2` | 0.05 |
| `energy` | 8.0 |
| `shape` | 1.0 |
| `smooth` | 0.001 |
| `partition / peripheral` | 0.5 / 0.5 |
| `floor / boundary` | 1.0 / 0.3 |

这只是纠正目标，不保证模型 Jacobian 正确，也不保证相位已形成目标。
分区项是能量均衡、边界项是边界强度离散程度，并非几何轮廓距离；
因此实际接受还必须检查 coverage、IoU 和能量，不能只看总 loss。

### 2.2 辐射率单位不一致

冻结模型与拟合使用原生 `counts/ms`，旧锚定路径却额外除以 `counts_scale`，
Mono12 下产生约 16 倍标度差，破坏测量锚定与模型增量的比例。
本轮复用已有 `radiometry.count_rate`，统一为扣背景后的原生计数除以曝光，
不再除 `counts_scale`。禁止跨位深、曝光、窗口或激光功率状态直接比较原始指标。

[单位离线复现](../blackbox_path/sim_units_20261029.md) 证明了标度缺陷，
但没有复现全部实验拒绝；因此单位修复是必要修正，**不是全部失败的充分解释**。

### 2.3 模型误差和测量漂移仍未解决

[2026-10-30 仿真可信度报告](../../simulation/sim_credibility/sim_credibility_20261030.md)
补充了两个独立事实：在 `differentiable_shaping` 的自有模型里，FFT 与 ASM 的自动微分
均通过有限差分检查；但 `Sim2fConfig.calibrated()` 数字孪生对实验差分方向的同批次余弦
中位仅 0.0288，符号一致率 0.5056。该方向失败**直接约束这个已标定数字孪生**，
不是 `FrozenDefocusForward` 当前检查点的同等定量验证，不能把 0.0288 移作后者指标。
它仍提高当前入口的风险等级：模型内部梯度正确不等于实验梯度方向正确。

该报告的 `sum1` 退化也属于 `differentiable_shaping` 的损失约定：归一化目标使
`target > 0.5` 得到空掩膜，并把能量项零点错位 256 倍。本轮使用另一条
`ShapeObjective` 路径，目标是 0/1 掩膜，复算 `l_partition=0.08196`、
`l_boundary=2.62838`，所以**不能用这条路径消除旧基准的缺陷，也不能把该缺陷
当作当前 formation 损失的证据**。修复了损失约定仍须处理模型与实验方向的一致性。

报告中同相位的 `fft→asm` EE 从 0.8465 降至 0.0147、参数偏差 ±2% 后 EE 降至
0.0128–0.0542，来自 0.1 m 传播、128² 网格的小模型，不是当前 2f 实验的定量外推。
它足以说明不能把后端替换或标称参数当作可靠优化；不支持直接选定 ASM，或断言当前
检查点的轴向误差就是某个数值。后续完整传播链必须在同一冻结相位与验证集上择优。

单帧强度相似不意味着相位到强度的局部导数正确。历史同相位重复有明显漂移，
旧数据不能可靠地给出“模型方向正确/错误”的结论。新入口从当前测量图像求目标导数，
经冻结模型 VJP 形成一个小增量，只允许实际 CCD 的重复比较决定是否采用。
它不在模型里长期优化后一次性加载，也不把展宽阶段收益计为可微优化收益。
**若正反向增量均通过形成判据，也只说明局部方向可用；仍须先通过 §10.7 的重复
符号探针门槛，再恢复小步长可微更新。未通过时继续校准物理预测模型，不转实测 SPGD，
也不靠切换后端继续盲试。**

## 4. FFT、ASM 与不在前焦面的 SLM

SLM 不在前焦面是已知实验状态，不能继续把“理想前后焦面”当作物理事实。
但把单次 FFT 换成一次自由空间 ASM 也不等价于包含透镜的实验系统。
显式模型应为：

```text
U_CCD = P(z2) { aperture * lens_phase * aberration * P(z1)[A * exp(i*phi_SLM)] }
I_CCD = pixel_integral(|U_CCD|^2) -> radiometry -> observation
```

`P` 可以用带限 ASM 或满足采样条件的 Fresnel/缩放传播实现。
必须保留透镜、孔径、两段距离、输入曲率、坐标标度和像元积分；
SLM 与 CCD 不同采样间距时不能直接共用未经检查的等间距 ASM 网格。
FFT 与 ASM 不是“可微/不可微”的区别，两者均可微。

在近轴、薄透镜和有效孔径假设下，ABCD 链可化为输入二次相位、缩放傅里叶变换和
输出二次相位。对单平面强度，输出二次相位不可见，所以当前优先保留
**二次相位 FFT + 条件性轴向修正**作为可比较基线，而不是无证据切换传播器。

理想薄透镜例子：若 CCD 正好在后焦面，`B=f` 与 SLM 到透镜距离无关，
输入传播曲率 `A/B=0`；SLM 轴向距离仅进入输出相位，无法靠该平面强度独立估计。
CCD 离焦时距离效应与入射曲率、几何标度耦合。未知入射场的单平面数据不能把
SLM 绝对距离、CCD 离焦与入射曲率唯一分离。当前只能拟合**条件性等效误差**。

### 4.1 本轮离线轴向扫描：未采用

复用 `transfer.axial.scan`，从历史 `common_replay` 中选取同一 377 × 377 网格、
同一 0.717 ms 曝光且采样目标未饱和的 4 条不同相位 `replay_0000..0003`；
`0004..0014` 因曝光或网格不同排除。筛选只检查已采样目标，
不是对未采样的原生像素作“全部未饱和”的保证。

| 结果 | 基线 0 m | 条件最优 -0.2 m |
|---|---:|---:|
| 训练 relative-L2 | 0.1159564 | 0.1125857 |
| 验证 relative-L2 | 0.1286515 | 0.1242911 |
| 验证 CV 绝对误差 | 0.0365404 | 0.0396165 |

验证 relative-L2 相对改善 3.389%，但训练最优落在 `[-0.2, +0.2] m` 的边界，
验证 CV 误差反而增加；`selection.json` 为 `boundary=true, promoted=false`。
新入口不加载 `candidate_parameters.json`，仍使用原检查点。
**不能据此声称 SLM 偏移 -0.2 m，也不能外推扫描范围外的绝对距离。**
只有一个曝光时，加性背景与电子偏置也不能独立识别。

后续如需区分传播段，先增加多平面或已知距离/曲率的独立约束，再比较完整 ASM 链与
当前基线的验证图像、CV 和实测方向响应；不要只按拟合训练误差选择复杂模型。
完整链的验收须先过采样/孔径/透镜实现检查，再用独立相位做局部方向余弦检验；
仅提高单帧图像拟合相似度、或仅在 ASM 内通过自动微分检查，都不足以替换当前基线。

## 5. 新实验入口与预注册接受准则

入口为 `scripts/slm/square_1000_diff_abba_20261030.py`。
默认仅读取历史归档、生成 `offline_plan.npz / config.json`；
只有显式 `--execute` 才进入设备等待、取得 `DeviceLock` 并加载驱动。
锁覆盖相机和 SLM 的打开、采集、复位及关闭；不删除陈旧锁、不终止其他进程。
陈旧 SDK 状态按设备互斥模块的诊断退出，不能靠删锁恢复。

执行步骤：

1. 在 0.5 ms 下测展宽种子，按完整目标峰值选择曝光（上限 16.87 ms）；
   验证信号与完整目标饱和情况后冻结曝光，不能复用历史功率假设。
2. 采三组同相位重复，每组 5 帧；固定背景、覆盖阈值与指标窗口。
   覆盖阈值为 `max(3 * temporal_noise_of_mean, 0.2 * initial_core_mean)`，
   图像平滑 sigma=8 原生像素，后续不随候选重算阈值。
3. 每块重新采当前接受相位为锚点，经实测图像目标导数与冻结模型 VJP 生成一步 Adam 更新；
   增量平滑 sigma=3 控制单元，联合加权去 piston/倾斜，仅改变增量而保留种子载波。
   初始加权 RMS cap=0.03 rad，单点绝对增量不超过 0.3 rad。
4. 同曝光采 `A1 -> B1 -> B2 -> A2`，两次 B 必须分别通过。
   第一块另测反方向的完整 A-B-B-A，它只用于诊断，不自动采用。
   若反向通过，标记方向失效并停止，避免把择优搜索误称为梯度验证。
5. 默认最多 3 块，最多允许 5 块；拒绝后 cap 减半，连续两次拒绝停止。
   接受结果写 `accepted_phase.npy`，结束或采集中出错均尝试下发直接零灰度、关闭设备后释放锁。
   不自动把结果留在 SLM 上，不改变激光设置。

固定判据：对每个指标，以 A1/A2 时间线性插值作该 B 的参照。
改善分辨阈值为 `max(absolute_floor, 3 * repeat_std, 3 * abs(A2-A1))`，
这是保守操作阈值，不是统计显著性或置信区间。

| 检查 | 接受要求 |
|---|---|
| coverage / IoU | 两次 B 各自超过参照与分辨阈值；绝对下限均为 0.002 |
| formation 总 loss | 两次 B 各自下降超过分辨阈值；绝对下限 0.001 |
| CV / boundary error | 不超过参照加分辨阈值；绝对下限 0.01 / 0.005 |
| 目标净能量率 | 不低于各自参照的 98% |
| 局部 EE | 绝对下降不超过 0.005 |
| 完整原生目标 | 任一帧出现达到 `0.98 * 4095` 的像素即否决，不只检查稀疏核心 |
| 曝光 / 时间 / 有限性 | A-B-B-A 曝光回读比不超过 1.001，时间顺序合法，指标有限 |
| 同相位能量漂移 | A1/A2 相差超过 5% 则拒绝，需要新会话重定基 |

coverage 在内缩 20 px 的核心计算；IoU 在固定局部窗口、排除零级盘后计算。
boundary error 是核心外围带相对核心均值的绝对强度误差，**不是像素单位的边界距离**。
局部 EE 的分母是固定窗口（排除零级）的净能量，不冒充全帧 EE。
稀疏网格上的 loss 与原生像素形态指标共同验收，避免只优化稀疏采样点。

## 9. 前向传播与局部可微校准的补充（2026-10-30）

核心目标仍是物理预测模型约束下的任意形状远场整形。低阶模式探针用于校准和
独立检验局部 Jacobian，不以高维随机搜索取代可微相位更新。

### 9.1 SLM 偏离前焦面不等于 CCD 离焦

设 SLM 到薄透镜距离为 `f+s`、薄透镜到 CCD 距离为 `f+t`，正号表示远离透镜。
无孔径截断的傍轴链为 `P(f+t) L(f) P(f+s)`：

```text
A = -t/f
B = f - s*t/f
C = -1/f
D = -s/f

U2(r2) = exp(i*pi*D*|r2|^2/(lambda*B))/(i*lambda*B)
         * integral U1(r1) exp(i*pi*A*|r1|^2/(lambda*B))
           exp(-i*2*pi*r1.r2/(lambda*B)) d^2 r1
```

当 `t=0` 时，`A=0, B=f`，SLM 轴向偏移仅改变输出二次相位，输出强度和倾斜
标尺不变。因此“SLM 必须严格位于前焦面，否则必然发生强度缩放和严重像差”的
说法不适用于理想薄透镜后焦面强度测量。轴向偏移本身也不会在该模型中生成球差
或彗差；有限透镜孔径截断、非傍轴传播、倾斜入射和实际透镜像差需要另建模型。

当 `t!=0` 时，输入二次相位 `A/B` 和傅里叶标尺 `B` 同时改变，SLM 偏移才与
CCD 偏移发生强度耦合。单个 CCD 平面还存在输入曲率与 `A/B`、几何标尺与 `B`
之间的参数混淆。不能把自由拟合的等效距离称为绝对机械距离，也不能同时放开全部
距离、曲率、焦距和缩放，而不加独立标定约束。

### 9.2 本轮新增的离线算子

`src/ao_shaping/algorithm/signal_processing/defocus_forward_core.py` 新增
`lens_abcd` 与 `collins_field`。前者显式保留两个平面偏移；后者以可分离复矩阵积分
计算 Collins 场，输入与输出使用独立的米制坐标，保留相位、传播参数和输出二次相位
的自动微分。原 FFT、拟合器和冻结模型的默认路径未改，新增算子尚未接入设备控制。

测试 `tests/ao_shaping/algorithm/test_collins_forward_core.py` 覆盖 ABCD 矩阵乘积、
后焦面复场与 FFT 极限一致、仅移动 SLM 时的强度不变性、相位与两距离的有限差分
梯度、后焦面距离不可辨识性、锚定图像不改变模型 Jacobian，以及奇异平面/非均匀
输入网格拒绝。该算子没有宣称包含有限孔径、旋转的 CCD 坐标、像元积分和器件
非线性；实际采用前必须补上这些测量链，并证明控制网格和输出采样收敛。

现有 `slm_axial_offset_m` 是相对冻结 ABCD 标定的条件修正，不是上述两个机械距离
的独立测量。现有 ASM 代码还需要单独审计可学习标量距离是否被转为 Python 浮点数。
ASM 的有限窗口、周期卷绕和传递函数采样误差也不能解释成物理方法本身不存在远场
适用范围；仅把 FFT 替换成 ASM 不构成模型修复。

### 9.3 下一轮拟合与验收

1. 从已经重复实测的 `F_blur4_full` 展宽相位建立当前曝光、背景和漂移参照。

   响应。曝光对照用于区分光强比例、加性背景（杂散光）项与电子偏置。
3. 先固定独立测得的几何标尺，只拟合有效输入曲率、低阶静态相差、照明和少参数

- 驱动板身份此前只出现在终端日志，未写盘。现已在脚本中加入 `write_json(args.out/"device.json", {drive_board, slm_number, wavelength_nm, opened_utc})`（位于 `slm.require_drive_board()` 之后），v7 已落盘 `22030108`；v4/v6 的身份仍只存在于采集时的终端输出。
- 诊断网格默认为 4 px 抽样；`--bin-size 4` 的 4×4 分块只把 RX/RY 方向余弦提高约 0.02–0.04，散斑混叠仍是主要限制。v7 的 1.0 rad 探针未饱和（最大 1127 counts），但偶次残差与信号同量级，说明提高幅度不足以突破漂移/非线性底噪。

### 10.7 结论与下一步

冻结模型的局部 Jacobian **仍未通过验证**。v7（1.0 rad / 1.0 ms）锚点仿射相对 L2 0.1875、相关性 0.1957；倾斜方向余弦 0.270（RX）/0.444（RY），4×4 分块仅 0.287/0.478；N4 在 1.0 rad 下仍为零响应（-0.0092）。与 v6 相比，幅度提高带来更强的相干响应（RX 0.218→0.270，RY 0.429→0.444），但方向一致率仍低于 issue #221 的两轴均不低于 0.5 的门槛，且偶次/奇次比 0.99/1.50 表明测量残差与信号同量级。N4 在实测与模型中均为空响应，只作对照，不参与通过或失败判定。该结果不支持“模型 Jacobian 可直接用于梯度更新”，也不足以反证模型存在数量级错误。

因此决定（按用户要求保持可微优化路线，不转实测 SPGD）：
1. 暂停从冻结模型恢复可微梯度迭代，但不放弃可微优化；局部 Jacobian 未验证前，不执行模型梯度更新。
2. 先用 v6/v7 已有采集离线核对预测链：统一锚点与符号差分的原生 `counts/ms` 口径，检查 ROI 亚采样、相位到面板坐标映射、模型归一化与动态范围，并复算模型对同一 A/P/M 序列的奇偶次响应。此步不新增设备采集。
3. 预测链修正后，先离线要求它同时复现锚点空间分布和 v6/v7 两轴倾斜响应，再重复同一 collect-only 符号探针；只有独立重复中 RX/RY 方向余弦均至少 0.5、偶次残差明显小于奇次信号且无非本征饱和，才恢复小步长模型梯度 A–B–B–A。未通过则继续用已有符号响应校准局部物理参数，不切换 SPGD。
4. v7 的 1.0 rad / 1.0 ms 仅证明该探针未饱和（最大 1127 counts），不代表可微优化步长已标定。1000 px 均匀正方形仍未达成；本报告记录的是局部模型诊断与后续验收门槛，不把诊断完成写成整形成功。§11 与 §12 继续对同一冻结模型做离线缺陷诊断与改进候选仿真。

## 11. 冻结模型的内在缺陷（离线复算，2026-10-30）

`data/debug/slm_transfer/multishape_nogs_20261030/square1000_model_diagnostic_20261030_v7/defect_sim/`。

### 11.5 D5 — 加性本底占预测框值的 94%，辐射率低估约 40 倍

预测框内最小值 0.755715 counts/ms 正是加性本底
`background + bias_counts/exposure`；预测框均值 0.8015 中约 94% 是这个常数，
真实预测信号只有 0.04575 counts/ms，而实测框均值 1.84449 counts/ms。绝对尺度
低估约 40 倍（1.84449 / 0.04575 = 40.3）。

该本底对形状目标（`ShapeObjective` 已做归一化）不致命，但它让残差指标在低信号
区由常数项主导，也是 §10.5 三参数拟合给出不可物理识别的负背景
（v7 `background = -20.70 counts/ms`）的原因之一。冻结检查点自身给出的
`gain = 151.340`、`background = 0.204884`、`bias_counts = 0.550832` 与实测三参数
拟合的 `gain ≈ 28.16`、`bias ≈ 14.96 counts` 不自洽，属于同一缺陷的另一侧面。

### 11.6 D6 — 证据边界：这是模型缺陷，不是测量噪声

三点：(1) A 重复的框内 rms 噪声底 0.417732 counts/ms，只占信号的 2.2%
（0.417732 / 1.8898）；(2) 相位复相关 0.996–0.997 的近重复对（A–E、B–C）给出场相关 +0.998，而相位
复相关 ≤ 0.004 的正交对给出 −0.048…+0.288 的场相关，说明该实验系统在相位上
高度可重复；(3) 实测种子响应
是噪声底的 12.8–15.5 倍。因此 §11.1–§11.5 的失配量级（共同分量 15 倍、种子
响应低 80 倍、辐射率低 40 倍）不可能由测量噪声或运行间漂移解释。

对照只覆盖目标框与 ROI 两个口径，没有覆盖 0 级附近的饱和/溢出；模式响应 v2 中
目标区内 `clipped_target = 0`，但 0 级溢出到目标框的部分无法从这批数据中排除。
这不改变 D1–D5 的结论（它们全部是目标框内的相对统计），但意味着绝对辐射率口
径仍需一次独立标定。

### 12.3 仍未解决的部分

振幅包络修复是必要但不充分的。候选把对角 r 从 0.0924 抬到 0.2083（2.3 倍），
把对角−交叉从 +0.0573 抬到 +0.2310（4.0 倍），但保真度天花板仍只有约 0.21——
即模型只解释了实测框内约 4% 的方差（r² = 0.2083²）。剩余失配至少有三条候选
来源，本轮均未验证：(a) 相位到面板坐标的映射（§10 的锚点仿射相对 L2 0.1875
已提示这一项不干净）；(b) 缺失的散射光/杂散光模型，它会把能量从包络边缘搬到
目标框内，正好是实测"边缘聚集"的来源；(c) 种子的高空间频率内容被模型网格
（640，`pixel_samples = 3`）滤掉。

因此本轮不把"换振幅包络"写成已验证的修复，只写成已由离线仿真支持、需在实验
系统上按新门槛验收的候选。

### 12.4 新门槛与决策

1. 保持可微优化路线，不转实测 SPGD（按既有决定）。
2. 模型梯度与黑盒梯度搜索继续暂停，恢复条件从单一的方向余弦门槛改为三条同时
   满足：(a) 正交对共同分量 r < 0.10；(b) 局部 Jacobian 方向余弦两轴均 ≥ 0.5；
   (c) 对角 r ≥ 0.30。三条的当前值分别是 +0.5354 / 0.270（RX）与 0.444（RY）/
   +0.0924，全部未达标。
3. 保留冻结检查点 `p20261030_s1000_square_plane_formation/model640/frozen_parameters.json`
   与种子 `square1000_bandlimit_live_20261030_v2/plan.npz::F_blur4_full`；拒绝
   −0.2 m 轴向候选（§4.1）。
4. 不切换 FFT/ASM（§4 的理由不变），不声称均匀 1000 px 方形整形成功。
5. 下一步的第一项是在候选振幅包络下重跑模式响应诊断，用同一套 `common-mode`
   口径在实测上复核共同分量是否真的降到 0.10 以下——离线仿真支持这个预期，但
   只有实测能确认。

### 12.5 复现方式

复现命令为 `python scripts/slm/square_1000_model_defect_sim_20261030.py --mode {variants|seed-sweep|common-mode|both}`；
产物为 `defect_sim/sim_variants.json`、`seed_sweep.json`、`common_mode.json`、
`seed_sweep_fields.npz`。脚本只读 `data/debug/` 与冻结检查点，不接触设备。
`seed-sweep` 与 `common-mode` 的实测侧复用的是 v7 的 1.0 ms 锚点采集与 v2 种子
运行的 5.468 ms 采集，没有新增采集。
