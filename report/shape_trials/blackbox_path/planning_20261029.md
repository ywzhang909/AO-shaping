## 阶段目标与待验假设

本轮要回答两个**不同**的问题，任一通过都不代表另一个通过：

- **H1（模型可预测性）** 在光路改变后，少参数物理预测模型的预测与 CCD 实测在
  当前相位族上是否相关（逐探针 Pearson、相对 L2、核心 CV）。
- **H2（模型可指导）** 该模型的局部响应方向能否引导 CCD 上的整形指标改善
  （少块更新后的 CCD 验收，而不是模型损失的下降）。

拒绝条件：模型损失下降但 CCD 指标不变或变差；探针相关系数普遍低于可辨识水平；
方向校验的差分图相关接近 0 或符号相反。

## 事实与边界

用户授权当前 SLM+CCD 实验；用户告知光路已改变（透镜朝 CCD 方向移动），但**移动
方向与距离不作为拟合器输入**，只在事后解释时使用。因此本轮的「当前几何」必须由
本次采集重新测量，历史设备身份、历史标定、历史曝光、历史检查点一律不是本轮真值。

当前只读进程检查未发现其他实验采集进程；残留锁文件不等于持有锁，执行程序必须
取得操作系统互斥锁后才能访问设备。

## 最小实验矩阵

使用现有 `ao_shaping.tools.slm.transfer.workflow.run_session`（不新增实验管线），
入口脚本 `scripts/slm/run_blackbox_path_20261029.py`：

| 项目 | 取值 | 性质 |
|------|------|------|
| 目标形状 | `square` / `triangle` / `rectangle` | 固定（见下方口径说明） |
| 原生 CCD 目标边长 | 200 px | 固定（沿用上一轮结论的目标尺寸，非本轮实测） |
| 核心掩膜 | 目标框内腐蚀 2 px，零级不单独扣除（`zero_radius=0`） | 固定 |
| 优化优先级 | 形状目标（CV + EE + 形状项），验收用配对 A–B–B–A | 固定 |
| 参考相位 | 平相位（首轮）/ GS 初相位（次轮） | 每轮声明 |
| 曝光比较方式 | 块内参考与候选同曝光；曝光由自动阶梯选定并读回 | 固定 |
| 探针 | 12 个确定性探针，12-bit，`counts_scale=16` | 固定 |
| 适配 | 完整少参数适配 120 次迭代，控制网格 128、FFT 2048 | 属于本轮预算 |
| 采样窗 | 半跨度 420 原生 px、步长 2 px | 属于本轮预算 |
| 整形块 | 3 块 × 8 次更新，每块三帧 | 属于本轮预算 |
| 数据 | `save_dataset` + Recorder，保留原始相位/灰度/CCD/曝光/时间/journal | 固定 |

**为什么是三个形状而不是一个**（对上一版的更正）：上一版规划写「一个方形目标」，
与实际会话不符。校准阶段（曝光响应、模糊/辐射度量）需要**形状族**才具备区分力——
单一形状无法把「等效模糊」与「增益/背景」分开，因此三个形状是校准的可辨识性要求，
不是三次独立整形目标。整形结论仍按形状分别报告，不做跨形状平均。

## 通过 / 拒绝标准

- H1 通过：逐探针相关中位数 ≥ 0.8 且无系统性符号反转；相对 L2 只作同单位的
  相对比较，跨单位不解读为倍数误差。
- H2 通过：同一形状、同一掩膜、同一曝光下，候选相对参考的 CV 与 EE **同时**不劣化，
  且 A–B–B–A 配对判定为接受；仅模型损失下降不计。
- 相似度：新增的 `target_pearson`（实测帧与目标掩膜在全采样窗上的 Pearson）作为
  「像不像这个形状」的读数，与 CV / EE 并列报告；它不能单独作为接受依据。

设备释放预案：上下文管理器关闭设备，外层 `finally` 释放互斥锁；保留日志证明实际
关闭结果，不以进程退出代替关闭证据。任一硬失败（无光、饱和不可解、几何失败、
设备占用）立即停止并保留失败产物。
