## 1. 两轮只差一个变量：起始相位

| 项 | r1 | r2 |
|---|---|---|
| 起始相位 | 名义初始化（平面相位） | GS 预整形种子 |
| 采样窗 | 半跨度 420 原生 px、步长 2 px | 同 r1 |
| 控制网格 / FFT | 128 / 2048 | 同 r1 |
| `model` / `anchored` 曝光（读回） | 0.119 ms | 4.320 ms |
| 采集探针曝光阶梯 | 0.067–0.243 ms | 0.071–0.238 ms |
| 采集 / 原始帧 | 54 / 162 | 54 / 162 |
| 整形块 | 9（3 形状 × 3 块） | 9 |

两轮共用同一条流水线（探针采集 → 名义初始化 → 少参数拟合 → 控制分辨率导出 →
模型块 → 曝光响应 → 模糊/辐射度量 → 锚定块 → 原始数据审计 → 汇总 → 方向校验）。
r2 只换起始相位，用来回答一件事：**200 px 目标填不满，是种子的问题还是模型的问题**。

曝光差 36× 是**形状后的相位**决定的，不是光路变了：r1 的平面相位把能量压在零级，
r2 的 GS 相位把能量摊进目标区，同样的饱和上限自然要更长曝光才够。所以两轮之间的
亮度不可直接比较，可比量只有同轮内同曝光的 `target_pearson`、CV、EE。

## 4. 块级验收

| 轮次 | 模板块接受 | 锚定块接受 | 锚定块损失变化（相对） |
|---|---|---|---|
| r1 | 4/6（square 0/2、triangle 2/2、rectangle 2/2） | 8/9（square 2/3、其余 3/3） | 未逐块记录 |
| r2 | **0/6** | **9/9** | −0.65% … −4.40% |

r2 的 6 个模板块**全部被拒**，且不是「漂移超限」而是**指标本身变差**（+0.27% … +2.93%）：
在模型自己的图像上，优化步没有让它自己的目标变小。同一批相位在锚定块上却 9/9 通过、
实测损失下降 0.65–4.40%。这两个方向相反的结果是本轮最值得查的一条，展开见
[`analysis_20261029.md`](analysis_20261029.md) §4。

## 5. 按规划判据复核：两条假设都未通过

`planning_20261029.md` 的判据是事先写的，这里照原文逐条对：

| 假设 | 判据 | 实测 | 判定 |
|---|---|---|---|
| H1 模型可辨识 | 逐探针相关中位数 ≥ 0.8，且无系统性符号反转 | r1 0.91–0.93（但两轮都是散斑，见 §6）；r2 0.56–0.78，中位 0.70 | **未通过**（r2） |
| H2 候选不劣化 | 同形状、同掩膜、同曝光下 CV 与 EE **同时**不劣化，且 A–B–B–A 判定接受 | A–B–B–A 9/9 接受，CV 三个形状全部下降；但 **EE 三个形状全部下降**（−2.6%、−1.8%、−3.5% 相对） | **未通过**（EE 项） |
| 相似度（并列读数，不作接受依据） | `target_pearson` 与 CV/EE 并列报告 | r1 0.10–0.24；r2 0.66–0.80 | 记录 |

**H2 的未通过不是判据太严，而是综合目标与判据不是同一件事。** 块级接受用的是加权复合分数
（`cv2` / `energy` / `shape` / `smooth`），它在「核心更平整」与「窗内能量更多」之间可以互相
抵消；本轮它选了前者——CV 下降 6–19%，代价是固定 441 px 窗内的 EE 下降 2–4%、峰值下降
最多 38%（rectangle 1170 → 726 计数）。也就是说：**整形确实在发生，但它把能量推出了
评价窗**，而规划里的判据恰恰要求这两项同时不劣化。

这不是本轮的偶发：`planning_20261029.md` 的「通过/拒绝标准」写明了「仅模型损失下降不计」，
所以按那次规划的措辞，本轮结果是**拒绝**，不能写成「验收通过」。

## 6. 相关度高不等于模型对

r1 的实测/预测相关 0.91–0.93，比 r2 的 0.56–0.78 高，但 r1 的 `target_pearson` 只有
0.10–0.24。原因是 r1 的光场是散斑：散斑与散斑的去均值相关天然很高，CV 比值也在 0.95–1.10
（见 `analysis_20261029.md` §3 的表）。**两幅都是散斑时，相关度不能区分「模型对」与
「模型和实测一样糟」。** 判据要的是「像不像目标」，那就只有 Pearson 与 CV 的相对位置能答。

## 7. 同曝光重放

两轮曝光不同，直接把 r1 与 r2 的亮度差读成相位质量差是错的，所以另做了一次重放：
把两轮归档的同一条相位（13 条，含 `flat`）用**同一曝光**各采一遍，共 38 次采集 / 114 帧，
全帧峰值 2606/4095（63.6%），饱和像素 0，设备互斥锁全程独占并已释放。

结论：r1 的低 Pearson 是相位质量差，不是曝光/本底造成的伪影。细节（曝光定档、逐条相位
出处与 sha256、第 2 轮反序）见同目录 `artifacts/live_acquisition_20261029.md`。

## 8. 口径与限制

- 两轮之间的亮度、峰值、EE 绝对量**不可比**（曝光差 36×，且曝光是被相位决定的）。
  可比的是同轮内同曝光的 Pearson / CV / EE 变化方向。
- 采样窗按半跨度 420 px、步长 2 px 采样，`target_pearson` 只在这个窗内定义；窗外的零级
  不参与读数。
- 审计哈希证明产物未被改动，**不证明**产物本身的读数正确；读数口径的问题见
  [`analysis_20261029.md`](analysis_20261029.md) §2。
- 本文件不含任何重算的模型预测值；预测值一律引自会话内 `summary/results.json`。
