## 0. 一句话结论

1. **工程修复已确认**: V2.0 的四个非理想旋钮**这次真的到达了仿真** —— 新报告的数字与基线不再逐字相同 (§1 PIB 仿真 0.1492 → 0.03357, 噪声地板 σ(PIB) 0.0006401 → 2.9e-05 等)。上一版「重跑」之所以毫无变化, 是因为 `slm_pib_sim.py` 的转发链没把旋钮送进 `SimPibSystem`, 这一版已修好 (见 §7)。
2. **方向是对的, 数值还没收拢**: 零级晕正确地把框内 PIB 压低 (这正是硬件 PIB 也偏低的物理来源), PRNU/暗 FPN 也正确地把噪声地板抬高。**但**本轮给的是「代表性未标定值」(η=0.1、PRNU σ=1.5%、FPN σ=2 counts、γ=1), 不是这块器件实测标定的值, 所以判定分布反而从 **一致 35** 滑到 **一致 24**。
3. **这不是退步, 是孪生变「诚实」了**: V1.0 的「一致 35」里有一部分是因为孪生太理想、碰巧在某些指标上和硬件撞上; V2.0 把硬件真正有的误差源建出来之后, 在「PIB / 噪声地板 / 增益」这些**正由非理想性主导**的指标上和硬件分开了 —— 这正是忠实孪生的应有行为。剩下的差距是**标定**问题 (参数值), 不是**建模**问题 (模型结构)。

## 2. 按物理机制拆「为什么变这样」

- **零级晕 (η=0.1) — 主导了 PIB 类 8 行变差**: `U = U_inc·[η + (1−η)e^{iφ}]`, 零级只过物理透镜散成一圈弥散晕, 不进 GS 整形主瓣 ⇒ 框内 PIB 从 0.1492 掉到 0.03357, 硬件实测 PIB 也只有 0.1666。**方向 100% 正确** (硬件低 PIB 正是零级晕造成的), 但 η=0.1 是拍的, 量级过冲 (仿真 0.0336 比硬件 0.1666 还低 5×)。
- **PRNU (σ=1.5%) + 暗电流 FPN (σ=2 counts) — 主导噪声地板重排**: 固定乘性图在量化**前**作用, 把逐帧重复噪声从「白噪声整流底座」变成「带空间相关结构的固定图」, σ(峰值) 从 0.2582 收敛到 0.1845 (实测 0.1845, 反而更贴), σ(CV) 从 0.001646 进一步降到 0.001363。结构上对, 但 σ(PIB) 反而更集中 (2.9e-05), 说明 PRNU/FPN 的幅值没标对。
- **SLM LUT (γ=1.0, 无表) — 本轮几乎中性**: γ=1 是线性, 只额外叠了 2π/993 灰度量化往返。它对远场是微小相位抖动, 在 CV 上恰好把平场/GS 剖面填平了一点 (那 2 行变好), 但没造成系统性偏移。要见真章得喂设备实测 LUT 表。
- **宽度/焦面类 (§1 FWHM、§3 离焦、§4 1/f) — 部分被零级晕扰动**: 基线宽度本是「一致/偏差」边界, 加零级晕后本底抬高、离焦散开形态变了, 导致 FWHM 从一致滑到偏差/不一致。焦面标定 1/f / 焦距 仍稳 (这是几何量, 不受非理想性影响)。

## 4. 让数值也收拢的下一步 (需要你给标定数据)

V2.0 的模型结构已经齐了, 差距全是**参数值**没标对。把下面任一条喂给 `sim_twin_params_20261023.json` 再跑 `--execute` 即可:

1. **零级占比 η**: 实测 SLM 的零级衍射效率 (通常 5%–15% 量级)。现在拍的 0.1 把 PIB 压过头, 标真实值会直接把 §1/§5 的 PIB 拉回「一致」。
2. **SLM LUT 表**: 设备实测的「灰度→显示相位」曲线 (或 γ)。现在 γ=1 中性, 真实 LUT 非线性会改剖面, 可能进一步改善 CV 类。
3. **PRNU σ / 暗电流 FPN σ**: 相机平场标定给出。现在 1.5% / 2 counts 是拍的, 标真实值会让噪声地板落到正确档。
4. **(可选) 各向异性补零**: `--sim-far-field-padding 行,列` 让两轴节距都 = 相机像元, 清掉 ~1% 宽度标度残差。

复现命令 (改完参数直接重跑整轮, 或只重出表):

```bash
# 整轮重跑 (约 8–15 min, 离线)
python scripts/slm/compare_sim_vs_hw.py --execute \
    --params report/shape_trials/sim_vs_hw/artifacts/sim_twin_params_20261023.json

# 只重出表与正文 (复用已存产物, 秒级)
python scripts/slm/compare_sim_vs_hw.py \
    --params report/shape_trials/sim_vs_hw/artifacts/sim_twin_params_20261023.json \
    --sim-root data/debug/sim_vs_hw_20261023_v2
```
