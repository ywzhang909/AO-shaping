## 1. 本轮做了什么

把**同一批采集脚本**搬到**数字孪生**上, 跑第三轮的**同一组测量**, 再用**同一套指标函数**与第三轮硬件归档产物逐项对照。三条纪律:

1. **实测侧零硬编码**: 每一个实测数字都从归档产物 `report/shape_trials/hw_defocus_zernike/artifacts/round3_20261022` 的 `measurements.json` / `summary.json` / 焦面标定 JSON 里**读**出来 —— 数据变了, 表跟着变。
2. **仿真侧不改采集脚本**: 离焦扫描用 `scripts/slm/hw_gs_defocus_probe.py`、焦面标定用 `ao_shaping.tools.slm.panel.focus_probe`、阶数扫描用 `scripts/slm/run_gs_refine_zernike_sweep.py`, 三者都有现成的 `--cam-type sim` 路径; 本脚本只在**运行时**替换它们各自的 `configure_sim_system`, 把完整口径注入进去。**三个脚本文件一个字都没改。**
3. **指标口径不另写一套**: CV / PIB / 复合分数来自 `ao_shaping.algorithm.signal_processing.square_shaping`, 光斑几何来自 `ao_shaping.utils.image.frame_analysis` —— 与采集脚本用的是**同一个函数**。

**两侧同源的三件事** (不同源就是两种口径, 表就没有意义): 同一张瞳面菲涅尔焦面矫正片 (`defocus_focal_mm` = 1549.33 mm)、同一批 1/f 格点 (焦面标定的 42 个点)、同一个目标框 (阶数扫描) —— 全部从实测那一轮的 `run_config.json` / `summary.json` 读出。

## 2. 仿真用了什么 (以及为什么是那个值)

完整一组在 [`sim_twin_params_20261022.json`](artifacts/sim_twin_params_20261022.json) (`--params` 读回即复现)。每一项都不是拧到「看着像」, 而是**由某条实测反推**:

| 旋钮 | 本轮取值 | 为什么是那个值 (依据哪条实测) |
|---|---|---|
| `far_field_padding` | 4 | 孪生的角标度 = `λf/(N_pad·p)`; 实测 Kx = 7546.4 / Ky = 7495.9 (相机像元/面板像元), 面板 1920 列 ⇒ 7557/1920 = 3.94 ⇒ **4** 才复现实测角标度 (脚本默认的 16 是 4× 放大的显示口径, 角标度会差 4 倍) |
| `peak_counts_per_ms` | 133.5 | 实测平场 0.2 ms 整帧峰值 27 counts ⇒ 135 counts/(峰值分数·ms) ⇒ 取 133.5 使仿真帧与实测帧**同一量纲** (不再是「归一到 ~100」的相对强度) |
| `read_sigma_counts` / `shot_k` / `quantize_bits` | 0.5 / 0 / 8 | 实测帧是 uint8、4 帧平均、背景只有 0 / 0.25 / 0.5 三个值 ⇒ 每原始帧 σ ≈ 0.56 counts; 而 σ(整帧峰值) 只有 0.184 counts (27 counts 处) ⇒ 该光级**不是散粒受限** ⇒ `shot_k = 0` |
| `dark_level_counts` | 26.75 | 实测相机的暗电平 (远高于读出噪声)。它让背景**不再落在中位数的跳变边界**上: 整帧总功率的相对抖动 实测 0.446% vs 仿真 0.469% (补暗电平之前仿真是 72.7%) |
| `camera_defocus_m` | 0.010084735 m | 实测最佳 1/f = 0.6454 m⁻¹ ⇒ 瞳面二次相位的补偿焦距 1549.33 mm; 孪生里 `f_v = f²/Δz` (Collins/ABCD) ⇒ `Δz = 0.125²/1.54933` |
| `counts_reference` | `flat` | 逐帧把峰值归一会把离焦散开的光**又拉回原峰值** (实测峰值随离焦崩塌 27 → 0.25 counts); 固定参考 = 平场在**理想聚焦**下的峰值 ⇒ counts 守恒能量 |
| `beam_w0` | 120 | 实测焦面矫正后的平场 FWHM 14.61 相机像元 ⇒ 反推**强度** 1/e² 半径 ≈ 170 面板 px; 孪生的 `beam_w0` 是**幅度**的 1/e 半径 ⇒ 120 (衍射极限由入射有效口径定, 不是面板尺寸) |
| `illumination_radius_px` | `None` | 真实照明是软的;**硬截断会造出 Airy 环**, 让阶数扫描的自动定尺把目标框撑到 148 px (实测是 12.54 px) ⇒ 本轮不截断 |
| 面板静态相差 (`SimPanelAberration`) | `{}` / 粗糙度 0 | 孪生的面板是**理想相位板**。实测多出来的宽度已由「入射有效口径」解释; 再叠低阶 Zernike 虽然能把光斑撑宽, 但会把**平顶**光斑变成**带裙边的尖峰** ⇒ 目标框内的 CV 反而变差 ⇒ 本轮**不用它凑宽度** |

## 4. 对上了什么 / 仍差什么

判定分布: **一致 35** / 偏差 8 / 不一致 6 (共 49 行)。逐项归因见下 (与数据表 §2 同一份函数产出):

- ① **几何 / 焦面** — ✅ 已对齐: 实测最佳 1/f = 0.6454 m⁻¹ (f = 1549.33 mm), 仿真最佳 1/f = 0.6456 m⁻¹ (f = 1548.86 mm)。**机理**: 孪生原来没有「CCD 离焦」这个自由度 (远场是面板相位的纯 FFT ⇒ 焦面按构造就在探测器上), 所以「用瞳面菲涅尔相位把焦面搬回探测器」在仿真里毫无效果、最佳 1/f 恒为 0。现在孪生有 `camera_defocus_m` (探测器在 f+Δz 处, 瞳面上等价地乘 `-π·Δz·r²/(λf²)`), 补偿焦距 `f_v = f²/Δz` ⇒ 实测的 0.6454 m⁻¹ (= 瞳面二次相位焦距 1549.33 mm, 边缘相位 24.7 rad) 就是 **Δz ≈ 10.09 mm**。更硬的证据是**平场对菲涅尔矫正的响应**: 实测平场宽度 46.52 px → 14.61 px (收到 0.314×), 仿真 61.29 px → 17.36 px (收到 0.283×) —— 两侧现在都是「一个被离焦散开的平场 + 一片把它收回来的菲涅尔相位」。
- ② **光斑宽度 / 面板静态相差** — ✅ 已对齐: GS 相位下的光斑宽度 实测 13.94 px vs 仿真 17.28 px。仿真侧的数字已经换算成相机像元 (孪生一个远场采样点 = 1.57 相机像元 (行) / 0.98 (列), 调和平均 ×1.211)。 **机理**: 孪生的光斑宽度由**入射光的有效口径**定 (衍射极限 ~ 1.03·λf/D), 实测焦面矫正后的平场宽度 14.61 px 反推出**强度** 1/e² 半径 ≈ 170–400 面板 px —— 本轮取 `beam_w0 = 120` 面板 px (孪生的 `beam_w0` 是**幅度**的 1/e 半径 ⇒ 强度的 1/e² 半径 ≈ 170 px), 并且**不**再截断到照明盘。面板静态相差 (`SimPanelAberration.zernike_rad`) 会把光斑**再**撑宽, 但它同时把光斑从「平顶」变成「带裙边的尖峰」⇒ 目标框内的 CV 反而变差, 所以本轮**没有**用 Zernike 去凑宽度, 只把它留作可调旋钮。
- ③ **光度 / 离焦能量守恒** — ✅ 已对齐: 0.2 ms 曝光下整帧峰值 实测 27 counts (⇒ 135 counts/ms) vs 仿真 24.25 counts (⇒ 121.2 counts/ms)。**机理**: counts 口径原来**逐帧**把远场峰值归一到 100 ⇒ 离焦散开的光又被拉回原峰值 (实测峰值随离焦崩塌到 0.25 counts, 仿真几乎不动)。现在 `counts_reference="flat"` 用**固定参考** (平场在理想聚焦下的峰值), 峰值分数 = 当前远场 / 该参考 ⇒ Δz=+20 mm 处仿真 1.75 counts (仍偏高)。
- ④ **噪声 / 暗电平** — 部分对齐: σ(CV) 实测 0.00448 vs 仿真 0.00165; σ(PIB) 实测 0.00111 vs 仿真 0.00064; σ(复合分数) 实测 0.00192 vs 仿真 0.000678; σ(峰值, counts) 实测 0.184 vs 仿真 0.258。 **根因是暗电平, 不是噪声大小**: 探针的帧处理是「减中位数 + 裁负」, 而孪生的 counts 帧原来**背景恒为 0** ⇒ 读出噪声被**整流**成一块与像素数成正比的 DC 底座, 而它的「中位数」恰好卡在 0/0.25 的跳变边界上 ⇒ 逐帧跳变。整帧总功率 实测 11412 ± 50.9 counts (0.446%), 仿真 11920 ± 56 counts (0.469%)。补上实测相机的 26.75 counts 暗电平 (量化作用在**带暗电平的原始 ADU** 上, 暗电平靠减中位数去掉) 之后, 中位数不再落在跳变边界上 ⇒ 底座稳了, σ(PIB) 也随之落到同一档。
- ⑤ **离焦响应形状** (FWHM 归一化到各自 Δz=0): Δz=-20: 实测 5.894 / 仿真 5.260; Δz=-15: 实测 10.332 / 仿真 3.775; Δz=-10: 实测 1.373 / 仿真 2.606; Δz=-7.5: 实测 3.257 / 仿真 2.221; Δz=-5: 实测 2.461 / 仿真 1.682; Δz=-3.75: 实测 2.289 / 仿真 1.494; …共 24 点。逐点相对差最大 +176.9% @ Δz=+10 mm (但逐点值噪声大: 远场是散斑场, 单帧 FWHM 本身不单调 —— 实测在 Δz = −10 mm 处量到 19.2 px、在 −15 mm 处量到 144 px)。**稳健量** (|Δz| ≥ 5 mm 的 10 点, 归一化 FWHM 的中位数): 实测 3.2 vs 仿真 2.88 ⇒ 仿真的离焦响应**陡 0.901×**。
- ⑥ **基线** (Δz=0, GS 相位, 同一目标框): CV 实测 0.1951 vs 仿真 0.2196 (一致); PIB 实测 0.1666 vs 仿真 0.1492; 空心度 实测 0.8885 vs 仿真 0.9216。**注意**: 目标框边长固定 10 px, 光斑一旦比框**宽**, 框内就接近平顶 ⇒ CV 低; 光斑比框**窄**时框采到的是翼 ⇒ CV 爆炸。所以 CV 对**光斑宽度与剖面形状**极其敏感: 宽度对上之后, 剩下的差主要是**剖面形状** (实测 GS 相位打出来的是一个**平顶方斑**, 而孪生把同一张相位打在**另一块**面板相差上, 剖面更尖)。

**还没对上的几类, 各自的物理原因** (不硬凑):

- **极小光斑峰值 (Δz = ±20 mm, 0.25 vs 1.5–1.75 counts)**: 这是**量化级**地板, 不是物理差距 —— 实测 0.25 = 4 帧里只有 1 帧出现 1 count; 仿真的 1.5–1.75 来自「暗电平 + σ=0.5 的 4 帧平均」在减中位数后的残余。要压下去只能改噪声分布, 那是编造。
- **§4 的「最佳点峰值/曝光」与「相对平场增益」**: 两侧的「平场」不是同一个量 —— 硬件那一轮的 GS 相位是**针对这块面板的相差优化过**的, 所以它的 GS 光斑比未整形平场亮 (实测增益 29.21×); 孪生把同一张 GS 相位打在**另一块 (合成的)**面板相差上, 那个增益不存在。要真正对上, 得先**实测反演**出这块面板的面形再注入, 超出「对照尺」能定的范围。
- **§5 的 `before` / `after` 行**: 两侧 SPGD 轮数不同 (硬件 154+150, 仿真 8+8), 这几行**只能看方向** (`quality` 在仿真里确实随阶数上升), 绝对值不可比。

## 5. 这条仿真链能用来干什么 / 不能用来干什么

### 5.1 能

- **证明接口与流程在线实现**: 同一份 CLI、同一套指标函数、同构的产物 (`measurements.json` / `run_config.json` / `frame_*.npz` / 焦面标定 JSON), 在孪生上跑完不掉链子 —— 换后端 (`--cam-type sim`) 不改一行采集代码。
- **定量检验「哪些物理效应必须建模」**: 三个根因 (CCD 离焦 / counts 的固定参考 / 暗电平) 都是**先量出差距、再补模型、再看差距消掉**的; 这类判断可以反复在孪生上做, 不必占机时。
- **调参与回归**: 目标框 / 曝光 / 阶数 / SPGD 超参的行为在孪生里可复现 (固定 seed 逐位可重复), 适合当 CI 级的冒烟与回归。

### 5.2 不能

- **不能当实测替代**。孪生里 focus_probe 的「最佳 1/f」是**几何产物**: 它等于 `1/(f²/Δz)`, 正是我们把 `camera_defocus_m` 设成 10.0847 mm 的**逆运算** —— 表里它对上实测, 证明的是「我们把 CCD 离焦量按实测反推对了」, **不是**「孪生独立标定出了 1549.33 mm」。任何「孪生给出的焦距/标定值」都必须这样读。
- **曝光线性度检查在孪生里量的是噪声**: 孪生没有真实的曝光非线性 / 暗电流 / 增益切换, 所以 `linearity_ratio` (实测 1.037 vs 仿真 1.203) 在仿真侧只是「同一帧换个曝光」的量化噪声, 不能当作传感器线性度的验证。
- **面板相差是合成的**: `SimPanelAberration` 里的 Zernike 与粗糙度是**我们选的**, 不是这块面板的实测面形。用它解释「为什么光斑宽了 1.5×」只在量级上成立。
- **不能用来定绝对精度类结论**: 衍射效率、真实散斑统计、长期漂移、像素响应非均匀 (PRNU) 这些都要真实器件。

## 7. 局限 (没有建模的物理效应)

按本轮实际看到的写, 不列「可能」:

1. **零级 (η) 分量**: 真实 SLM 的瞳面是双分量 `U = U_inc·[η + (1−η)e^{iφ}]`, 零级只过物理透镜、在 `f+d` 处散成一圈弥散晕; 孪生的瞳面只有**一路光**, 没有这个双分量 ⇒ 「框外功率占比」虽然对上了, 但它的**来源构成**不同 (实测含零级晕, 仿真只有边瓣与焦外弥散)。
2. **面板面形误差**: 只有「合成 Zernike + 可选空间相关粗糙度」, 没有这块面板的实测面形; 逐像元白噪声 (`roughness_corr_px = 0`) 在远场上只加弥散本底、**不撑宽光斑**, 这也是本轮没用它凑宽度的原因。
3. **探测器非理想性**: 曝光非线性、暗电流、增益切换、像素响应非均匀 (PRNU)、读出噪声的空间相关性 —— 都没有。噪声是逐像元高斯白噪声 + 8-bit 量化。
4. **LCOS 的响应时间与松弛**: 仿真面板是**瞬时响应** (`display_data` 的 `wait_time_s` 被接受并忽略), 所以 `display_and_average` 的稳定性判据在孪生里恒为「一次就稳」。
5. **SLM 的 LUT 非线性与 10-bit 灰度量化对远场的影响**: 孪生只做「弧度 → 灰度 → 远场」的理想映射 (`two_pi_gray = 993`), 没有 LUT 曲线、没有灰度级量化误差。
6. **热漂移 / 长期漂移**: 没有。噪声组只重复 9 次 (几十秒尺度)。
7. **远场网格的各向异性**: 面板 1920×1200 是长方形, 单一补零因子无法让两轴都等于一个相机像元 (行 1.57 / 列 0.98) —— 宽度比较已按调和平均 ×1.21 换算,但仍有 ~1% 的标度残差。
