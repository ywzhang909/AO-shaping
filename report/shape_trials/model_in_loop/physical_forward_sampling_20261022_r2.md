## 2. 传播采样：变化很小，不能解释主要 CV 误差

保持已拟合 M4 的像差、几何、光轴、振幅、增益和背景全部冻结。
计算区域始终是 `1920×1920 panel px`，面板高度 `1200 px` 外振幅为零。
加密输入网格时节距为 `1920/N`，FFT 到 CCD 的映射同步改变。
采用规范 `focal_intensity`，并按输入节距与正交 FFT 归一化保持物理强度尺度。
不以重新拟合增益抵消采样引起的数值变化。

发现并显式保护了一个坐标约定：原 128 网格 Zernike 中心位于
`63.5×15=952.5 panel px`，不是 `960 panel px`。
加密时从规范全分辨率模式按该物理中心重采样，避免无意改变倾斜和模式尺度。
原网格与物理基函数重采样的结果逐位一致。
这是旧拟合的物理约定保持，不代表已独立确认真实光轴位于该中心。

| 输入网格 / FFT / 积分 | U 的 CV 误差均值 | C 的 CV 误差均值 |
| --- | ---: | ---: |
| 128 / 512 / 点采样 | 0.07322 | 0.24373 |
| 128 / 1024 / 点采样 | 0.07289 | 0.24701 |
| 128 / 2048 / 点采样 | 0.07282 | 0.24779 |
| 256 / 2048 / 点采样 | 0.07273 | 0.24722 |
| 512 / 2048 / 点采样 | 0.07408 | 0.24448 |
| 512 / 4096 / 点采样 | 0.07377 | 0.24774 |
| 512 / 4096 / 每像素 3×3 面积积分 | 0.07399 | 0.24593 |

逐记录预测图的相对 L2 差（包括参考记录）：

- 固定输入网格，FFT 512 → 2048：中位 `0.236%`，最大 `0.441%`。
- 固定 FFT 2048，输入网格 256 → 512：中位 `0.672%`，最大 `1.289%`。
- 固定输入网格 512，FFT 2048 → 4096：中位 `0.196%`，最大 `0.376%`。
- 固定 512/4096，点采样 → 3×3 像素积分：中位 `0.113%`，最大 `0.186%`。

结论限于这批已保存的带宽及光路：加密后的变化远小于 C 的 CV 偏差。
不能把当前主要误差归因于 FFT 采样不足或单个 CCD 像素面积积分缺失。
尚未覆盖任意高空间频率相位，也没有声称无限网格严格收敛。
`2 px` 间隔的诊断 ROI 与每个真实像素 `1×1 px` 的面积积分是两个概念，
积分没有把 `2×2 px` 当成物理 CCD 像元。

## 3. 曝光偏置：有实际影响，但单独校正不能解决 CV

补充曝光：C 为 `0.307/0.769/1.539/3.079/1.539 ms`，
U 为 `7.510/18.777/37.554/75.109/37.554 ms`。
无饱和；前 9 组稳定，第 10 组 U 重复档超时，
不作为有效响应验证样本。随后延长最大等待至 `30 s`，保留 `stable_tol=0.05`，
固定 U `37.554 ms` 重复 3 次，均稳定。
3 次原始圆盘积分为 `428383.8/430390.0/431368.8 counts`；
与较早同曝光读数存在漂移，因此不能拿后来的重复强行替代前面失败记录。

逐像素模型为两种固定相位的独立曝光斜率与共享非负截距：

```text
counts_p(t, branch) = slope_p,branch * t + offset_p
```

每个相位首次出现的曝光档用于拟合，重复档仅用于验证；稳定失败全部排除。
无真实遮光暗场，`offset_p` 只能称带光条件下的仿射截距估计，
可能受低光非线性、光路漂移和空间结构变化影响，不能认定为纯电子暗偏置。
无约束截距约 `9.86%` 像素为负；约束后截距的 `5/50/95%` 分位为
`0.000/0.470/1.580 counts`。唯一有效 C 重复档的预测 RMSE 为 `0.275 counts`；
U 在该组没有有效重复验证，三次后续固定曝光只能补充重复性证据。
校正后的全部诊断像素约 `10.85%` 为负，已完整保存，未截断。

因此本轮不把大面积截距忽略，也不将这种校正直接升级成相机通用响应标定。
当前档位足以检查局部仿射偏置，仍不足以稳定辨识双指数/Bezier 等高自由度模型。

## 4. 剩余峰宽：有效展宽仅部分解释，未调制光不是充分解释

对固定物理预测做已知单位的高斯强度展宽，sigma 以 CCD px 表示，
检查 `0/1/2/3/4/6/8 px`。该项是**有效模型偏差**，不是独立测得的 CCD PSF。
比较时使用校正后的观测、固定 ROI，且仅在原训练相位上拟合共享非负增益与常数背景。

训练归一化图像 MSE 最小的单分量展宽约 `sigma=2 px`；
对应后采诊断相位 CV 误差约 U `0.0854`、C `0.1869`。
sigma 继续到 `4 px`，C 的 CV 误差可降到约 `0.1018`，
但 U 增至约 `0.1043`；训练图像误差也变差。
因此不能根据测试 C 的 CV 单独选择 `4 px`，也不能说共同展宽解释了两分支。

另用冻结物理模型的零指令强度作相位无关光模板，
与主信号做非相干非负混合。训练择优约为 `sigma=2 px`，
系数约主信号 `26.20994`、模板 `0.32766`、常数 `0.02109`。
其后采 CV 误差为 U `0.0841`、C `0.1859`，相对单分量几乎没有改善。
模板混合系数不是经独立标定的器件零级比例；
该结果仅表明这一非相干背景假设不足以解释当前误差，
没有排除相干零级、振幅耦合或更复杂的相位响应。

## 5. 训练目标修正与后续门槛

原拟合以相关性为主，可能在结构较像时容许明显 CV 偏差。
新增强度归一化 MSE 与固定 ROI CV 误差的联合目标，
只用原训练相位更新共享像差、振幅、光轴、增益、背景和一个有效展宽参数。
CV 权重在运行前设为 `1.0`，未按测试相位误差调整。
每轮保存训练预测 NPZ、全部参数、损失、UTC 与单调时钟到 `iterations.pkl`；
最终按训练目标选择检查点，不用后采数据选迭代。

联合拟合完成 `150` 次更新，含初值共保留 `151` 个迭代快照。
训练联合目标从 `0.13538` 降到 `0.11050`，训练 CV 平方误差均值从
`0.02558` 降到 `0.00738`；最佳训练目标对应最终迭代。
有效展宽 sigma 由 `2.0` 调为 `3.51592 CCD px`。

| 数据 / 分支 | 相关性均值 | CV 绝对误差均值 | EE_ROI 绝对误差均值 | 强度矩质心误差均值 / px | RMS 半径相对误差均值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原训练 U | 0.8973 | 0.0883 | 0.0304 | 6.61 | 2.62% |
| 原训练 C | 0.9531 | 0.0675 | 0.0281 | 6.10 | 7.61% |
| 原开发验证 U | 0.8599 | 0.0716 | 0.0288 | 7.28 | 2.06% |
| 原开发验证 C | 0.9483 | 0.0910 | 0.0418 | 4.38 | 5.96% |
| 后采诊断 U | 0.8889 | 0.0975 | 0.0289 | 7.68 | 2.37% |
| 后采诊断 C | **0.9611** | **0.0888** | 0.0364 | 4.64 | 6.66% |

这里“强度矩质心”和 RMS 是在同一固定采样窗口对非负强度权重计算的描述量，
不是热点定位；弱背景和尾部会明显影响它。校正图像本身保留负值，
CV/EE_ROI 没有采用非负截断，只有强度矩权重作非负处理并在代码中显式定义。
本轮没有把中心误差隐去：即使宽度均值改善，质心误差仍高于预定 `1 px`。
EE_ROI 分母保持原 `241×241 px` 采样窗口，不能当作全传感器效率。

原始计数率的 CV 与偏置校正后的 CV 对应不同测量定义，不能将两者误差差值全部归于
展宽改善；精确展宽消融应比较第 4 节相同校正目标下的结果。
对照显示：C 的 CV 对峰宽/目标函数敏感，但 U 的误差没有同步下降，
**当前模型仍不能共同通过均匀度及几何验收**。
原训练相位的 CV 误差本身仍超门槛，说明问题不只是验证集种子变化。
因此继续保持可微整形关闭；没有采集新的优化相位或宣称方形匀化成功。
设备最后在 19:08 恢复平相位并释放连接；没有改变相机位置或关闭激光。

## 5.1 已排除项、剩余假设及下一次实验

本次证据支持：当前采样与像素面积积分变化足够小，不是主要 CV 误差来源；
背景偏置、峰宽与训练目标有实际影响，但这三项还不足以解决问题。
没有把有效高斯展宽当成测得的器件非理想机制，
也没有把训练择优的小幅背景模板系数当成真实零级比例。

补充采集了**同一相位、同一曝光的重复参考**，
C 固定 `3.079 ms`，U 固定 `75.109 ms`，各 3 次、每次 5 张原始帧，全部稳定。
同样固定 ROI 上，每组五帧平均后的 CV 为：

| 分支 / 定义 | 3 次 CV | 均值 ± 样本标准差 |
| --- | --- | --- |
| U / 原计数 | 0.34451 / 0.35787 / 0.36600 | 0.35612 ± 0.01085 |
| U / 仿射截距扣除 | 0.34958 / 0.36297 / 0.37112 | 0.36123 ± 0.01088 |
| C / 原计数 | 1.75053 / 1.74499 / 1.74954 | 1.74835 ± 0.00295 |
| C / 仿射截距扣除 | 1.85096 / 1.84502 / 1.84975 | 1.84858 ± 0.00314 |

这表明固定相位下的短时测量重复性明显好于当前约 `0.09` 的模型 CV 误差；
两者来自不同相位，不能当成正式配对显著性检验，但不支持“全部只是随机测量噪声”。
同时 C 的原计数与校正 CV 相差约 `0.10`，再次说明偏置口径必须明确。
逐张原始帧、每组平均帧的指标均已保存到单独 JSON；原始帧本身仍在数据目录。

本轮曝光扫描中固定 U 的 FWHM 随曝光仍有明显变化，
其可能来自低信号/阈值测量依赖或光斑结构漂移，不能只凭稳定峰值归因。
同时用固定总相位在可用计数范围拍多曝光，检查逐像素响应斜率是否保持空间一致；
当前稳定判据不等同于逐像素光强完全稳定。

下一步可检验独立的相位响应/振幅耦合以及相干零级，
但需要新的探针设计，不能把这些物理项都随意拟合成模糊。
相位响应须复用既有离散器件模型并独立测量；
相干零级须用载波方向/频率和参考相位变化来辨识干涉，
不能仅在强度模型中加入一张固定模板后宣称已排除。
后续各项均保持输入/输出独立保存，并在新模型确定后采新种子验收。
