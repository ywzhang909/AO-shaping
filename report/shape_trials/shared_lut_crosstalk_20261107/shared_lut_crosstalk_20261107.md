## 1. 目标与验收

目标是在 `slm_phase` 旁增加两个默认关闭、零初始化恒等的功能：

1. 以实际加载的整数灰度为索引的 256 级共享 SLM 响应 LUT，带单调约束、可微插值和 2–4 个低频空间基的小系数展开；不做逐像元独立 LUT，也不把灰度当作连续输入交给 1×1 卷积。
2. 与 LUT 参数分离的 3×3/5×5 对称串扰小核，作用于 SLM 面板相位，表达空间耦合而不是值映射。

issue #238 原文验收判据逐项照录如下，后续不得用训练集改善替代这些判据：

> (1) 默认关：所有既有 tests 逐位通过；checkpoint 无 LUT 字段时行为不变。
>
> (2) 单元测试：LUT 单调性（256 级 φ(v) 非降）、双线性插值可微（梯度非零且方向正确）、零初始化恒等、串扰核对称性。
>
> (3) 拟合收敛：在 issue #234 同批数据上 LUT+串扰标定后 train loss 显著下降（预期 ≥10–30%），holdout Z5–Z11 对称 pattern 相关从 <0.5（issue #234 实测）提升到 ≥0.9（median ≥0.95）。
>
> (4) 量化一致性：LUT 输入整数灰度 = 硬件实际加载值，量化-反量化往返误差 = 0。
>
> (5) 消融：LUT-only / 串扰-only / LUT+串扰 三组对比，证明二者正交互补，不互相替代。
>
> (6) 文档：report/shape_trials/ 下标定报告，含 LUT 曲线图、串扰核热图、收敛曲线、消融表。

这些数值是待验证的验收门槛，本文不宣称已达到其中任何一项。

### 2.1 已有的部分

只读检查了 `src/ao_shaping/algorithm/signal_processing/differentiable_defocus_uniformity.py` 及 `physical_forward_fit.py`：

- 当前 SLM 值非线性仍是 `slm_phase_nonlinearity(phi, a, b)` 形式的全局两参数周期修正。它不是 256 灰度索引的共享 LUT，也没有 2–4 个低频空间基的系数展开。
- `FrozenDefocusForward` 和 `PhysicalForwardFit` 已提供可选 `monotonic_ccd_h`，经 `MonotonicResponse` 在观测链末端映射 CCD 响应；其输入域和作用位置属于 **CCD 辐射度响应**，不能当作本 issue 的 SLM 灰度到相位 LUT。
- 因而“模型侧目前无 CCD 响应 LUT”这一背景口径与当前代码不符。准确说法是：**已有可选 CCD 响应 LUT；尚无本 issue 要求的 SLM 共享 LUT 与像素串扰核。**两者必须分开命名、分开标定，避免把传感器非线性误学成 SLM 相位响应。
- 现有辐射度链路保留曝光/黑电平口径；本规划统一采用原生 **counts/ms**，原始 `uint8` 帧与 `exposure_ms` 用于核验换算，禁止逐帧峰值归一化后再拟合响应。

## 4. 逐项探针计划

### 4.1 探针 A：1×1 共享 LUT 的可辨识性

**数据来源**

- 首选三组 issue234 单模屏数据中的 `panel_gray`、正负 Z5–Z11、两个方向的斜坡与重复 pass。
- `defocus_forward_20261107_focus_r2` 的 U/C、参考和斜坡用于补充低频/载波约束，但必须先重建并验证实际整数灰度。
- `20261107_focus_scan` 只固定离焦和曝光背景，不作为灰度 LUT 的独立充分证据。
- 若现有数据的灰度覆盖或空间频率不足，按第 5 节补采全灰度扫描及多载波方向/频率探针。

**方法**

1. 固定数据划分：以方向、模式和 pass 为单位划分标定/验证，验证集方向绝不参与 LUT、空间系数或早停选择。
2. 对每个样本统计实际整数灰度覆盖、每级样本数、空间位置覆盖及时间覆盖；形成“灰度级 × 探针类型”的覆盖矩阵。未覆盖区域只保留恒等/平滑先验，不允许插值结果被解释为实测响应。
3. 在固定几何、离焦、照明幅度和 CCD 辐射度的前提下，构造共享单调 LUT 的残差 Jacobian。导数采用 `softplus(h(v)) + ε`，用参考锚定消除整体尺度任意性；空间低秩项仅使用 2–4 个预先指定的低频基。
4. 对 LUT 参数块做奇异值谱、条件数、参数相关性和按 pass 的 bootstrap/轮廓损失检查；分别比较“共享 LUT”“共享 LUT + 空间低秩”是否获得独立验证收益。
5. 对灰度扫描的局部斜率与离焦、几何 Jacobian 做互相投影，量化可被其他参数解释的部分。只开放条件数受控且验证集方向稳定的参数方向。

**产出**

- 灰度覆盖矩阵和有效激励清单。
- 共享/空间低秩参数的可辨识性报告：奇异值谱、弱方向、跨 pass 稳定性及与离焦/几何的相关矩阵。
- 单调 LUT 曲线、置信区间、未覆盖灰度区标记，以及实际量化—反量化往返日志。
- 若证据不足，产出应是“不开放 LUT/仅开放共享低频方向”的否定结论，而不是补出一条看似完整的曲线。

**判据**

- 所有已估计区间单调非降，插值对 `h(v)` 的梯度经有限差分验证；零参数严格恒等。
- 整数灰度输入与硬件加载值一致，往返误差为 0。
- 参数方向跨振幅、跨 pass 稳定，且在未参与标定的方向上改善；最终必须达到 issue 原文 holdout 对称 pattern 相关 `≥0.9`、`median ≥0.95`，并报告全量分布而非只报最好模式。
- 若验证集方向变差、跨 pass 曲线漂移超出预先设定的噪声区间，或灰度覆盖不足，则 LUT 不开放、不进入联合拟合。

**依赖**

- #235 极性门禁通过，且 `phase_sign` 对载波/倾斜/指令相位的作用域有明确结论。
- 实际量化灰度链路可溯源；几何、配准、离焦及 counts/ms 辐射度基线冻结。
- #237 增益场的参数边界已协调，避免空间低秩项吸收照明幅度误差。

### 4.2 探针 B：从单模屏帧反解串扰核

**数据来源**

- 三组 issue234 单模屏数据：利用相同模式的正负振幅、0.02/0.05/0.10 rad 三档振幅、两个 pass 和保存的 `panel_gray`。
- 已有 x/y 斜坡用于检查核的方向性与配准耦合；issue235 配准扫描只用于敏感性控制。
- 现有低阶模式不足以唯一约束高频核时，补采高频单像元/稀疏像元组、细条纹或棋盘及多方向多频率载波；具体图案须遵守面板安全与采样带宽限制。

**方法**

1. 不在 CCD 图像上直接做盲目反卷积。把候选对称核放在 SLM 面板相位上，经完整前向传播预测 CCD 帧，再以原生 counts/ms 残差反解。
2. 核与 LUT 参数完全分离；从 3×3、零初始化恒等开始，以显式对称参数化减少自由参数。DC 归一化（如核和固定为 1）作为受控消融项，防止核整体尺度与照明增益互相吸收。
3. 先固定 LUT 为恒等、冻结几何/辐射度，只用高空间频率敏感样本估计核；再比较 3×3 与 5×5 的验证集收益。低阶 Z 模式主要作为交叉验证，不单独承担高频核辨识。
4. 对核估计做 pass/振幅留一验证和配准扰动敏感性分析；检查核中心、邻接项及轴向对称项是否稳定，而不是仅看训练 loss。
5. 比较“相位卷积”与错误作用位置（灰度域或 CCD 域）的诊断消融，确认改善来自 issue 指定的物理位置。

**产出**

- 3×3/5×5 候选核、热图、对称参数及跨 pass/振幅不确定度。
- 不同空间频率探针的 Jacobian/敏感度表，以及现有数据不足以约束的核方向清单。
- 配准、离焦和 DC 归一化扰动下的核稳定性表。

**判据**

- 核严格对称、零初始化恒等，默认关闭时基线逐位不变。
- 仅在独立方向/模式上稳定改善才保留；3×3 已足够时不用 5×5 增加过拟合自由度。
- 与 LUT-only、串扰-only、LUT+串扰三组统一数据划分比较；最终沿用 issue 原文 holdout 相关门槛和 train loss 预期改善，不用训练集结果替代验收。
- 若核随配准或 `phase_sign` 口径翻转而显著变化，则判定为混淆未解除，不交付标定核。

**依赖**

- 同探针 A 的极性、配准、离焦、量化灰度和辐射度前提。
- 需要足够的面板高频激励；没有该激励时，只允许给出可辨识性否定结论或待补采清单。

### 4.3 探针 C：LUT 与串扰核的耦合和解耦

**耦合来源**

- LUT 改变局部相位斜率，串扰核改变相邻像元的相位混合；二者都能改变图案方向的远场误差。
- 串扰核 DC 分量、共享 LUT 的整体尺度和照明增益都可改变总效率；空间低秩 LUT 又可能与 #237 增益场共享低频空间方向。
- CCD 响应 LUT 改变强度观测曲线，若与 SLM LUT 同时自由拟合，会把传感器曲率误归因于相位响应。

**解耦策略**

1. **分阶段冻结**：先锁定 CCD 辐射度、照明幅度、几何与极性，以恒等核估计 LUT 的可辨识方向；再冻结 LUT，用高频探针估计串扰核；最后只允许证据充分的参数做小幅联合精修。
2. **专用数据分工**：全灰度/低频探针主要约束 LUT，高频/多方向探针主要约束核；验证集探针不参与任一组参数拟合。
3. **联合可辨识性审计**：计算 `[LUT, 空间低秩, 串扰核, 增益场]` 的块相关矩阵与联合奇异值谱。对近零奇异方向不逐项给“精确值”，而应收缩、固定或合并先验。
4. **正交化与尺度锚定**：固定核的尺度约定和 LUT 参考点；#237 增益场与空间 LUT 不同时自由开放，或先从参数子空间中剔除共同低频方向。
5. **四组对照**：baseline、LUT-only、串扰-only、LUT+串扰使用相同样本、相同辐射度与训练预算；比较独立方向误差、参数稳定性和总参数量，验证是否真正互补。

**产出**

- 分阶段与联合拟合的参数轨迹、块相关矩阵和消融表。
- 每个参数的“开放/冻结/拒绝”决定及对应数据证据。

**判据**

- 联合组不能仅靠牺牲验证集方向或另一参数块的物理一致性换得训练 loss 降低。
- 参数在跨 pass/振幅下稳定，联合组相对单模块组有独立验证增益；否则退回更简单的分阶段模型。
- 默认关闭和零初始化恒等始终不受影响。

**依赖**

- 探针 A/B 的独立可辨识性结论、#237 参数边界以及 #235 门禁结论。

2. **`phase_sign` 作用域未解**：载波、倾斜与指令相位究竟哪些随 `phase_sign` 变化尚未定论。该符号会改变方向导数与 Jacobian，**响应 LUT 的拟合必须在作用域问题解决后重跑**；串扰核也需做同样复验，不能沿用旧参数。
3. **现有数据的可辨识性不足**：低阶 Z5–Z11 对高频串扰不敏感，单模振幅变化也不等于全灰度覆盖。可能得到“现有数据只能约束少数方向”的结论。
4. **与 #237 增益场重叠**：共享 LUT 的整体尺度、串扰核 DC、空间低秩响应和照明增益场均可能解释效率/低频误差。需固定或正交化参数，并明确哪一侧负责哪种物理量。
5. **CCD LUT 与 SLM LUT 混淆**：代码已有 CCD `MonotonicResponse`。两者若同时开放会产生强度—相位归因歧义；应先冻结并独立校验 CCD 辐射度，再拟合 SLM LUT。
6. **配准、离焦和采样混淆**：全局位移、离焦、CCD 像素积分与对称串扰核可能产生相似的方向相关残差；必须做配准扰动和独立方向验证。
7. **灰度量化前提未闭合**：focus_r2 样本没有直接保存 `panel_gray`，而 issue 要求 LUT 输入严格等于硬件实际加载整数灰度。重建值未经链路核验前不能用于量化一致性验收。
8. **温漂和重复性**：多批数据采集时间不同，共享 LUT 的空间项可能吸收时间漂移。需用重复参考和跨 pass 稳定性区分真实空间响应与时间变化。
9. **验收基线风险**：issue 的预期 train loss 改善为 ≥10–30%，它是原文预期而非预先保证；若未达到，应如实报告并检查可辨识性，不能通过放宽验证集或重复归一化制造改善。
