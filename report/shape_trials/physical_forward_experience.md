## 1. 一句话结论

物理预测模型在**结构相关性**上能做得很好（验证集中位相关性可达 0.88–0.96），但在
**均匀度（CV）/能量效率（EE）的绝对误差**上始终过不了门槛；诊断表明主要误差不是
采样/像素积分，也不是随机测量噪声，而是强度标定与相位族覆盖问题。相关性通过从未
转化为可微整形准入，最终这条"靠可微物理预测模型驱动逆向整形"的路径被放弃，能力被
收拢到当前保留的实验系统标定与 transfer 路径。

## 2. 历史证据（已实测 / 已判定）

### 2.1 主动离焦与 U/C 配对采集（2026-10-22，历史实测）

真实 Santec #1 + Daheng、1064 nm、全帧 2592×1944；U（未补偿离焦）/ C（叠加菲涅尔
二次相位补偿）配对采集 38 组，全部通过 `stable_tol=0.05`，曝光 2.397–88.652 ms。
低参数物理预测模型（9–16 个共享参数）在固定 CCD 网格上：

| 模型/分支 | 平均相关性 | 中位相关性 | 最低相关性 | CV 绝对误差均值 | EE_ROI 绝对误差均值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| M0 / U | 0.2122 | 0.1735 | 0.0886 | 0.2597 | 0.0715 |
| M0 / C | 0.3473 | 0.3689 | 0.2073 | 0.9914 | 0.4049 |
| M4 / U（最佳） | **0.8856** | **0.9005** | **0.7951** | 0.0732 | 0.0334 |
| M4 / C（最佳） | **0.9474** | **0.9544** | **0.9185** | 0.2437 | 0.0590 |

- 全新种子冻结参数检验中 M4 三类相关性中位：U 为 0.9008/0.9129/0.8432，C 为
  0.9657/0.9223/0.9544。**两分支通过拟定相关性门槛，但 CV 未通过 0.05 门槛**，
  C 的 EE_ROI 也未通过：M4 在 U 的实测/预测 CV 均值 0.6030/0.5745，C 为
  1.1947/1.4384；C 被系统性预测得偏尖锐。
- **决策（历史）**：本轮没有进入可微相位整形，也没有产生新的方形匀化成功结果；不是
  继续放宽相关性阈值，而是先解决 CV 预测偏差。

### 2.2 采样、像素积分与曝光偏置诊断（2026-10-22 第二阶段，历史实测）

- **传播采样与 CCD 像素面积积分不是 CV 误差主要来源**：输入网格 128/256/512、FFT
  512–4096、3×3 面积积分的全部组合下，预测图相对 L2 差中位 **≤0.7%**，CV 误差均值
  变化 **<0.004**，远小于 C 分支约 **0.24** 的 CV 偏差。
- **曝光偏置有实际影响但不能单独解决 CV**：未遮光条件下逐像素仿射截距 50% 分位
  **0.470 counts**，不可当纯电子暗本底；约 10.85% 像素校正强度为负，完整落盘而非
  截断归零，否则偏置误差会被掩盖成"改善"。
- **峰宽只能部分解释**：最优单分量等效高斯展宽约 σ=2 px，但对峰宽敏感的 C 与对
  结构敏感的 U 不能用同一展宽参数同时满足；非相干本底模板几乎无额外改善。
- **联合目标改善但未达门槛**：训练 CV 平方误差 **0.02558 → 0.00738**，后采 C 相关性
  升到 0.9611；但 U/C 的 CV 绝对误差 **0.0975 / 0.0888**、质心误差 **7.68 / 4.64 px**
  仍超过 **0.05 / 1 px** 门槛，可微整形准入维持**不通过**。
- **测量重复性显著优于模型误差**：固定相位固定曝光短时重复 CV 约
  **0.356 ± 0.011（U）/ 1.748 ± 0.003（C）**，比模型 CV 误差小一个量级，不支持
  "剩余误差主要是随机测量噪声"。由此确立"先立噪声地板、再归因模型误差"的纪律。

### 2.3 相机移位后的泛化判别（2026-10-19，历史实测）

新几何下标准相位族（平滑+Zernike）验证集相关性约 0.78–0.87，但**全频随机相位**仅
约 0.108–0.277（详见总述 §2.4）。可达上限判别显示全频族在相机窗内支撑仅 7.91%、
支撑内能量 10.68%、理论上限约 0.477——该族在相机窗内本就不可观测，**不是可由
迁移学习/振幅模型修补的缺陷**。迁移/振幅修补的尝试表现为典型过拟合
（全频族 0.118→0.129、0.108→0.105）。

## 3. 当时的计划 / 设想（从未成为测量结论）

> 以下均为历史规划文件内容，**不是已验证事实**，仅说明当时为何继续探索并最终放弃。

- **主动离焦调优方案（2026-10-22 计划）**：曾设想在相机主动离焦位置以学习当前观测面
  传播为主目标、SLM 聚焦补偿为对照，用原始逐帧统计避开历史摘要中的阶数/噪声口径问题。
  其中"历史补偿焦距约 1523.8 mm、FWHM 约 115→15 px"等数字来自更早会话，**不可直接
  假定适用于当前相机位置**。
- **无 GS 起点方案（2026-10-27 计划）**：曾设想只用平面/低频随机相位起点、分层指标、
  局部响应校正、同曝光 CCD 验收与缓漂适配。其中"平面起始三角形 CV 0.6632→0.5967、
  接受 3/4"、"冷启动相关性 0.8471→0.9127 但 CV 绝对误差 0.6434→0.8995 恶化"等为
  **该计划引用的历史观察**，用来说明"相关性不能单独作为模型选择标准"，不是本计划
  新增测量。

## 4. 放弃路径的收束

结构相关性高但 CV/EE 不过门槛、误差非采样非噪声、全频相位族在相机窗内不可观测——
三点共同否定了"靠可微物理预测模型直接驱动逆向整形"的可行性。当前保留的是不依赖该
闭环的实验系统几何定位、标定与 transfer 路径。历史数字仅为归档证据；不得用现已移除的
脚本或已删除的中间明细报告声称可复现。
