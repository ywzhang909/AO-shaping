## 1. 目的与本次范围

目标是在相机保持当前离焦位置的条件下，验证现有最佳物理正向模型给出的相位更新
能否降低真实 CCD 方形目标区域的 CV。此次仅分析历史报告、检查实现并制定方案，
没有连接设备、加载相位或产生新实验数据。

沿用用户明确提出的探索性测试要求：历史模型的 CV、中心误差准入门槛不再阻止
本次短时可微测试。历史误差保留报告，不降低或改写成通过；候选相位是否采用，
由当次同曝光、同区域的 CCD 配对测量决定。设备占用、画面截断、饱和和异常
仍按正常采集流程处理。

首轮优先做 C 分支：SLM 叠加聚焦补偿，在当前 CCD 平面整形；之后有时间再做
U 分支：不预叠聚焦补偿，由包含离焦的模型直接合成同一 CCD 平面的方形光斑。
两条分支都不移动相机。每个分支首先与自己的 GS/已有方形相位初值比较，
不把 U/C 初始光斑差异记为可微细化收益。

| 证据 | 可使用的结论 | 本方案的处理 |

| 随机初值、全图峰值归一化 MSE，200 次模型迭代：损失约 `0.010708 → 0.000929`，未形成目标结构 | 当前初值和损失组合会产生无效解 | 使用已有方形相位或 GS 初值；固定信号区目标，CV 为主要指标 |

| 既有带宽下 FFT/输入网格加密及 CCD 像素积分变化很小 | 不是这批低带宽探针主要 CV 偏差来源 | 首轮不重复全套网格扫描；新增可学习相位必须另做带宽一致性检查 |

以下解释不能直接沿用为物理结论：

1. `31²/1024² = 9.16481e-04` 是低信号目标区可能出现的损失尺度，
   **不是普遍的理论下界**。预测恰好匹配目标时该 MSE 可为零；非零有限能量
   条件下还存在区外残差。旧报告中“不可达下界”的表述不能用作收敛证据。
2. 两次相位各自的 raw RMS 接近，不意味着两次相位相同。
   应计算去 piston 后的相位差和圆周相位差，另报告相邻像素的圆周梯度。
3. `DifferentiableBeamOptimizer.update(measured_intensity=...)` 计算的是
   `J_model.T @ grad_I L(I_CCD)`。它是模型给出的近似实验更新，
   没有测得真实光路 Jacobian。旧 5 步下降不能证明所有方向可靠。
4. 单次低相关性不能证明全由随机初值导致，也不能排除轴映射、偏心二次相位、
   光轴和相位响应的影响。有限宽度差不能证明某类模型误差“不可消除”。
5. 过程动画复算的最大相对偏差 `1.06e-07` 与相位差 `6.29e-05 rad`
   支持数值近似复现，不属于逐位相同。缺失的第二步 CCD 帧不能补造。

## 3. 正向模型、总相位与坐标

起始候选采用 `uniformity_refit_20261022_r1/` 中训练目标选出的冻结检查点。
如果 `fit_forward_sampling_variants.py` 的已有结果提供更好的候选，必须按预先
记录的训练/开发验证选择规则选取，保存确切 JSON、参数和 SHA256；不能只因某个
历史测试分支 CV 较低而替换。历史测试集已经参与诊断，本次另采新局部相位验证。

沿用现有离焦物理模型的坐标、输入振幅、共享像差、增益、加性背景（杂散光）项
及有效强度展宽；有效展宽只是经验偏差项，不称为独立测得的器件 PSF。
输入振幅、几何及模型参数在每个优化块内冻结，避免同时变化造成不可解释结果。

总相位明确定义为：

```text
phi_panel = phi_seed + delta_phi + phi_focus(branch) + phi_carrier(optional)
I_pred = detector_model(propagate(A * exp(i * (phi_panel + phi_aberration))))
```

离焦项可以在传播算子内，也可以用已验证的等效瞳面二次相位表示，但只计一次。
C 的 `phi_focus` 是控制输入，不能同时从拟合像差删除又额外反向抵消；U 为零。
不要把历史最佳 `0.5606821133007323 / 0.611 / 0.6666666666666666 m⁻¹`
视作当前固定参数，它们来自不同会话。补偿中心偏移会产生倾斜，需实测位置并纳入模型。

面板相位始终使用未包裹弧度，仅在驱动规定入口包裹。复用规范 Zernike 工具，
不增加第二份 Noll 查表或多项式生成器。
历史 128 网格的物理基函数中心为 `952.5 panel px`；不能将其直接改成 `960`
后复用旧系数。加密时保持物理区域、相位插值和绝对强度尺度不变。

首轮采用原 128 控制网格上的平滑残差，例如 `16×16` 可学习控制点，
经固定插值算子映射至模型和面板；传播基准从已审计的 256/2048 配置开始。
对初值、最终候选各用更密网格离线复算一次。若 CV 变化明显或方向反转，
收紧控制带宽后再测试，不将旧低阶探针收敛性外推至任意像素相位图。
预测必须通过同一面板下发算子；保存最终全分辨率相位，避免模型优化一张相位、
设备实际显示另一张。

## 4. 目标、均匀度与曝光

首轮方形边长拟定 `60 CCD px`，仅当当前视场足以完整容纳时使用。
目标中心、像素掩膜及评估窗口在优化前确定并冻结，不随每帧亮点重新定位。
保存完整方框及向内收缩 `3 px` 的内部区域两套 CV，内部 CV 为主要排序指标，
完整方框 CV 说明边缘影响。另记录均值、标准差、EE_ROI、质心及饱和像素数。
EE_ROI 使用固定 `241×241 CCD px` 窗口作分母，不能称全传感器衍射效率。

若零级与信号重合，同时报告完整指标和剔零级指标；零级掩膜用独立参考识别后冻结，
不能每帧将最亮或最不均匀部分自动剔除。若使用载波，先用纯载波确定目标级次、
方向与位置，零级掩膜、目标位置及模型同步变化；首轮不同时优化载波参数。

自动曝光用于找到适合当前光路的曝光，再锁定一个配对测量块。
相机增益、像素格式、黑电平、gamma 和自动处理状态均记录并在块内固定。
曝光边界读取设备和当前环境配置，不沿用历史 `0.4 / 0.6 / 200 ms` 为永久上限。
若候选饱和或过暗，重新选择曝光，并在新曝光下重测该块全部参考和候选。
短曝光响应未独立标定前，不只用 `counts/ms` 连接不同曝光档的结果。
带光仿射截距不是暗场；原始 counts 必须保留，校正结果另存且不裁负。
若该截距在当前状态没有验证，原 counts CV 作为主要同曝光指标，校正 CV 作敏感性分析。

## 5. 优化目标与步长

使用固定掩膜内的均匀度目标，避免全图背景面积主导损失：

```text
mu = mean(I[mask_core])
L_cv = mean((I[mask_core] / (mu + eps) - 1)**2)
L = L_cv + w_shape * L_shape + w_phase * L_phase
L_phase = mean(1 - cos(neighbor_difference(delta_phi)))
```

`L_shape` 在目标边缘的固定过渡区约束方形轮廓；其权重单独记录。
首轮固定 `w_shape=0`，只测试已有方形光斑的匀化；轮廓、均值和 EE_ROI 仍报告。
`w_phase` 拟定 `0.01`，不在实验中同时扫描多个权重。
若目标均值不高于重复参考所给出的可分辨信号，则标为无效，不能将无光区域的
低 CV 当成成功。首轮不以 EE 最大化排序；须同时报告任何能量损失。

相位残差去 piston，去除与固定定位冲突的整体倾斜；首轮不释放补偿焦度。
块内最多 `10` 次 Adam 更新，学习率拟定 `0.01`，每次保存模型预测和梯度。
相对已接受相位的照明加权 RMS 增量先限 `0.10 rad`，而非限制所有控制点 L2
为固定常数。单纯降低相位梯度能否改善均匀度可作为独立消融，不能同时归入可微收益。

测量锚定时，模型预测、CCD 校正图像及上游梯度必须处于同一单位与坐标，
不能把 counts 梯度直接施加到未标定的无量纲强度。实现时必须使用同一完整模型
的 Jacobian，不能计算损失时用拟合模型、反传时退回理想 FFT。

## 6. 首轮设备测试协议

本表是拟执行协议，所有步数和预算为计划值，不是已完成的测量。

| 阶段 | 操作与数据 | 决策 |
| --- | --- | --- |
| A，约 3–5 分钟 | 获取设备互斥占用；平相位参考；按已有缓存加局部探测确认照明中心、焦度、CCD 坐标和曝光；正负 x/y 倾斜独立确定轴映射 | 有光且目标完整可测即可探索；不因模型 CV 历史误差自动退出 |
| B，约 2–3 分钟 | C 下重放已有方形相位及新 GS 初值，各 `3` 组，每组 `5` 原始帧；记录 2 次初值间切换的重现性 | 按固定内部 CV 选初值；记录信号均值、能量与轮廓，平相位仅作参考 |
| C，约 2–3 分钟 | 计算初值处模型下降方向，归一至照明加权 RMS `0.03 rad`；以初值 A、正方向 B+、初值 A、反方向 B−、初值 A 采集，每点 `5` 帧 | 比较正负 CCD CV 差及重复参考漂移；不将模型下降当作实验下降 |
| D，约 3–5 分钟 | 最多 `5` 个块、每块 `10` 模型更新；候选逐块按 A-B-B-A 重放，每点 `5` 帧；保留拒绝候选 | 只有实测改善超过当次噪声/漂移分辨率才接受；失败收缩 RMS 上限至一半，不盲目累积更新 |
| E，约 2 分钟 | 冻结最优相位；初值与最优 A-B-B-A 完整重复 `3` 次，各点 `5` 帧；这批新帧不再用于调参 | 给出配对 CV 差、均值、重复性及所有附加指标，结束后释放设备 |

主结果是 C 的一组完整“初值—优化—独立重放”数据。时间允许时用相同协议补 U，
两者分开报告。预算不足时结束 C 后释放设备，不为补齐 U 长时间占用。
最小 C 数据集的 E 阶段为 `60` 张原始帧；它不包含探测、初值与优化过程帧。

若方向检验无效，仍保存正负候选与实验结果，缩小步长复核一次；仍不改善则结束，
这就是一组有效的负结果。连续 `2` 个优化块未获可分辨改善即停，不增加迭代数。
保留初值和历史最佳相位，禁止在失败候选上继续无条件更新。
初值/候选的漂移超过本次参考重复性时，该块标为不可比较并重测一次；继续漂移则结束。
相位重放结束后先恢复约定平相位、清除临时叠加，再关闭相机和 SLM，释放互斥锁。
异常路径也执行关闭；若 SDK 超时导致无法确认释放，明确记录未确认状态。

## 7. 数据契约与统计

新数据建议放 `data/debug/defocus_differentiable/<本地时间戳>/`，不覆盖历史目录。
每次采集保存原始帧堆栈、平均帧、指令总相位、实际下发灰度（若可得）、
曝光读回、稳定判决、固定掩膜、相机参数及模型版本。
`iterations.pkl` 每条含 `iteration/block/branch/accepted`、完整参数、预测图、
梯度范数、增量 RMS、圆周梯度、损失各分量、候选/基准 CV、源数据路径、
UTC 微秒格式时间戳及 `perf_counter_ns` 起止；帧时间、显示时间和优化时间分别记录。
时间戳格式精度不等于相机触发同步精度。即使中止也保留已完成记录和异常说明。

每块参考重复计算的噪声和漂移用于接受判断，建议最低可分辨改善取当次配对差
不确定度的 `3` 倍，估计方法及小样本限制一并保存。
最终报告原始配对 CV 差及相对改善，不只报最佳一张图。
最终仅 `3` 组重放不足以宣称显著性或跨光路泛化；若后续扩展样本，统计复用
`src/ml/zernike/eval_stats.py`，不复制第二套置换检验。
逐文件生成大小与 SHA256 清单，拒绝候选、超时数据和未经校正帧同样保留。

## 11. 执行修订（2026-10-23，依据可微优化主报告的 GS 初值轮）

主报告 [`../slm/differentiable_opt/differentiable_opt_report.md`](../slm/differentiable_opt/differentiable_opt_report.md)
在 §10 记下了一条**只换初值就翻盘**的实测：同一实验系统、同一目标，随机初值轮的
模型↔硬件强度相关系数 0.11–0.15，GS 初值轮 **0.810**。以下修订全部由它（及该轮其余
数字）推出，不改变 §3–§5 的口径，只收紧**执行顺序与判定**。

| # | 修订 | 依据 |
|---|---|---|
| 11.1 | **初值必须是解析整形解**；GS 与存档方相位之间只按事先写死的固定内部 CV 规则择优，禁止事后挑选；初值与检查点都记 SHA256 | 只换初值，相关 0.15 → 0.810 |
