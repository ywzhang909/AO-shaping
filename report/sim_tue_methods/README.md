## 0. 一句话

在本仓库 64×64 可微仿真（CPU，无硬件）上定量复现了 TU/e 的四项能力：系统松弛的「正向收益」在本实验系统的前向模型上**未迁移**（噪声只单调抬高相位高频 rms，过注入劣化验证集形状，反向验证成立），混合拟合中 15 项 Zernike 结构叠在逐像素 freeform 上**不改变最终远场**（joint 与 per-pixel-only 数值相同，低阶结构被 freeform 吞并），样本查询与不确定性采样定量证实了**塌缩机制**（无约束梯度最大化不确定度把选样范数推到域外 2.6 倍、两两距离一个量级以上，逐分量盒拦不住）但在 24 查询预算下**未优于盲采样**；「低参数 vs 深度」一项由论文 5.4 节 24+30 张实测帧的同帧对照（物理模型 0.81 至 0.84，U-Net 近零）已更强地覆盖，无需另跑仿真。

## 1. 为什么用本仓库仿真 + 实验对照

TU/e 的可微物理仿真与本文 MIL 闭环物理同构（单色激光经 LCOS SLM 加载相位、2f 傅里叶面相机记录远场强度、由远场反演/优化 SLM 相位），见论文 7.6 节逐项对照。但 7.6 节此前只是「交叉对照」，未用本仓库的 ML 仿真把这些方法跑出来。本目录补齐定量证据，并回答两个 7.6 节遗留的问题：

- TU/e 在纯仿真域内的「系统松弛收益」「混合拟合可造任意形状」，在**本实验系统的前向模型 + 器件带宽约束**下是否成立？
- 仿真结论与实测的定量差距有多大（能否把仿真当实验的离线代理）？

后者由 `report/shape_trials/gs_refine_fwdmodel/gs_refine_fwdmodel_calibration.md` 的实验标定回答（见第 6 节）。

## 2. T1 系统松弛 A/B（对应 #124 / R-83）

**协议**：在 `shape_phase_with_frozen_aberration` 的 Step B Adam 循环内，每 `noise_inject_every=5` 步向演化中的 SLM 相位注入零均值高斯瞳面噪声（幅度 `sigma` rad，经 `StepBConfig.noise_inject_every` / `noise_sigma_rad` 两个**默认关闭**字段控制，无噪时与原路径逐位不变）。对照组冻结一个与真值不一致的 12 模 Zernike 像差（Noll 4 至 15、0.5 rad RMS），逐像素相位朝该错模型优化；最终在**真值像差**下实测远场，报 CV / EE / 复合分数 / 相位高频 rms。5 个种子。

**结果**（`region=64`、`iters=200`、`lr=0.05`、`w=0.4/0.6`、`inject_every=5`；`results/t1_noise_relaxation.json`）：

| 臂 | sigma (rad) | CV | EE | 复合分数 | 高频 rms |
|---|---:|---:|---:|---:|---:|
| 错模型（与 Step A 估计不一致） | 0.00 | 1.2837 | 0.6713 | 0.5610 | 0.7732 |
| | 0.10 | 1.2587 | 0.6591 | 0.5579 | 0.7758 |
| | 0.20 | 1.2803 | 0.6236 | 0.5355 | 0.8400 |
| | 0.30 | 1.3108 | 0.5428 | 0.4922 | 1.0338 |
| | 0.50 | 1.4258 | 0.2974 | 0.3595 | 1.9828 |
| 对模型（与 Step A 一致） | 0.00 | 0.1639 | 0.6867 | 0.7857 | 0.7711 |
| | 0.10 | 0.1419 | 0.6957 | 0.7904 | 0.7808 |
| | 0.20 | 0.2760 | 0.5996 | 0.7085 | 0.8816 |
| | 0.30 | 0.3542 | 0.5058 | 0.6319 | 1.0932 |
| | 0.50 | 0.4182 | 0.3054 | 0.5057 | 2.0595 |

**结论**（如实报告，不硬凑正向）：

- **反向验证成立**：sigma 由 0.3 提到 0.5，两臂复合分数均明显劣化（错模型 0.492 至 0.360、对模型 0.632 至 0.506），EE 从约 0.5 跌到约 0.30，确认噪声通道是真实作用的、而非常数。
- **正向「松弛收益」未迁移**：在错模型侧，sigma 从 0 到 0.5，复合分数单调下降（0.561 至 0.360），逐像素噪声**只抬高相位高频 rms**（0.77 到 2.0），并未如 TU/e 所述提高验证集形状拟合精度。在对模型侧，仅 sigma=0.10 有 +0.005 的边际改善（0.786 至 0.790），sigma 再大即劣化。
- **解读**：TU/e 的正向收益发生在其仿真域内（噪声注入的对象是仿真器自身，且其像差为 12 项 Zernike、无器件低通）；本实验系统前向模型里逐像素自由度受器件带宽低通（论文 7.4 节），噪声能量优先落在高频、被面板强烈低通，转化为远场散斑而非鲁棒性。故「系统松弛」在本仓库仿真里是**边界条件结论**：通道存在、反向可验，但正向收益取决于噪声能量是否落在可测带宽内，在本 64×64 前向模型上未迁移。这与论文 7.4 节「自由度必须截断在可测带宽内」一致。

## 3. T2 混合拟合（对应 #126 / R-84）

**协议**：参数空间 = Zernike（Noll≤15，15 项）低阶结构 + 逐像素 freeform，线性叠加进可微前向，与目标形状（三角形 / 五角星）做损失（0.4·CV 项 + 0.6·(1−EE) 项），梯度下降同时更新两组参数；真值像差 A（0.5 rad RMS）在优化与最终实测时均在场（与真实 model-in-loop「Step A 拟合 A、Step B 在 A 下优化」一致）。三臂对照（同一 A、同一目标、300 步预算）：`zernike_only`（仅 15 项 Zernike）、`perpixel_only`（仅逐像素，现 Step B 架构）、`joint`（两者联合，记录全程最佳 epoch）。3 个种子。

**结果**（`region=64`、`iters=300`、`lr=0.05`、`target_side=16`；`results/t2_mixed_fitting.json`）：

| 形状 | 臂 | CV | EE | 复合分数 | 最佳 epoch |
|---|---|---:|---:|---:|---:|
| 三角形 | zernike_only | 1.6946 | 0.9144 | 0.6429 | — |
| | perpixel_only | 1.4880 | 0.8323 | 0.6174 | — |
| | joint | 1.4880 | 0.8323 | 0.6174 | 292.7 |
| 五角星 | zernike_only | 1.7453 | 0.9352 | 0.6500 | — |
| | perpixel_only | 1.4253 | 0.8369 | 0.6247 | — |
| | joint | 1.4253 | 0.8369 | 0.6247 | 297.3 |

**结论**：

- **joint 与 perpixel_only 数值相同**（4 位小数一致）：在 15 项 Zernike 之上叠逐像素 freeform，低阶 Zernike 参数被 freeform 完全吞并（freeform 是 Zernike 的超集），联合优化不产生比冻结逐像素更好的远场。这与 TU/e「混合 CGH 造任意形状」的差异在于自由度预算：TU/e 全程仿真域、逐像素无成本；本 64×64 仿真里 15 项低阶结构相对 4096 个逐像素自由度不构成约束，故叠加无增益。
- **zernike_only 复合分数反而更高**：因为它 EE 高（0.91 至 0.94）而 CV 高（1.7），复合分数 0.5·EE + 0.5/(1+CV) 里 EE 占优。这说明 15 项 Zernike 做不出三角形 / 五角星的均匀结构（CV 1.7，远大于 freeform 的 1.4 至 1.49），但能给出更高能量占比的紧凑斑——验证了「15 项 Zernike 表达力不足以成形，必须靠逐像素 freeform」的结构性缺口。
- **最佳 epoch 落在长平台末端的跳变点**：joint 的最佳 epoch 在 300 步中落在 292 至 297，即收敛形态是长平台 + 末期跳变，与 TU/e「米老鼠头约 400 轮后突然跳变出现」同构。这印证论文 7.6 节的观察：联合拟合应报**全程最佳**而非末轮。

## 4. T3 低参数 vs 深度（论文 5.4 的对照，由实验数据覆盖）

issue 原计划用仿真在 2 至 8 张探针下复现「低参数在小样本下更稳」。但论文 5.4 节已用**实测**更强地覆盖该问题，无需另跑仿真：

- **5.4.2（24 张同帧验证集）**：物理 Zernike+NNLS 同帧相关性 0.839（平滑 / Zernike / 全频随机相位三族），而 121,177 参数 U-Net 预训练 0.018±0.053、10 步微调 0.030±0.041，EE 仅 0.16（近零相关、低信息平坦预测）。
- **5.4.3（五形状 30 张验证集帧 + 5 张成形）**：物理 Zernike 30 张验证集帧相关性 0.8294、5 张成形 0.8040；U-Net 冻结 −0.0420 至 0.0401、两探针微调 −0.0401 至 0.0403，EE 仅 0.06 至 0.08。
- **参数量对照**：约 70 参数的闭式物理模型（66 项 Zernike + 非负增益 + 加性背景项）在 2 至 8 张探针下稳定 0.81 至 0.84；121,177 参数小样本 U-Net 与 7,778,465 参数完整 U-Net 均未能在同帧对照中超过物理模型。

**结论**：在真实光路、极小样本（单轮 2 至 8 张探针）下，低参数闭式物理前向的验证集相关性显著优于同规模或更重的 U-Net，且物理模型的泛化边界（Zernike 基不足）更可预期。仿真复现只会比实验证据更弱（仿真正向模型按构造精确），故 T3 直接引用 5.4 实验数据，不新增仿真表。

## 5. T4 样本查询 / 不确定性采样（主动学习，对应论文 7.6 能力四）

**协议**：在 model-in-the-loop 可微仿真上复现 TU/e 的第四类能力。参数域 12 维 Zernike（Noll 4 至 15），可微前向用 64×64 的 `interpolated_pupil_intensity`（前向约 27 ms，端到端可微）；逆模型为 3 个独立训练的小 CNN 集成（每个 398,028 参数，32×32 远场强度到 12 维系数），认知不确定性 U(c) 取集成预测方差（对 c 可微）。主动学习环：3 轮、每轮选 8 个样本并入训练集、重训 12 epochs、在固定 64 个验证集样本（域半径 0.8 rad）上测系数 RMSE；初始集 300 个分布内样本（半径 0.3 rad），初始验证集 RMSE 0.9512。三臂对照：`random`（域内盲采样 1000 个再挑最不确定的 8 个，TU/e 所称传统做法）、`uncertainty_boxed`（梯度下降最大化 U(c)，40 步 × 8 起点，每步逐分量盒 |c_i|≤0.8 投影）、`uncertainty_unconstrained`（同搜索、不加幅值约束，范数以 6.0 为停止上限以暴露塌缩）。

**结果**（`results/t4_uncertainty_sampling.json`，三臂各从同种子初始集成出发，避免跨臂污染）：

| 臂 | 轮 | 累计查询 | 验证集 RMSE | 选样范数（均值/最大） | 选样两两距离 | 触界数 |
|---|---:|---:|---:|---:|---:|---:|
| random（盲采样） | 1 | 8 | 0.1922 | 0.222 / 0.243 | 0.294 | 0 |
| | 2 | 16 | 0.2037 | 0.222 / 0.242 | 0.295 | 0 |
| | 3 | 24 | 0.1553 | 0.233 / 0.282 | 0.274 | 0 |
| uncertainty_boxed（逐分量盒 0.8） | 1 | 8 | 0.1910 | 2.129 / 2.308 | 3.002 | 8 |
| | 2 | 16 | 0.2026 | 1.726 / 1.957 | 2.506 | 8 |
| | 3 | 24 | 0.1555 | 1.669 / 1.971 | 2.450 | 8 |
| uncertainty_unconstrained（无幅值约束） | 1 | 8 | 0.1922 | 2.140 / 2.346 | 2.928 | 0 |
| | 2 | 16 | 0.1974 | 1.727 / 1.924 | 2.299 | 0 |
| | 3 | 24 | 0.1618 | 1.622 / 1.779 | 2.201 | 0 |

**结论**（如实报告，不硬凑正向）：

- **塌缩机制定量成立**：梯度搜索两臂（boxed、unconstrained）把选样范数从 random 臂的约 0.22 rad 推到 1.6 至 2.3 rad（域半径 0.8 的 2.6 倍），选样两两距离 2.2 至 3.0（random 臂 0.27 至 0.29 的一个量级以上）——即 TU/e 所警告的「不加约束最大化不确定度会把参数推向极端、数据集塌缩」的定量复现。逐分量盒在 12 维下合成范数上限约 2.77 rad（0.8×√12），拦不住范数膨胀（boxed 臂每轮 8 个选样全部触界），印证 TU/e 必须另施加包围盒、最大重叠数等更强的几何约束。
- **24 查询预算下收益未迁移**：三臂第 3 轮验证集 RMSE 为 0.155 / 0.156 / 0.162，无显著差异。在 12 维平滑 Zernike 域 + 3 成员集成、每轮 8 查询的预算下，不确定性采样未优于盲采样。与 T1 同一风格的诚实边界结论：机制成立，收益未迁移。
- **反向验证成立**：最小化 U(c)（3.6 s）从域边界起点（范数 0.75）收敛到范数 0.080（低幅值、分布内样本），与 TU/e「最小化确信度会让物体消失」一致。

**与 TU/e 的边界差异**：TU/e 的参数域是无界物体位姿/尺寸（位置可全部叠到一起、尺寸可推到最大），本实验是 12 维有界 Zernike 幅值域，塌缩表现为范数膨胀而非物体堆叠；其域上不确定性采样的收益空间也远大于本 12 维域，故本实验定位为机制复现与约束工程验证，而非收益复现。

## 6. 实验与仿真的定量对照（为什么仿真可信 / 不可信）

上述 T1/T2/T4 仿真与本实验系统正向模型的关系，由 `report/shape_trials/gs_refine_fwdmodel/gs_refine_fwdmodel_calibration.md` 的实验标定定量回答（2026-10-13，Santec SLM #1 22030108、Daheng CCD，1064 nm 实际光路，3 个 run × 平场 / GS）：

| run | 相位 | FWHM 实测/仿真 (px) | EE50 实测/仿真 | 远场相关 |
|---|---|---:|---|---:|
| `20261012_175810` | flat | 12.0 / 11.0 | 9.2 / 5.8 | +0.9526 |
| `20261012_175810` | GS | 89.0 / 91.0 | 35.5 / 38.5 | +0.8154 |
| `20261012_175929` | flat | 12.0 / 10.0 | 9.1 / 5.1 | +0.9528 |
| `20261012_175929` | GS | 82.0 / 94.0 | 39.1 / 38.3 | +0.7976 |
| `20261012_180222` | flat | 12.0 / 11.0 | 9.2 / 5.8 | +0.9276 |
| `20261012_180222` | GS | 92.0 / 93.0 | 36.1 / 40.0 | +0.7531 |

**关键数字**：接入实验系统正向模型 + 相机像元标定后，实测远场 vs 仿真远场相关 **平场 +0.944、GS +0.789（整体 +0.867）**；尺度（FWHM）与方形结构一致，但 EE50 仿真偏高（仿真铺得更开，实测对比度更高），CV 仿真系统性偏低约 36%（理想圆瞳做出的方斑内部散斑比实测更均匀）。

**对 T1/T2/T4 的含义**：本 64×64 仿真继承同一正向模型，可作为实验的**几何检查离线代理**（尺度、对称性、形状、左右上下转置），但**不可用于预测 CV/PIB 的绝对值**——CV 绝对值系统性偏低约 36%、EE50 偏高。因此 T1 的「系统松弛未迁移」、T2 的「joint 无增益」与 T4 的「不确定性采样 24 查询预算下未优于盲采样」结论应读作**边界条件 / 结构性结论**（方向与趋势可信），而**非**对实测绝对整形指标的预测；实验侧的最终验收必须走交错重放 + 验证集（论文 8 节）。

**两个被实验证伪的解释**（`gs_refine_fwdmodel_calibration.md` 第 3 节）：残差不是远场中心没对齐（全在 2 px 内），也不是径向低通 / PSF 频率响应（加径向低通只涨 +0.0000，且实测平场更宽而 GS 更紧，单一径向滤波器做不到）；残差来自**加性背景（杂散光）项与 SLM 真实相位分辨率**这类结构上缺失的物理。这与论文 7.4 节「理想圆盘瞳没有的物理」一致，也解释了为何 T1 的噪声能量落在高频时被器件低通吞掉、T2 的 freeform 高自由度在 64×64 前向模型上无法体现为更优远场。
