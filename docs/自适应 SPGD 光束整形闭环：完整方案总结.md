## 一、系统架构总览

`每轮迭代 k:`\
`  ┌─────────────────────────────────────────────┐`\
`  │ 0. 标定(一次性):  σ_J = 指标噪声地板           │`\
`  │                  几何标定 CCD(扳正+对准)        │`\
`  │ 1. 锚点测量:      J₀ = J(a₀)      [1次曝光]    │`\
`  │ 2. 探测(按需):    ±Δa 对偶采样    [0~2次曝光]  │`\
`  │ 3. 历史回放:      二次代理模型 → g, H, trust  │`\
`  │ 4. 可信域牛顿步:   step = −H⁻¹g, ‖step‖≤δ     │`\
`  │ 5. 回溯接受:      J(a₀+step) > J₀ 才接受      │`\
`  │ 6. 调度:         成功率→δ;  SNR→σ;  阶段→w    │`\
`  └─────────────────────────────────────────────┘`

**测量预算**：稳定期每轮 2~3 次曝光（锚点 + 稀疏探测），约为朴素 SPGD 的 1/4。

## 二、均匀化目标函数（三层职责划分）

核心原则：**一个指标只负责一件事**，避免优化器拿均匀度换亮度、拿形状换效率。

### 2.1 三项复合指标

``` math
J = w_{\rho}\,\rho\left( \hat{I},T \right)\mspace{6mu} - \mspace{6mu} w_{u}\, CV\left( I_{roi} \right)\mspace{6mu} - \mspace{6mu} w_{e}\, E_{out}
```

| 项 | 定义 | 职责 | 量级 |
|:---|----|----|----|
| 形状项 ρ | Pearson 相关系数 | 锁轮廓，免疫功率漂移/增益变化 | −1~1，实跑 0.9+ |
| 均匀项 CV | `std(I_roi)/mean(I_roi)` | **你要的均匀度**，直接惩罚散斑 | 0.05~1.0 |
| 效率项 E_out | ROI 外能量占比 | 防能量漏出、防光斑漂移出框 | 0~0.5 |

```python
import numpy as np

def pearson(I, T):
    """计算皮尔逊相关系数"""
    a = I - I.mean()
    b = T - T.mean()
    # 防止分母为零，添加小量epsilon
    denom = np.sqrt((a * a).sum() * (b * b).sum()) + 1e-12
    return float((a * b).sum() / denom)

def make_metric(target, roi):
    """
    构建评估指标函数
    Args:
        target: 目标光斑图像 (numpy array)
        roi: ROI掩膜或索引，用于提取感兴趣区域
    Returns:
        metric: 评估函数，输入为生成图像，输出为 [相似度, 均匀度, 能量泄漏率]
    """
    T = target.astype(float)
    
    def metric(img):
        # 【关键修复】归一化后应使用新变量参与后续所有计算
        img_norm = img / (img.sum() + 1e-12)
        
        # 锁形状：皮尔逊相关系数天然免疫全局增益/偏置漂移
        rho = pearson(img_norm, T)
        
        # 均匀度：ROI内的变异系数 (CV = std/mean)，越小越均匀
        I_roi = img_norm[roi]
        u = I_roi.std() / (I_roi.mean() + 1e-12)
        
        # 能量泄漏率：ROI外的能量占比
        eout = 1.0 - I_roi.sum()
        
        return np.array([rho, u, eout])
    
    return metric
```

返回**分项向量**而非标量是关键设计：自适应权重需要知道每一项的当前值和梯度贡献，标量指标做不到。

### 2.2 逐帧归一化的细节

Pearson 已免疫乘性+加性漂移，但 CV 和 E_out 依赖绝对亮度，所以每帧先做 `img /= img.sum()`。若你的相机有慢变暗电流，ROI 内背景扣除（前面给过的四角中值法）要在归一化之前做。

### 2.3 备用：对数域 RMSE 形状项

若 Pearson 在你的目标形状上饱和太早（轮廓简单时很快到 0.99+），可换成对数域 RMSE 替代 ρ，对乘性误差等权、对内部起伏更敏感：

```python
import numpy as np

def log_rmse(img, target, eps=1e-6):
    """
    计算对数域均方根误差的负值（用于最大化优化）
    
    Args:
        img: 生成/测量图像 (numpy array)
        target: 目标图像 (numpy array)
        eps: 防止log(0)的小量
        
    Returns:
        float: 负的Log-RMSE值（越大表示越接近目标）
    """
    # 确保输入为非负浮点数，避免log产生NaN
    img_safe = np.maximum(np.asarray(img, dtype=float), 0.0)
    tgt_safe = np.maximum(np.asarray(target, dtype=float), 0.0)
    
    # 在对数域计算差异
    log_diff = np.log(img_safe + eps) - np.log(tgt_safe + eps)
    
    # 返回负RMSE（若用作loss最小化，去掉负号即可）
    return -float(np.sqrt(np.mean(log_diff ** 2)))
```

## 三、自适应权重（三个层面）

### 3.1 阶段调度（粗调 → 精修）

权重随收敛阶段切换，这是最简单的自适应：

| 阶段   | 判据       | w_ρ | w_u     | w_e     |
|:-------|------------|-----|---------|---------|
| coarse | 能量未聚拢 | 0.5 | 0.5     | **3.0** |
| middle | 能量\>80%  | 1.0 | **2.0** | 1.0     |
| fine   | CV\<0.15   | 1.0 | **3.0** | 0.5     |

阶段判据用实测指标值自动切换，不用人工干预：

```python
import numpy as np

# 分阶段权重策略: (判据lambda, 权重向量)
# values = [rho, u, eout] 对应 make_metric 返回的三个分量
STAGES = [
    # Stage 1: ROI外能量泄漏 > 0.3 → 优先收敛能量到目标区域
    (lambda m, v: v[2] > 0.3,   np.array([0.5, 0.5, 3.0])),
    # Stage 2: ROI内变异系数 > 0.20 → 能量已收拢，重点压制不均匀
    (lambda m, v: v[1] > 0.20,  np.array([1.0, 2.0, 1.0])),
    # Stage 3: 兜底精修阶段 → 均匀性已达标，微调形状匹配
    (lambda m, v: True,         np.array([1.0, 3.0, 0.5])),
]

def get_stage_weights(metric_func, values):
    """
    根据当前指标值自动选择对应阶段的权重向量
    
    Args:
        metric_func: make_metric 返回的评估函数（此处作为上下文传入，供扩展使用）
        values: 当前迭代的指标数组 [rho, u, eout]
        
    Returns:
        np.ndarray: 当前阶段对应的权重向量
    """
    # 【关键修复】添加 default 参数防止所有条件都不满足时抛出 StopIteration
    # 实际上最后一个条件是 True，永远不会触发，但这是防御性编程的最佳实践
    return next(
        wt for cond, wt in STAGES if cond(metric_func, values),
        STAGES[-1][1]  # 默认回退到最后一级权重
    )
```



### 3.2 梯度量级平衡（防”大嗓门”项垄断）

SPGD 的梯度是数值差分：某一项的**数值量级**决定它对参数更新的话语权，而不是它的物理重要性。CV 变化 0.01 是显著改进，ρ 变化 0.01 则无关紧要——所以用历史梯度估计逐归一化：

```python
import numpy as np

class GradientBalancer:
    """
    多目标梯度幅值自适应平衡器
    通过EMA跟踪各分项梯度的历史幅值，动态归一化后再加权合成
    """
    
    def __init__(self, n_terms=3, ema_decay=0.9, eps=1e-9):
        self.ema_decay = ema_decay
        self.eps = eps
        # 【关键修复】将全局可变状态封装为实例属性，避免闭包/全局变量陷阱
        self.gbar = np.ones(n_terms, dtype=float)
        
    def compute(self, dJ_terms, da, weights=None):
        """
        Args:
            dJ_terms: shape (3,) 各指标对参数的差分 ΔJ_i
            da:       标量或shape (3,) 参数变化量 Δa
            weights:  shape (3,) 外部阶段权重向量（来自AdaptiveWeightScheduler）
            
        Returns:
            float: 归一化并加权后的合成标量梯度
        """
        # 防止除零：da可能是标量或数组
        da_safe = np.where(np.abs(da) < self.eps, self.eps, da)
        g_terms = dJ_terms / da_safe
        
        # EMA更新梯度幅值的滑动平均
        abs_g = np.abs(g_terms)
        self.gbar[:] = self.ema_decay * self.gbar + (1.0 - self.ema_decay) * abs_g
        
        # 归一化到等量级后施加外部权重
        balanced = g_terms / (self.gbar + self.eps)
        
        if weights is not None:
            balanced = weights * balanced
            
        return float(np.sum(balanced))
    
    def reset(self):
        """重置EMA状态（切换优化目标或重新开始时需要）"""
        self.gbar[:] = 1.0
```

这样 `w = [1, 2, 0.5]` 的含义就是”均匀的物理重要性是形状的 2 倍”，而不是被数值尺度扭曲。

## 四、自适应扰动（PPO 可信域思想的 SPGD 实现）

### 4.1 三个自适应对象

| 对象                     | 机制                  | PPO 类比              |
|:-------------------------|-----------------------|-----------------------|
| 探测幅度 σ_i（逐模式）   | SNR 驱动双向调节      | 策略熵/探索噪声自适应 |
| 步长限幅 δ（可信域半径） | 成功率调度 + 回溯接受 | clip 参数 ε / KL 系数 |
| 梯度本身                 | clip 截断防野值       | PPO 的目标函数 clip   |

### 4.2 核心机制

**(a) SNR 诊断**（自适应的依据）：

``` math
{SNR}_{i} = \frac{\left| J\left( a + \Delta a_{i} \right) - J\left( a - \Delta a_{i} \right) \right|}{\sqrt{2}\,\sigma_{J}}
```

- σ_J 一次性标定：固定相位连拍 10 张，指标的 std；
- SNR \< 2：该模式梯度不可信 → σ_i ×1.3（加大探测）；
- SNR \> 8：探测过粗 → σ_i ×0.85（精细搜）；
- σ_i 硬限幅 \[0.01, 0.3\] rad，防低阶模式扰动过大把光斑推出 ROI。

**(b) 可信域半径 δ**：经典 trust-region 调度——

```python
import numpy as np

def adapt_step_size(delta, accept_history, window=10):
    """
    根据最近N轮接受率自适应调整搜索步长 δ
    
    Args:
        delta:          当前步长
        accept_history: 布尔列表/数组，记录每步是否被接受 (True/False)
        window:         滑动窗口大小
        
    Returns:
        float: 调整后的新步长
    """
    # 【关键修复】将中文变量名替换为合法英文标识符
    # 取最近 window 轮计算接受率，不足 window 轮时用实际长度
    recent = accept_history[-window:] if len(accept_history) >= window else accept_history
    
    if len(recent) == 0:
        return delta
        
    succ_rate = np.mean(recent)  # 接受率 ∈ [0, 1]
    
    # 【关键修复】使用 if-elif 保证互斥，避免同一轮既乘1.4又乘0.6
    if succ_rate > 0.6:
        delta *= 1.4       # 接受率高 → 扩大搜索域，加速探索
    elif succ_rate < 0.3:
        delta *= 0.6       # 接受率低 → 缩小搜索域，精细搜索
    # 0.3 <= succ_rate <= 0.6 时保持不变（最优接受率区间）
    
    # 【关键修复】clip 是 numpy 函数，需显式调用
    delta = float(np.clip(delta, 0.02, 0.5))
    
    return delta
```

**(c) 回溯接受**：每步多拍一张验证 `J(a+step) > J₀`，不接受则回退且 δ 缩小——这给 SPGD 提供了单调性保障，是 PPO 没有的（PPO 靠 clip 近似保证，我们靠回溯严格保证）。

**(d) 历史复用（省采样的关键）**：存 `(a, J_分项)` 历史，加权岭回归拟合局部二次模型 `J ≈ J₀ + g·Δa + ½ΔaᵀHΔa`，指数遗忘因子 0.85 抗漂移。模型给出牛顿步 `−H⁻¹g`，并用 H 的最大特征值定义信任半径 `trust = 0.3/|λ_max|`——**曲率大的方向自动小步**。3~5 轮后模型成熟，探测采样可降为隔轮一次。

**(e) 重要性权重（σ 变化时的保险）**：历史样本若采样自旧 σ_old，回放时按高斯比 `w = N(Δa;0,σ_new²)/N(Δa;0,σ_old²)` 校正，并 `clip(w, 0.5, 2.0)`——σ 变化过大的样本直接弃用，防重要性权重方差爆炸。

1.  **先跑 σ_J 标定**：打印三项的 σ_J。若 σ_J(CV) \> 0.01，说明相机信噪比不够，先解决曝光/衰减，别调算法；
2.  **看 σ_i 自适应走向**：σ 全部顶到上限 → 指标对该模式不敏感，检查 Zernike 模式覆盖是否够（高阶散斑需要更高阶模式或接受多图平均）；σ 全部压到下限 → 系统很干净，可以加快 δ；

## 六、Gerchberg-Saxton (GS) 光斑均匀度

Gerchberg-Saxton (GS) 算法虽然收敛速度快，但其核心缺陷在于**仅约束目标区域的振幅，而忽略了相位自由度和非目标区域的能量分布**。这导致重建光斑容易出现散斑噪声、边缘陡峭度差以及整体均匀度不佳（RMS误差大）。

针对光斑均匀度问题，以下是目前学术界和工业界主流的改进算法及策略，按推荐程度排序：

### 1. 加权迭代反馈法 (Weighted Iterative Feedback / Adaptive GS)

这是解决均匀度最直接、成本最低的改进方案。

- **核心思想**：在每次迭代的傅里叶域（焦平面）引入一个动态权重矩阵 $W(x,y)$。对于光强高于目标值的区域施加惩罚（降低权重），对低于目标值的区域给予补偿（提高权重）。
- **公式修正**：$A_{k+1} = A_{target} \cdot W_k \cdot e^{i\phi_k}$，其中 $W_k = W_{k-1} \cdot (A_{target} / |F_k|)^\gamma$。
- **优势**：无需改变GS基本框架，仅需增加几行代码；能显著压制热点（Hotspots）并填补暗区。
- **注意**：$\gamma$ 参数需自适应调整，过大会导致震荡不收敛。

### 2. 混合输入输出算法 (HIO) 及其变体

HIO 是相位恢复领域的经典算法，比纯GS具有更强的逃离局部极小值能力。

- **核心思想**：在非目标区域（Support Constraint之外）不强制置零或替换振幅，而是采用负反馈机制：$g_{k+1}(x) = g_k(x) - \beta \cdot P(g_k(x))$。
- **均匀度提升点**：HIO允许能量在非目标区域适度“泄露”再回流，避免了GS因硬截断导致的频域吉布斯效应和高频噪声，从而使目标区域内的光强分布更平滑。
- **推荐组合**：**GS + HIO 混合策略**。前N次用HIO探索全局最优解，后M次用加权GS精细打磨均匀度。

### 3. 基于梯度下降/优化的算法 (Gradient-Based Optimization)

将相位全息图生成视为一个可微优化问题，而非交替投影。

- **代表算法**：NOVA、Adam-Phase、L-BFGS。
- **核心思想**：直接定义包含均匀度指标的代价函数，例如： $$ \mathcal{L} = \alpha \cdot \text{MSE}(I, I_{target}) + \beta \cdot \text{TV}(I) + \gamma \cdot \text{UniformityPenalty} $$ 其中 TV (Total Variation) 项专门用于抑制散斑、提升平滑度。
- **优势**：可以显式地将“均匀度”作为优化目标写入Loss函数；支持自动微分框架（PyTorch/JAX），收敛精度远超GS。
- **劣势**：计算量比GS大1-2个数量级。

### 4. 多平面/多波长约束 (Multi-Plane / Multi-Wavelength)

从物理维度增加约束自由度。

- **核心思想**：不仅在焦平面约束振幅，还在轴向多个离焦面同时施加约束（Multi-plane GS）。
- **均匀度提升点**：单一平面的均匀解空间很大，容易陷入含散斑的局部最优。多平面约束大幅压缩了解空间，迫使算法找到在三维上都平滑的解，天然抑制了焦面上的高频不均匀性。

### 5. 深度学习辅助 (Deep Learning Phase Retrieval)

- **思路**：用U-Net或Transformer直接从目标光斑预测初始相位，再用少量GS/HIO迭代微调。
- **均匀度提升点**：神经网络学习到了大量高质量均匀光斑的先验分布，其输出的初始相位已经避开了GS容易陷入的“散斑陷阱”，后续迭代只需做局部均匀度修正。

#### ⚠️ 关键提醒：检查硬件约束

在追求算法均匀度之前，务必确认你的SLM/DMD是否满足以下条件，否则算法再好也无济于事：

1. **像素填充率**：SLM像素间隙会导致高阶衍射噪声，破坏均匀度。
2. **相位量化误差**：8-bit以下量化会引入固有散斑，考虑使用误差扩散或时间平均技术。
3. **入射光束质量**：如果入射光本身不均匀，GS只能在有限动态范围内补偿。建议先对入射光做平顶化处理。

如果你能提供当前光斑的具体问题（如：是中心亮边缘暗？还是有随机散斑？或是特定图案填充不均？），我可以给出更具针对性的算法参数配置建议。
