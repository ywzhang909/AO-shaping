# Micro-DM 1300 单元硬件文档

## 1300-5.xlsx 映射表说明

本文件定义了 1300 (36×36) 单元 Micro-DM 的**单元格 → 控制器 → 通道**映射关系。

### 表结构

| 列 | 列名 | 说明 | 示例 |
|----|------|------|------|
| A | 位置序号 | 硬件物理位置 ID (1–1296) | 109, 110, 74 |
| B | 36×36 行 | 网格行坐标 (0–35) | 3, 3, 2 |
| C | 36×36 列 | 网格列坐标 (0–35) | 0, 1, 1 |
| D | IP 组 | 控制器 IP 地址后缀 (101–126) | 124, 111, 101 |
| E | 序号 | 通道编号 (**0-based**, 0–49) | 26, 16, 12 |
| F | 组 | 分组名称 | 一组, 二组 |
| G | 引脚编号 | 硬件引脚号 | 1, 2, 3 |
| H | 连接器 | 连接器编号 | 1-1-1, 1-1-3 |

### 关键映射

```
位置序号 (硬件 ID)
    ↓
36×36 行/列 (网格坐标)
    ↓
IP 组 + 序号 (控制器 + 通道)
    ↓
物理执行器
```

### 序号说明

- **序号从 0 开始**: 每个 IP 组有 50 个通道 (序号 0–49)
- **位置序号 ≠ Excel 行号**: 位置序号是硬件物理 ID，与 Excel 行号无直接对应关系
- **26 个控制器**: IP 101–126，共 1300 个单元

### 数据分布

| IP 组 | 行数 | 序号范围 |
|-------|------|---------|
| 101–125 | 50 行 | 0–49 |
| 126 | 50 行 | 0–49 |
| **总计** | **1296 行** | **0–49** |

### 与图像文件的映射

图像文件名格式: `192.168.0.{IP组}-{序号:03d}.png`

示例:
- 位置序号 1225 → IP 101, 序号 0 → `192.168.0.101-000.png`
- 位置序号 37 → IP 101, 序号 1 → `192.168.0.101-001.png`
