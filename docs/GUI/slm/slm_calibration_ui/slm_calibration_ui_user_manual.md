# SLM LUT 校准 UI (slm_calibration_ui.py) — 用户手册

## 1. 概述

`slm_calibration_ui.py` 是 SLM 查找表 (LUT) 校准的 Streamlit 前端页面。支持连接 SLM 与相机、配置校准参数、运行闪耀光栅校准以寻找 2π 相位对应的灰度值、实时可视化校准曲线、保存/加载校准结果。

启动方式：

```bash
streamlit run src/ao_shaping/gui/slm/slm_calibration_ui.py
```

完整技术细节见 [`slm_calibration_ui_srs.md`](./slm_calibration_ui_srs.md)。

---

## 2. 快速上手

### 2.1 连接设备

1. 在侧边栏设置 SLM 编号（默认 1）和波长（默认 1064 nm），点击「连接 SLM」。
2. 设置相机曝光时间（默认 50 ms），点击「连接相机」。
3. 连接成功后，SLM 与相机句柄存入 session state，可进行校准操作。

### 2.2 配置校准参数

在校准参数面板中设置：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 校准方法 | 校准方法（闪耀光栅） | BLAZED_GRATING |
| 光栅周期 | 闪耀光栅空间周期，单位像素 | 8 |
| 灰度最小值 | 灰度扫描起始值 | 100 |
| 灰度最大值 | 灰度扫描结束值 | 800 |
| 灰度步长 | 灰度扫描步长 | 20 |
| 细搜索步长 | 细搜索步长 | 2 |
| 细搜索范围 | 细搜索范围 | 50 |
| 采样次数 | 每个灰度值的采样次数 | 3 |
| 自动曝光 | 是否启用自动曝光 | True |
| 目标强度最小 | 目标强度范围下限 | 80 |
| 目标强度最大 | 目标强度范围上限 | 220 |
| ROI 中心 | 感兴趣区域中心 | None |
| ROI 尺寸 | 感兴趣区域尺寸 | 100 |

### 2.3 运行校准

1. 检查 SLM 与相机均已连接。
2. 配置校准参数。
3. 点击「运行校准」。
4. 校准在后台线程运行，UI 实时显示进度（百分比、当前灰度、强度）。
5. 校准完成后，显示 2π 灰度值及拟合参数。

### 2.4 保存与加载结果

1. 校准完成后，点击「保存校准结果」，结果保存到 `data/slm_calibration` 目录。
2. 如需加载历史结果，点击「加载校准结果」并选择文件。

## 3. 关键设计规则

| 规则 | 说明 |
|------|------|
| 设备连接互斥 | 连接前先断开现有连接，避免句柄泄露 |
| 后台线程通信 | 校准运行在后台线程，通过 JSON 文件与 UI 通信进度，不直接操作 `st.session_state` |
| 校准运行锁定 | 校准运行期间禁止重复启动，通过 `slm_cal_running` 标志位控制 |
| 错误隔离 | 设备连接/校准失败通过 `st.error` 显示，不导致页面崩溃 |
| 句柄释放 | 断开设备时始终在 finally 块中执行 close() |
