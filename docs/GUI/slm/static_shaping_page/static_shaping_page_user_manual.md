# SLM 静态整形页 — 桌面版用户手册

本手册说明 PySide6 桌面控制台（`ao_shaping.gui.ccd.beam_quality`）中「SLM 静态整形」页
（`src/ao_shaping/gui/slm/static_shaping_page.py`）的操作流程。页面入口与启动方式见
[beam_quality/README.md](../../../../src/ao_shaping/gui/ccd/beam_quality/README.md)。

## 1. 这是什么

本页把 Streamlit 版 PatternHelper 的静态整形交互搬进桌面控制台：**选图案类型 → 调参数 →
生成预览 → 下发到所选 SLM**。相位生成本身是纯数值计算，不需要 CCD；但下发到 SLM 之后实际
光路效果如何，取决于光路是否与模型假设一致，因此本页对「本次下发基于什么光路认知」做了
显式声明（见 §4）。

## 2. 启动与进入

```bash
.venv\Scripts\python.exe -m ao_shaping.gui.ccd.beam_quality
```

左侧窄导航栏切换到第 2 页「SLM静态整形」。该页在切过去时才创建，冷启动不会被它拖慢。

## 3. 页面布局

页面分两列：

- **左列（可滚动表单）**，自上而下四个分组 + 动作按钮：
  - ① 图案类型
  - ② 参数（随图案类型动态变化）
  - ③ 目标 SLM
  - ④ 光学观测来源
  - 动作按钮：「生成预览」「下发到 SLM」
- **右列**：预览图（空状态时显示下一步操作提示）。

## 4. 操作步骤

### 4.1 ① 图案类型

下拉选择要生成的相位图案。可选图案与 Streamlit 版共用同一份规格注册表，两侧不会漂移：

| 图案 | 说明 |
|------|------|
| 线性光栅 | 周期光栅 |
| 圆形光栅 | 同心圆光栅 |
| 透镜 | 聚焦透镜相位 |
| 棋盘格 | 棋盘格相位 |
| 二元光栅 | 二元衍射光栅 |
| 微透镜阵列 | 微透镜阵列相位 |
| 湍流相位屏 | 先按 r0/L0 初始化随机湍流屏再生成，每次点击重新解耦生成 |
| Zernike | 单阶 Zernike 相位 |
| 达曼光栅 | 达曼光栅 |
| 涡旋相位 | 涡旋相位 |
| 聚焦 | 聚焦相位 |

切换图案类型后，参数区会重建为该图案对应的参数项，旧预览作废（不会把与当前表单不符的
相位发给 SLM）。

### 4.2 ② 参数

按当前图案类型显示参数控件（数值输入或下拉）。直接在控件上改值即可，改完点「生成预览」
以新参数重新生成。

### 4.3 ③ 目标 SLM

「SLM 编号」选择要下发到的 SLM（1–8）。默认 1。

### 4.4 ④ 光学观测来源（重要）

本页的相位生成基于**模型前向假设**（PSF、离焦、照明包络取默认值）。这一假设是否成立，
需要 CCD 实测才能确认。下拉框提供三种声明，务必如实选择：

| 选项 | 含义 | 何时该选 |
|------|------|----------|
| ○ 模型前向（未观测，按理想光路） | 未做 CCD 观测，相位按理想光路直接下发 | 本会话没有测过光路时（默认） |
| ○ 未知（几何未标定，用内置回退） | 连几何参数都没标定，用页面内置回退值 | 首次装机、几何未标定时 |
| ● 已标定光路（本会话实测） | 本会话已用 CCD 实测光路，相位基于实测几何 | 已完成光路标定且本次未漂移时 |

规则：

- 选择未观测类选项时，下方红色提示条声明「光路假设未验证，下发结果不代表实测」；
  选择「已标定光路」时提示条变绿。
- 「已标定光路」选项只有本会话确实注入过实测快照时才可用，否则禁用——避免误把模型
  前向当成实测。
- **在未观测状态下点「下发到 SLM」会弹出确认框**，说明本次下发基于模型前向假设，
  要求显式确认后才继续；选「否」则不下发。已标定状态下跳过确认框。
- 预览图无论选哪种来源，都是模型前向结果（预览不依赖 CCD）；预览悬停提示中已标注
  「预览为模型前向，未含实测光路校正」。

### 4.5 生成预览

点「生成预览」，后台生成相位（不卡界面），完成后右列显示灰度预览。此时相位被缓存，
可供下一步下发。若生成途中改了参数，旧结果作废并自动重新等待新结果。

### 4.6 下发到 SLM

点「下发到 SLM」，后台线程把相位写入所选 SLM 并显示。成功或失败都会弹窗告知。

## 5. 下发元数据记录

每次下发成功后，页面会把**本次下发所依据的光路认知**与相位摘要记录到：

```
data/debug/static_shaping_send/<时间戳>_slm<编号>_<图案类型>.json
```

记录内容包括：图案类型、时间戳、光路认知快照（`source` / `observed` / 假设项 / 备注）、
相位尺寸与相位的 SHA-256 摘要。用途：事后回查时，区分「算法效果差异」与「光路漂移 /
假设错误」——记录里 `observed: false` 即表示该次下发未做实测光路验证。

记录写入失败只记日志，不影响下发本身。

## 6. 注意事项

- 相位生成（预览）不需要任何设备，可离线使用；只有「下发到 SLM」需要 SLM 在线。
- 预览是模型前向结果，只表示相位数值本身，不代表实际光路下的远场效果。
- 本页与桌面控制台其它页面共用单线程任务池：同一时刻只有一个设备操作在跑。
- 桌面控制台是纯 Qt 进程，不连 Streamlit，因此默认的光学观测来源是「模型前向（未观测）」；
  只有宿主在构造本页时注入实测光路快照，「已标定光路」才会可用。
