# Micro-DM 微驱动器控制 UI (micro_dm_ui.py) — 用户手册

## 1. 概述

`micro_dm_ui.py` 是 Micro-DM 微变形镜控制的 Streamlit 前端页面。支持单单元控制与 39×39 矩阵联合控制，电压下发、周期波形发送、实时热力图可视化。

启动方式：

```bash
streamlit run src/ao_shaping/gui/dm/micro_dm_ui.py
```

完整技术细节见 [`micro_dm_ui_srs.md`](./micro_dm_ui_srs.md)。

---

## 2. 快速上手

### 2.1 电压安全范围

两个 Tab 共享电压上下限设置：
- 下限默认：-20.0 V
- 上限默认：120.0 V
- 所有下发电压自动裁剪到安全范围与硬件物理极限

### 2.2 Tab 1 - 单单元控制

1. 设置 IP 地址与端口（默认端口 10101）。
2. 点击「测试连通性」检查 TCP/ICMP 连通。
3. 点击「连接单单元」建立连接。
4. 设置目标通道号、电压模式（固定/周期）、波形类型（正弦/方波）等参数。
5. 点击「开始发送」启动后台线程周期下发电压。
6. 查看实时电压历史曲线。
7. 点击「停止发送」停止后台线程。

### 2.3 Tab 2 - 矩阵联合控制

1. 连接 39×39 矩阵控制器。
2. 在热力图中编辑各单元电压值，或导入矩阵配置。
3. 点击「一键应用」批量下发电压。
4. 支持连续电压下发（间隔可设）。

## 3. 关键设计规则

| 规则 | 说明 |
|------|------|
| 电压安全裁剪 | 所有下发电压自动裁剪到安全范围与硬件物理极限 (-20V ~ 120V) |
| 后台线程隔离 | 周期发送线程不直接操作 `st.session_state` |
| Tab 独立反馈 | 两个 Tab 各自拥有独立反馈区，互不干扰 |
| 连接互斥 | 连接前先断开现有连接，避免句柄泄露 |
