# Issue #247：波形归因信号同窗口重复性复核（预注册）

**状态：冻结后才允许生成图样；禁止依据采集结果回改图样、阈值或判据。**

## 1. 本轮问题与边界

本轮只回答：2026-11-24 的归因窗口中，波形/面板轴差异与缺峰现象能否在**同一次硬件打开周期内的重复呈现**。这是先行复核，不是独立采集窗口，不建立新的 panel→CCD 映射，也不解决支持域、LUT 实际相位或未见方向问题。

本轮结果不能单独证明根因、不能冻结映射、不能宣称矫正提升预测准确率；若差异未重复，只能标为本窗口内不稳定，不能据此关闭 issue。

## 2. 采集冻结项

- 计划：现有 `attribution` 的完整 23 个图样，每个图样连续采 4 帧；重复 3 轮，轮次标识 `r1/r2/r3`，共 69 个有唯一 ID 的 pattern、276 帧。
- 顺序：`r1` 按冻结 attribution 顺序；`r2` 反序；`r3` 按冻结顺序。不得在轮间重新 open/close SLM。
- 每轮 flat 参考随原计划重复；各轮同一 base pattern 的相位 SHA-256 必须一致。
- 固定曝光 `0.04 ms`、settle `0.8 s`、每图样 `4` 帧、饱和门 `0.9 × full_scale`、SLM #1 / 1064 nm / cam 0。设备和曝光须先通过独立六步光路预检 `verdict=ok`；采集 CLI 必须 `--wait-until-idle 1800`，仅允许一个执行进程、一次 SLM open + close，不自动重试。
- 每次采集使用全新输出目录；只在 SLM 关闭、锁释放后运行离线检查。

## 3. 冻结检查口径

配套检查脚本必须拒绝缺失/重复轮次、pattern ID 或帧、相位摘要不一致、错误曝光/帧数、饱和帧、flat 漂移超出原预注册 `2.0 px` 门限、设备未正常释放、或基线分析产物缺失的输入。不得静默修补或丢弃样本。

对每个 base pattern，逐轮从原始帧重新执行同一分析器和同一参数，报告每帧/每轮质心、候选峰、`axis_angle_deg`、峰数及信噪信息（若分析器有输出），不能只比较合并后的 4 帧均值。对所有可评估 pattern：

- 同轮四帧角度离散度、轮间最大轴角差均按轴向角（模 180°）报告；
- 方向重复性门：三轮中至少两轮可评估，且任意两轮轴角差 `≤ 2°`；否则为未复现/不可评估，须说明缺测原因；
- 原预注册 G1–G4 逐轮单独计算，不合并数据绕过门槛；三轮门结果及实测值都要保留。
- `patch_x_minus_p192` 缺峰必须保留为缺测；不得调检测阈值以使它通过。可附加报告固定敏感性网格，但主判读仍使用原冻结参数。

## 4. 报告结论边界

本轮若重复性门通过，只能说“该异常在本次连续硬件会话内可重复”；不等同于跨会话独立复现。若未通过，结论为“本窗口信号不稳定/证据不足”，不等同于 issue 无效。无论结果如何，panel-y 轴路由、实际 LUT/相位写回、匹配支持域及未见方向验证仍为未解决证据缺口。
