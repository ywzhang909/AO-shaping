## 1. 范围

- 适用对象：transfer 科学验收的 `light`（少 CCD + 实测锚点）与 `none`（纯模型开环）两模式。
- **不覆盖**：锚定闭环、混合模式外推、跨 epoch / 漂移泛化。这些需各自单独计划与预注册。
- 本草案只定义**判据与口径**，不定义采集数量以外的新实验；采集序仍按
  `hw_ccd_mode_test_plan_20261118.md`，统一入口
  `scripts/experiments/run_transfer_window_20261119.py`（`lock_mode="window"`）。

## 2. 指标定义（必须在评估前锁定）

| 项 | 冻结内容 |
|---|---|
| 强度指标 | 固定 ROI + mask 上的**未缩放** `relL2`：预测零步绝对强度图 vs 独立实测帧 |
| 禁止操作 | 事后拟合全局增益、重新中心化、挑选曝光档、挑选 ROI、剔除"不好看"的 pass 或模式 |
| 形状诊断 | Pearson 相关仅作空间形状诊断，**不替代**绝对强度误差 |
| 计算口径 | `relL2 = \|\|p - t\|\|₂ / max(\|\|t\|\|₂, 1e-9)`；同一网格上的预测与实测强度率数组（`count_rate`，counts/ms 量级），未缩放、未做单位和归一化消除 |
| 暗场/设备记录 | 暗场/黑电平处理必须在预测比较前按冻结流程执行；满量程与位深按当次 `optical_path_record.json` 记录。不得把 `protocol.py` 中整窗单位和归一化的 scale-free `rel_l2` 与本门混用 |

## 3. 测量有效性前置（任一不满足 → 该 pass `not assessable`）

采集前一次性冻结，并把哈希写进验证记录：

1. 模型定义与权重（checkpoint 文件哈希）、训练/验证拆分；
2. ROI / mask 几何；
3. 曝光档与 `exposure_ms` 记账（每个 pass 的实际曝光必须与记录一致）；
4. 暗场/黑电平处理与位深、满量程；
5. settle 判据与丢帧规则；
6. 采集脚本与评估脚本的版本哈希。

**任一 pass 出现曝光记录与实测不一致、饱和、settle 失败、暗场缺失**，该 pass 记
`not assessable`，不得由它宣告通过或失败。

## 4. 独立性与汇总

- 冻结后的模型只评估**新采集的 hold-out**；训练数据不得复用为验证。
- 两个方向互换的 cross-fit（pass1→pass2 与 pass2→pass1）在数学上互为镜像，
  **不重复计数**；`LocalResponseModel` 的 12/14 属此类，不得当作 14 个独立证据。
- 每个独立 pass 单独计算 `relL2`，采用**最差 pass** 判定，不用合并平均掩盖单 pass 失败。
- 重复帧只用于估计该 pass 的测量不确定度，不作为独立实验单位。

## 5. 联合规则（方向门 + 强度门）

- **方向门**：沿用既有判据——每模式 Pearson ≥ 0.50，14 对中 ≥ 10 对通过
  （见 `agent_notes_20261118.md` §双 pass 合并）。只对**锁定模型**的真实独立 hold-out 对计数。
- **强度门**：所有有效独立 pass 的 `relL2 ≤ δ`。
- **放行条件**：两门同时通过 **且** §3 全部前置有效；否则分别报告 `fail` 或 `not assessable`。
- 本规则不放行任何未经单独计划的锚定闭环或混合模式外推。

## 6. δ（已选定为预注册工程容差）

**冻结值：δ = 0.20**（20% 未缩放 `relL2` 上限；仅适用于本文件冻结的 ROI/mask、暗场处理与采集配置）。

### 选择理由与证据强度

- 本项目已有直接的应用层质量容差：`hw_ccd_mode_test_plan_20261118.md:39` 规定 `light` 相对 `full` 基线的实测 CV 退化须 **< 20% relative**。据此将 20% 选作强度图误差的**同量级工程容差**；这里只借用既有项目的容差尺度作为政策锚点，不声称两种指标有可比较的严格性顺序。
- **这不是数学换算**：CV 是 `std/mean` 的单一统计量；`relL2` 衡量固定 ROI 内逐像素差异。CV 合格不保证 `relL2 ≤ 0.20`，反之亦然。两者作为相互独立的质量门，不将 CV 20% 宣称为 relL2 的等价容差。
- 既有报告的约 8% 跨 pass 差异是 CV/标度差异且曝光记账不自洽，并非固定条件重复测量的本门 `relL2` 噪声分布；因此**不**用它推导 0.20，也不声称 0.20 已有统计功效或噪声地板校准。另有历史报告记录同条件重复帧的 scale-free `rel_l2` 极差约 `0.0001–0.0011`（`historical_measured_shape_metrics_reanalysis_20261119.md:32,48`），但该口径先对整窗归一化、消除了绝对标度，**不是本门的未缩放 relL2**，只作测量质量参考，不直接用于阈值换算。首次新验证报告必须同时披露本门口径下的重复帧/重复 pass 测量变异；若有效性或重复性不足以解释观测误差，则报告 `not assessable`，不得事后放宽 δ。
- `δ=0.20` 是**预先选定的工程政策上限**，不是由模型表现拟合出来的统计参数。现有 `relL2=0.355`、`0.217–0.261` 均不参与设值；`fit.py` 中的 `relative_l2_above=0.25` 仍只是 escalation heuristic。

### 适用范围

先对锁定的 transfer 验证配置使用单一 δ，不按位深、曝光或模式事后分档。若未来覆盖不同采集条件，须在新数据产生前另行预注册分档及其重复性依据。本 δ 只作为 §5 的强度门，不替代该应用流程既有的 CV 质量判据。
