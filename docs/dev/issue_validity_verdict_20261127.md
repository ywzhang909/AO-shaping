## 2. 新增实测证据：全幅 1D 光栅轴路由跨会话对照（#247 / #235）

### 2.1 三源数据

对同一族全幅 1D 二值光栅（`grating_x_p128_scale993` / `grating_y_p128_scale993`，p128、two_pi_gray_scale=993），三个独立来源的 CCD ±1 级位移方向：

| 来源 | grating_x（panel axis=1） | grating_y（panel axis=0） |
|---|---|---|
| **NEW**（11-27，`xy_grating_scale_20261127_2030Z`，exit 0） | **行向** dr +59.731/−58.895，dc −0.672/+1.856；pitch 59.31 px | **列向** dr +1.212/−0.408，dc +59.235/−58.397；pitch 58.82 px |
| **S1**（11-26，`s1_verify_20261126_retry`） | **列向** dc +95.09/−93.22，dr +3.72/−0.32；≈94 px | **列向** ≈59 px |
| **拟合 A**（判据⑤）`[[26.25,−7673.44],[7705.91,−22.01]]` | 预测 px→**列**（dc 由 px 主导 +7705.91） | 预测 py→**行**（dr 由 py 主导 −7673.44） |

### 2.2 量化结论

1. **grating_y 三源稳定**：S1 与 NEW 均为列向 ≈59 px，跨会话一致，且与理论符合（见 2.3）。**grating_y 截面可作为 repeatability / 输入一致性基准。**
2. **grating_x 跨会话不稳定**：S1 落列向 ≈94 px、NEW 落行向 ≈59 px——**轴向与量级均变**。两 plan 的 grating_x gray SHA-256 完全一致（`bc0c5613…`），`grating_phase` 自 2026-11-20 起未改动（早于 S1 采集）。**同 gray、同代码 → 不同轴路由**，只能指向面板内部寻址/旋转态（`SLM_Disp_Data`，仓库外）跨会话变化。
3. **与拟合 A 互为转置**：A 预测 px→列、py→行；NEW 实测 px→行、py→列。这与 `provenance.py:1414` 已登记的「拟合 ramp_matrix 与现场轴映射互为转置，空间放置需标记测量裁决」一致——本组 NEW 数据即为该测量裁决的新证据：**全幅 1D 光栅路由不能由单一固定 ramp_matrix 表达**。

### 2.3 物理校核

p128 × PITCH 8.0 µm = 1024 µm，λ=1064 nm，f=125 mm，CCD 2.2 µm：
sinθ = 1.064/1024 = 1.039e-3 → Δ ≈ 125 mm × 1.039e-3 = 129.9 µm → **59.0 px**。
94.5 px 需约 80 px 周期，与 p128 不符。故 NEW 的 59 px 为物理正确值；S1 grating_x 的 94 px 为异常。

### 2.4 对判定的影响

- **#247**：前序判定「全幅 1D fy≡0 族落 CCD 列轴、不能用 A 映射」本组数据部分修正为「**全幅 1D grating_y 稳定落列轴；grating_x 轴路由跨会话不稳**」。结论方向不变且证据增强：全幅 1D 光栅族**不可冻结映射**，须用 A 映射（2D/局部 ramp）路线。**#247 维持有效、不关闭。**
- **#235(b)**：「ramp_matrix 的 y'→x' 分布与实测 grating_y 截面对得上」——grating_y 截面现已三源稳定（列向 59 px），可作基准；但若断言改用 grating_x 则**不可满足**（路由不稳）。**输入一致性断言的采集源应锁定 grating_y 或 A 映射，不用全幅 1D grating_x。**

## 3. 各 issue 离线判定与改进 / 数据采集计划

### 3.1 #234 结构化探针 + 在线回灌

- **判定**：有效、算法收益未证明。P3-1 已完成（`pool='k0m2m3'` 纳入拟合提升空间秩，0/16 模可辨识不变）；P3-2 局部 k 扫描因 G1 映射未冻结暂停，重放证明多解（MAE 0.125 vs 0.000）。
- **缺数据**：双门方向门需**独立方向几何**（结构化探针数据仅覆盖 1 个方向，插值零误差无检验力）；2f 窗未测（现 =2f 输出）。**2026-11-27 已补**独立 ramp/2D 探针（§4.1 C）；2f 窗仍未测。
- **计划**：沿 §2 结论，用 A 映射（2D/局部 ramp）闭合 G1 后再恢复 P3-2 k 扫描；方向门改对**独立方向/几何**探针评估（现有 `scripts/slm/audit_p3_finite_difference_20261123.py` 已支持方向扫描）。数据已具备，无需新采集管线。

### 3.2 #235 输入一致性

- **判定**：有效、部分子项完成。原根因（输入相位错）已被否（panel_gray 14 帧 mismatch 0；换实际相位方向 cosine 仍≈0）。pupil（瞳面）-center/shift_phase 零判别力（3.6e-10）；panel_gray 9/9 全部逐位一致（2026-11-23）。
- **本轮推进**：§2 给出 grating_y 截面稳定基准与 grating_x 不可冻结证据 → 断言采集源应锁定 grating_y / A 映射。
- **剩可信**：g₂π LUT 待 #238 暗场放行；零级质心已落地（`fc4d3cf3`，SD 0.297–0.330 px）。
- **计划**：把 #235 输入一致性 P0 断言的 ramp 截面源固定为 grating_y（列向 59 px，repeatability 可测）；不写新采集，复用既有 grating 帧。

### 3.3 #236 拟合损失重构

- **计划**：掩膜 CV / 高频 / log / JVP 四项损失的消融**推迟到双门放行后**。离线可先做「JVP 项可微性与有限差分对拍」纯单元验证（不依赖新数据），但**不得据此宣称方向收益**。

### 3.11 #213 收敛效率 / 物理保真度 / 高维优化

- **判定**：有效、L-BFGS 入围，K 轴与 cosine 不入选。14 模完成 AD / L-BFGS / Adam / 混合 / K-rot 公平对照；L-BFGS 优（时间 0.166s vs AD 0.249s、成功率更高）。K-rot 未进入扩展主推荐；KNN 对既有检查点零有效预测；cosine + L2 不优于纯 L2。
- **计划**：高维联合优化候选为 L-BFGS；权重纪律维持「不编造最佳权重」。已生成的双保真消融事实保留（Step A 高保真度在测试 IQA 反转）。

### 3.13 #223 2D 坐标轴序一致性

- **判定**：有效、离线可优化。全量 AST 审计坐实 5 套轴序约定并存（主约定 `(x,y)` 114 个生产者；`(row,col)`/`(y,x)` 13 个生产者；外加 `image_point.xy`、`SpotMeasurement(centroid_x,centroid_y)` 与 `[row,col]` 边界）。零级/光斑坐标每跨一次域即静默转置，是 transfer/MIL 几何正确性的真实 bug 源。
- **与 #247 的边界**：#247 是**物理**轴路由（SLM 面板→CCD 远场，§2 已证跨会话不稳，根因在 `SLM_Disp_Data`）；#223 是**软件**轴序约定（代码内 `(x,y)`↔`(row,col)`）。§2 的 grating 斑点由 `find_spots` 直接作用于原始帧，不经拟合模型代码，故 #247 的不稳是物理性、非 #223 代码转置所致。两者独立、不可互相替代。
- **现状核实（本轮运行验证）**：选项 1 **已落地**——`src/ao_shaping/utils/image/axis_order.py` 已提供 `Point` 命名元组、`rowcol_to_xy`/`xy_to_rowcol`、`AXIS_XY`/`AXIS_ROWCOL` 常量与 `ROW_FIRST_SURFACES` 单一事实源登记表（AST 守卫逐条核对 docstring）。守卫测试 `tests/ao_shaping/test_point_axis_convention.py` 本轮运行 **14 passed**（一律非方图 `(120,160)`，方图断言被显式禁用）。故本 issue 不需新建原语。
- **后续计划（选项 2 归一化，未启动）**：库边界全部转 `(x,y)` + 断言 + `Point` 化 + 逐步迁移 row 先生产者为 `(x,y)`。属行为改动，涉共享文件，需独立窗口逐路径提交并回归；本轮不做。

### 3.14 #182 MIL Step A 非理想性联合自校准

- **判定**：有效、摘要级证据、仿真优先。GRAPHYCS（arXiv:2611.00845，摘要级）在 PINN+DMD 变体上「非理想性感知最多 9× 改善」为方向性证据；本仓库已确认两类非理想性（光瞳相对错位、焦域采样）真实存在。
- **缺数据 / 前置**：全文未取，可调自校准参数集合与可辨识性未确认；不能由摘要外推联合解最优性。
- **计划**：在 `TwinErrorModel`/`utils.differentiable` 的物理可微光束链上注入已知强度非理想性，跑「纯 shape」vs「shape+非理想性联合自校准」对比择优（真实/预测非理想性误差、收敛步数、稳定 CV、最终 IQA）。与 #112/#119/#165 正交（那几条改注入形式/预训练，本条补系统校准环节）。判定依赖 bench_twin 仿真与对误差的验证，不做与 CCD 同步性能结论。

### 3.15 #232 EHGO 在线扰动估计（DM 域）
