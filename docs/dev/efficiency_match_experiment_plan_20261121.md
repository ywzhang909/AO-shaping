# 整形效率与衍射效率匹配性实验计划（2026-11-21）

> 状态：**采集前预注册草案；尚未授权设备占用**。
> 目的：锁定“当前光路下的远场整形，对无法被 SLM 调制的 0 级作分母修正后的利用能量效率”与“同光路衍射效率”是否匹配。
> 本文不改动代码、不写标定文件、不判定控制/迁移模型是否解禁。任何 `--execute`、上机与设备窗口均需用户当次明确批准。

## 摘要

现有数据不能回答这两个效率是否匹配：衍射探针估计的 ±1 级位置与实测几何不一致，且缺少同曝光暗帧；同一批整形帧也没有按“可调制能量为分母”的固定口径重算。

本实验采用**同一设备窗口、同一曝光、同一激光功率、同一 SLM LUT**交错采集三种相位：

1. 全平相位，测不可调制的 0 级基准 \(F_0\)；
2. blazed grating，测一阶衍射效率 \(\eta_d\)；
3. 目标远场整形相位，测目标区内来自可调制分量的能量相对于全平相位总入射基准的比例 \(\eta_s\)。

预注册比较式为

\[
\eta_s=\frac{S-S_0}{F_0}, \qquad
\eta_d=\frac{G_1}{F_0},
\]

其中 \(S\) 是整形帧的固定目标掩膜内积分，\(S_0\) 是同掩膜内由不可调制 0 级贡献的积分，\(G_1\) 是光栅 +1 级积分。以上均在扣除同曝光暗帧后计算；两种效率分别约为“整形后落入目标的、来自可调制分量的能量比例”和“光栅把可调制分量送入一阶的比例”。分母保留完整 \(F_0\)，不把 0 级或 −1 级等未进入比较区域的能量删去。

**匹配的定义**：在固定目标掩膜与固定积分口径下，\(\eta_s\) 与 \(\eta_d\) 的绝对值之差不超过 0.05，且 95% 自助置信区间上限不超过 0.08；同时顺序交错的重复采集中，两种效率的组内标准差各不超过 0.03。超过阈值只能判为“本比较式下不匹配”，不能直接归因为 SLM 物理效率不足。

## 1. 现有事实与限制

- 2026-11-21 的 0.1 ms 衍射探针帧在 row 方向测到相对 0 级的偏移约 −471 px 与 +189 px；默认探针几何无法定位真实 ±1 级。
- 用 `axis="y"`、`separation_scale=471` 重算得到的级次比例约 0.442 / 0.113 / 0.445，但左右级不对称，且没有同曝光暗帧；该组数字**只作历史线索，不参与本次验收**。
- 5 ms、1 ms 的相位速度采集饱和；0.1 ms 平场峰值约 146、未饱和。本次窗口仍以 0.1 ms 为候选曝光，实际以读回值重新确认，不把历史值当作永久上限。
- A1b 的二维 blaze 映射只在本窗口描述性有效，不能直接写入几何标定文件；本次必须重新测定光栅级次位置，不把历史 `slm_geometry_calib.npz` 当作实测事实。
- 全平相位时 0 级与目标重叠且远强于整形图案。本次允许轻微过曝以便看清弱峰，但效率积分必须在未饱和的独立曝光上完成；过曝帧只能用于定位，不得参与能量计算。

## 2. 比较口径的定义

### 2.1 不可调制基准

将全平相位下的远场中心峰视作 SLM 无法调制的直达分量。在 CCD 原生像元坐标中，以固定窗口积分得到 \(F_0\)；窗口由全平帧峰值和同一窗口下预设的半径确定，写死在采集配置中。

\(F_0\) 不是相机电子偏置。相机偏置通过同曝光暗帧扣除；激光功率漂移通过交错重复的全平参考监测并单独记录。

### 2.2 整形效率

目标掩膜由当前光路下实测的整形落点确定，形状、中心、边长/半径在采集前冻结。掩膜的物理尺寸用当前二维映射换算到 SLM/CCD 坐标，避免假设 panel-x 对应 CCD 行或列。

- 分子：整形帧目标掩膜积分扣除暗贡献，并扣除同一目标掩膜内的 0 级贡献；
- 分母：全平帧 0 级窗口积分扣除同窗口暗贡献；
- 分母保留完整 \(F_0\)：它代表全平相位下测得的总入射基准，未进入目标或 +1 级的部分不能被删去。\(S_0\) 只从分子扣除；若把 \(S_0\) 同时从分子和分母中抵消，得到的量不是本文定义的利用能量效率。

同时报告原始 \(S/F_0\) 作为对照，但不用它对本次“是否匹配”作最终判定。

### 2.3 衍射效率

光栅使用单一连续 blaze ramp，避免二值光栅多级能量分散。先用小范围二维搜索定位 +1 级，再用同一固定半径积分；0 级窗口沿用全平帧定义。

\[
\eta_d = \frac{G_1}{F_0},
\qquad G_1=P_{+1}-D_{+1}, \quad F_0=P_0-D_0.
\]

报告 −1 级作为对称性诊断，不纳入主比较；若 ±1 级积分相差超过 20%，只能判为光路/积分口径未收敛，本次比较作废。

## 3. 采集前离线准备（零设备）

1. 从 A1b 映射生成 grating 与整形目标落点的预测，写死每个图样的搜索 ROI；所有帧保留全幅，物理开窗禁止启用。
2. 生成相位/灰度 SHA256、目标掩膜、积分窗口的机器可读配置；用合成图和历史未饱和帧完成算法自测。
3. 确认三项积分使用同一暗帧、同一背景估计、同一饱和门；检查 12-bit 满量程和读回曝光，禁止逐图归一化。
4. 预注册分析脚本与判据后再申请设备窗口；不得根据新采集结果移动 ROI 或改变掩膜大小。

## 4. 冻结采集矩阵

顺序交错，每相位 4 帧，共 **16 帧**，实际曝光以当次读回值为准：

| 顺序 | 相位 | 目的 |
|---:|---|---|
| 1 | `flat_pre` | 0 级基准与漂移前参考 |
| 2 | `blaze_grating` | +1 级衍射效率 |
| 3 | `shaping_target` | 当前光路远场整形效率 |
| 4 | `dark` | 同曝光暗帧 |
| 5 | `flat_mid` | 中途功率/光路漂移检查 |
| 6 | `blaze_grating` | 第二次独立衍射测量 |
| 7 | `shaping_target` | 第二次独立整形测量 |
| 8 | `flat_post` | 末端 0 级基准 |

每个相位重复 4 次（上表循环 4 轮），每轮记录时间戳、实际曝光、SLM 序列号与要求返回状态、CCD 帧号、激光功率读数和相位哈希。全平参考的相对变化超过 5% 时，该轮标记为漂移轮，不参与平均。

使用 `DeviceLock`；SLM 与 CCD 只能由本进程占用。采集前后按 `docs/dev/hardware_discipline.md` 和 `libs/skills/ao-optical-path-calibration/SKILL.md` 完成设备在线、光路有效、曝光不超量程、SLM 真在调制的检查，并写 `optical_path_record.json`。背对背开关 SLM 之间留 settle 时间；任何驱动板静默回落或假死立即中止，不把错误帧纳入分析。

## 5. 数据与产物

唯一新目录：`data/shaping_efficiency_match/<UTC 时间戳>/`。内部结构至少包括：

- `raw/`：16 张原始帧 + 暗帧，不覆盖历史数据；
- `phases/`：flat、blaze、shaping 的原始灰度/相位与 SHA256；
- `config.json`：冻结的掩膜、ROI、半径、曝光、设备身份、场映射来源；
- `journal.jsonl`：逐帧时间、曝光、功率、相位哈希、采集状态；
- `analysis.json`：\(F_0\)、\(S\)、\(S_0\)、\(G_0\)、\(G_1\)、\(\eta_s\)、\(\eta_d\)、差值、置信区间与每轮数据；
- `optical_path_record.json`：设备/光路标定记录；
- `release.json`：设备释放证据，不把 journal 里的“success”当作释放证明。

## 6. 预注册判据

设 \(d=\eta_s-\eta_d\)，重复轮独立自助抽样 2000 次。

| 判定 | 条件 |
|---|---|
| **匹配（本比较式下）** | `abs(mean(d)) <= 0.05` 且 `CI95(high) <= 0.08`，且两种效率各自组内标准差 `<= 0.03` |
| **不匹配** | `abs(mean(d)) > 0.05` 或 `CI95(high) > 0.08` |
| **不可判定** | 漂移轮超过 1 轮；任一帧饱和；±1 级相对差超过 20%；全平 0 级不可定位；缺少同曝光暗帧；相位哈希或设备身份不符 |

“不可判定”优先于“匹配/不匹配”。效率本身超出 0–1、数学上违反能量守恒时，先按背景/分母口径错误或饱和处理，不做物理解释。

## 7. 差异归因顺序

只有判为“不匹配”时，才按以下顺序排查，并把每一步作为后续独立实验，不混入本窗口的主比较：

1. 若 \(\eta_d\) 明显高于 \(\eta_s\)：比较 blaze 与整形相位所需空间频率；检查整形掩膜是否过紧、目标落点和二维轴映射是否偏移。
2. 若 \(\eta_s\) 明显高于 \(\eta_d\)：检查目标内 0 级扣除是否过度、光栅 +1 级 ROI 是否遗漏旁瓣、暗帧是否不匹配。
3. 若两次同相位结果自身离散：检查功率/曝光漂移、SLM 响应稳定时间、相机触发与时序。
4. 若 ±1 级不对称：检查入射角、像差、有限口径与离轴几何，不把单级结果直接称为衍射效率。

## 8. 本次明确不回答的问题

- 不测 SLM 像素本征上升时间；相位速度探针测的是 SLM+CCD 的组合响应。
- 不训练或选择模型，不用本实验更新几何标定、LUT 或控制闭环参数。
- 不把 5 ms/1 ms 饱和帧或早期无暗帧探针数据作为比较证据。
- 不把轻微过曝的定位帧与未饱和的积分帧混用。
- 不承诺两种效率必须相等；本实验只检验上述明确口径下是否匹配，并以预注册阈值给出可复核结论。
