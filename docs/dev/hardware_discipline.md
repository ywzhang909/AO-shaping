# 硬件设备纪律（SLM / CCD / 激光）

> 外迁自根 `AGENTS.md`「🔴 必读」。所有 AI 工具与脚本（含后台运行）都必须遵守。

任何占用物理设备的操作（采集、探针、诊断脚本），**开始前和结束后**都必须在回复中
**明确报告**：

1. **占用了什么设备**（SLM #编号 / 相机 / 激光）；
2. **做了什么**；
3. **何时释放**；
4. **是否正常关闭**。

采集类脚本须在后台运行时同样遵守。设备被占用期间**不要并行启动第二个占用同一设备的
进程**（脚本自带 `--wait-until-idle` 时可用）。

> 相关：`data_debug_cleanup.py` 的"在飞保护"（`--min-age-hours`，默认 12 h）与
> `scripts/_common/` 下的 `--wait-until-idle` 约定——搬走正在写的 run 会毁掉在飞工作，
> 宁可漏搬，不可搬错。
