## 0. 总则（先于任何具体词条）

1. **只改中文叙述**，不改代码。代码标识符（变量名、函数名、CLI 参数、类名、
   模块名、mermaid 节点标签、行内 `` `code` ``、围栏代码块）一律**原样保留**，
   即便其中含 `pupil`、`bench`、`实机` 等字样。
2. **英文叙述保留英文**。若某句上下文是纯英文（本地 ±40 字符窗口内无汉字），
   `pupil`、`bench` 等保留英文原词，不强行夹注中文。`bake-off` 自 2026-10-17
   起**不再保留英文**：中文叙述一律用**对比择优**（见 T-50），仅纯英文上下文
   仍保留 `bake-off`。
3. **首现夹注**。`pupil` 在中文叙述中**首次出现**时加一次中文
   释义（`pupil（瞳面）`），同段/同文档后续出现可省略
   夹注，但**不得**出现双重夹注（`（瞳面）（`）。
4. **不丢数据**。术语替换是纯措辞改写，任何数值、单位、公式、参数、路径、
   DOI、引用编号必须逐字节保留。改写后跑 §5 的守恒校验。
5. **新增词须登记**。若出现下表未覆盖的新口语词，先在本文档 §3 登记再替换，
   并在提交说明中注明，禁止私下引入同义词。

> T-60 说明：代码标签为 `freeform`（`slm_model_in_loop.py::_holdout_phase` 返回的字面量
> 标签，与 `smooth` / `zernike` 并列）。三者都是去均值、标准差缩放到 `probe_spread` 的
> 随机瞳面相位，区别只在空间频率上是否带限：`smooth` 经 `gaussian_filter` 带限、
> `zernike` 只取 Noll 4–11、`freeform` 不做任何空间平滑，功率铺满全部可表示频率。
> 故规范中文名取「全频随机相位」而非按 `freeform` 直译——直译出的「自由」不携带任何
> 可检验的物理信息，而「全频」直接说明它把约 93% 的光散出 0 级的原因。
>
> **T-60 的适用范围仅限上述随机探针。** 它不适用于 GS 优化得到的相位：后者不是随机场，
> 而是确定性优化解，其「自由」指的是**逐像素相位自由度**（`AGENTS.md` 英文原文
> "full-pixel phase freedom"），与探针的空间频率带限无关。把「GS 自由相位」写成
> 「GS 全频随机相位」会把一个可检验的断言变成假的（GS 相位并非随机，也不以散出 0 级为特征）。

> T-61 说明：规范词取「逐像素相位」以与仓库既有措辞一致（`docs/`、`report/` 已用
> 「逐像素相位」6 处，`AGENTS.md` 用 "full-pixel phase freedom"）。代码标签仍是
> `gs_freeform` / `freeform`，属标识符，由 §2 保护，不改写。
> **规则顺序要求**：T-61 必须先于 T-60 的裸词规则执行，否则 GS 语境会被 T-60 吞掉。

## 5. 自动化校验（CI / 提交前）

```bash
# 1) 术语统一（dry-run 先看统计，--apply 才写盘）
python3 scripts/_common/term_unify_20261016.py            # dry-run
python3 scripts/_common/term_unify_20261016.py --apply    # 写入

# 2) 守恒校验：关键数值/单位必须逐字节保留（示例，按需扩展）
git diff -U0 | grep -E '^[+-]' | grep -vE '实验|瞳面|加性背景|pupil|bake|弥散|转移|对比择优' \
  | grep -E '[0-9]+(\.[0-9]+)?\s?(ms|nm|mm|px|rad|×|\%)'   # 应只看到措辞行，无数据行
```

**验收标准（提交前必须全绿）：**
1. `term_unify_20261016.py` dry-run 输出 `0` 个文件（已收敛）。
2. 无双重夹注 / 无中文语境 `bake-off`：`git grep -E 'pupil（瞳面）（|bake-off（对比择优）|bake-off（强制对比择优）'` → 空；
3. 无残留口语（正文）：`git grep -E '平场泄漏|台架|实机|真机|上机|瞳孔|跑通|打散|灌进|钻空子|金标准|围栅' -- '*.md'` 的命中**全部**落在 §2 的 DO-NOT-TOUCH 集合（代码/英文/mermaid/生成文档）内。
4. 数据守恒：改写前后每个数值/单位字符串计数一致（脚本内置 `must` 清单，见脚本头注释）。
5. 无残留「留出」（正文）：`git grep -E '留出' -- '*.md'` 的命中**全部**落在 §2 的 DO-NOT-TOUCH 集合内（代码标识符 `holdout*`、数据表 `holdout_*` 标签、行内 code、围栏块）；中文叙述一律「验证集」（T-62）。注意 `holdout` 英文标识符与 `留出` 中文词是两套体系：只统一中文叙述，`holdout_*` 数据列名、`--holdout-probe-count` CLI 参数、`freeform_holdout_count` 字段一律保留。
