# 跨光路 model-in-loop：探测、物理模型迁移学习、可微优化与 FAQ

更新时间：2026-10-19。适用于更换相机位置、改变入射位置、功率或像差后的工作交接。
本手册给出可执行入口、验收顺序和待完善内容；不保证任意光路均能被当前模型描述。
实验依据见 [2026-10-19 报告](../../report/shape_trials/model_in_loop_live_20261019.md)，
标准配置示例见 [自动化交接手册](model_in_loop_handoff.md)，
聚焦工具详见 [定位与校正说明](slm_alignment_probe.md)。

## 2. 完整流程与各阶段产物

### 2.1 确认设备和建立本次会话

记录相机型号/序列号、分辨率、ROI、增益、黑电平、位深、SLM 编号、波长、LUT、
光路配置和代码版本。释放其他程序的设备连接；一个测量序列内不调功率、衰减片或光路。
将数据保存至 `data/debug/<工具名>/<本次唯一目录>/`，保留失败记录。
相机 SDK 在受限进程枚举失败时，先排查进程权限和占用，不能直接认定设备离线。

在仓库根目录准备导入路径，先离线检查已有配置：

```powershell
$env:PYTHONPATH="${PWD}/src;${PWD}/libs"
python scripts/slm/model_in_loop_auto.py path/to/bench_profile.json --dry-run
```

标准新会话使用同一脚本去掉 `--dry-run`。高级校正流程使用下述独立工具及主 CLI，
不要向自动脚本 JSON 添加尚未支持的参数。

### 2.2 相机响应、自动曝光和时间漂移

从设备查询允许曝光范围，在当前显示相位下逐档探测，检查饱和比例、峰值及信号强度；
所有后续比较使用实际回读曝光。历史 `0.4 ms`、`0.6 ms` 均不是永久上限。
正值环境上限是当前实验约束，未设置或为零时走画面探测；Daheng 使用
`AO_DAHENG_MAX_EXPOSURE_MS`，其他型号须核对其驱动的曝光能力。
平相位很亮、全频随机相位很暗时，应分别确定可测曝光，不能仅沿用平相位的曝光档。

固定相位、固定功率采集多档曝光及重复帧，检查背景扣除后的信号是否与曝光成比例。
局部半曝光复测只证明局部响应，不能代替整个曝光区间标定。
可比较单调 LUT、多项式、双指数、Bezier 或逻辑响应，优先选独立曝光留出误差小且
反演稳定的方法；这些响应族是待比较的方法库，本轮没有完成其全面标定。
有真暗场时做逐像素偏置/暗电流校正，有合适均匀照明时再做逐像素平场校正。
高衰减滤光片不能证明电子偏置或暗电流为零；无法遮光时须明确暗场未测。

交替插入参考相位，记录时间戳、曝光、原始强度、质心及宽度。漂移不合格则中止本序列，
保留数据并重新测量，不能把时间漂移交给静态像差模型吸收。

### 2.3 入射位置、聚焦、对称性和 CCD 中心

先用全板响应定位实际受照区域；SLM 面板中心和 CCD 光斑中心属于两个坐标系。
粗扫描后细化入射中心与覆盖范围。单张弥散光斑无法唯一确定离焦量及其符号，
应加载正负二次相位扫描，必要时扩展范围，再局部细化。
在聚焦状态扫描两个彗差方向，以重新居中的左右/上下镜像误差和 RMS 半径共同评价。

```powershell
python -m ao_shaping.tools.slm.panel.alignment_probe --output data/debug/alignment_probe/session_001 --center-x 960 --center-y 720 --radius 450 --focus-points 9 --diopter-range 0.5 --coma-points 5
python -m ao_shaping.tools.slm.panel.alignment_probe --verify-directory data/debug/alignment_probe/session_001 --output data/debug/alignment_probe/session_001_verify
```

上述面板中心和半径仅为示例，必须替换为本次探测值。校正相位退出时不保留在设备上，
后续必须显式加载 `correction_phase.npy`。工具保存未包裹弧度，统一由驱动转换。
校正后重新确定 CCD 中心，报告重复性；没有绝对位置参考时不报告绝对定位准确度。

### 2.4 在相同校正状态下重测几何

以同一组合校正采集参考相位、两个倾斜方向及离焦等 Zernike 响应，确认坐标方向、
像素尺度、旋转/镜像、裁剪中心和视场覆盖。命令示例：

```powershell
python scripts/slm/model_in_loop_hw_runbook.py --stage sweep --out data/debug/model_in_loop_hw_runbook/session_corrected --pupil-center 960,720 --region 128 --far-field-size 1024 --collect-disc 450 --zernike-radius 450 --exposure-ms 0.1 --phase-offset-file data/debug/alignment_probe/session_001/correction_phase.npy
python scripts/slm/model_in_loop_hw_runbook.py --stage calibrate --out data/debug/model_in_loop_hw_runbook/session_corrected --region 128 --far-field-size 1024 --collect-disc 450 --zernike-radius 450
```

曝光、中心及半径都要根据本次画面调整。核对 `phase_offset.npy`、Recorder 的实际总相位
和 `bench_geometry.json`。束腰不可辨识、尺度交叉检查矛盾时保留警示，
不能仅凭几何拟合相关性继续宣称模型可靠。

### 2.5 采集迁移学习数据：实际改变相位并读 CCD

相位数据必须对应实际下发指令，包含基线校正、载波及本次探针，不可只保存优化变量。
每条记录至少关联相位文件/数组、实际曝光、原始帧、相位族、随机种子、
采集 UTC 时间、轮次、几何和设备配置。几何扫描与定位工具现已保存 UTC 微秒字符串；
微秒格式表示记录分辨率，不表示相机具有微秒级同步精度。

训练覆盖平滑随机相位、多阶 Zernike 和计划优化使用的空间频率、幅度范围。
独立留出使用不同种子，并包含全频随机相位及目标附近相位；按相位族、会话拆分，
不要将同一相位的相邻重复帧分入训练和留出造成信息泄漏。
本轮 16 个训练探针、4 个标准留出和 2 个全频随机相位留出是诊断设置，
不是任意光路通用的样本数保证。全频随机相位留出失败提示训练覆盖或模型表达不足。

### 2.6 迁移学习正向物理预测模型（Step A）

模型概念上为：

$$
I_\theta=\left|\mathcal{P}_G\{A\exp[i(\phi_{cmd}+\phi_{bias}+Zc)]\}\right|^2,
\qquad D(t)=R\{t(gI_\theta+B_{stray})\}+b_{dark}(t)+\epsilon .
$$

其中实际已知校正为 `phi_bias`，`Zc` 为待估残差像差，`G` 为传播几何，
`R` 为相机数字响应，暗偏置单独表示。该式是建议的数据解释模型；
当前代码没有同时实现其中所有可训练项。在线 Step A 主要调整低参数 Zernike 系数，
增益和相位无关加性背景由训练数据拟合，不能用留出图像重新调参后再报留出分数。
CCD 对应强度，不能用场振幅代替强度作为观测量。

先冻结可靠几何，迁移少量物理参数；检查训练损失、系数范数、增益、背景和独立预测。
每个相位族分别报告相关性、残差图、质心、宽度及强度范围；同时报告各样本和最差值。
当前默认相关性下限 `0.5` 是软件门槛，不是充分的光学质量标准；
所有留出均需通过，平均值通过不能覆盖个别失败。

有效 checkpoint 必须匹配网格、几何、相位映射和曝光约定。
`--forward-checkpoint` 用于兼容的模型；`--prior-run-dir` 还要求已验收整形记录，
不能拿此次被拒绝目录直接当热启动。被拒绝时保存的系数可能是回退状态，
不一定是拒绝前训练最优系数。

### 2.7 冻结模型、可微优化输入相位（Step B）

留出通过后冻结正向模型，选择方形、矩形、三角形、星形或圆形目标，
明确相机像素尺寸、目标内部/边界定义及零级掩码。通过可微传播反向更新输入相位，
再将候选实际显示并采集 CCD，按真实指标接受或回退；模型内结果不能替代 CCD。

主 CLI 为 `python src/ao_shaping/main.py --debug slm-model-in-loop`。
高级配置可用 `--geometry-file`、`--phase-disturbance-file`、`--pupil-oversampling`、
`--probe-count`、`--holdout-probe-count`、`--step-a-iterations`、`--step-b-iterations`，
具体完整调用先通过 `--help` 核对，并保持几何测量与运行网格一致。
`--w-uniformity` 和 `--w-efficiency` 控制已有目标权重。
已有底层相位平滑项尚未完整暴露为本流程 CLI 参数，不能直接使用臆造的平滑开关。

纯均匀度、零 EE 权重仅适合短时诊断：目标区域趋暗也可能使 CV 表观降低。
正式验收要求有足够信号及 EE 下限，分别报告完整区域 CV、去零级 CV、EE、IoU。
可探索平滑基底、相位梯度约束和有限带宽模型，但要独立测量其对均匀度与能量的影响。

### 2.8 固定曝光验收、归档和下次恢复

对候选与基线做交替顺序重放；同一比较使用相同曝光、ROI、增益和掩码。
平相位和整形相位动态范围不同时，可分别设置各自的固定曝光，但相同类别的 A/B
必须相同曝光。当前固定曝光重放工具只验证了 Daheng，不能宣称无修改支持所有相机。
保存每次原始帧，报告均值、样本标准差、漂移、饱和情况以及实际显示总相位。

归档内容包含：配置和代码版本、探测结果、校正相位、几何、相机响应、训练/留出索引、
模型、逐轮候选/回退原因、实际指标和最终重放。恢复时先做短参考复测：

| 变化                      | 优先重测                             | 可考虑复用的内容       |
| ------------------------- | ------------------------------------ | ---------------------- |
| 功率/曝光改变             | 响应线性、信号范围、漂移、增益       | 几何需短探针验证后复用 |
| CCD 横向位置改变          | 中心、ROI、坐标映射                  | SLM 入射位置需响应确认 |
| CCD 轴向或透镜改变        | 聚焦、彗差、中心、完整几何、独立留出 | 历史相位仅作对照       |
| SLM 入射位置/光斑大小改变 | 全板定位、照明范围、几何和模型       | 相机响应需快速复核     |
| 像差改变                  | 相同几何下多相位族残差迁移与留出     | 已验证几何及响应       |
| 目标形状/带宽改变         | 对应带宽留出、目标尺寸与固定曝光验收 | 合格模型可作为初值     |

上述按变化选择的缓存恢复是下一步工程目标；当前自动脚本偏向新会话重测，
尚未实现全自动指纹缓存及全部条件恢复分支。

## 3. 后续可行方向及验证顺序

1. **先解决照明与传播不匹配。** 实测偏心、椭圆和截断照明；比较少参数椭圆高斯
   与低分辨率非负振幅网格。联合拟合时约束与 Zernike 的退化，保留独立相位族验证。
2. **统一实际相位映射。** 以真正下发的相位为输入，比较 1×/2×/4× 采样、面板插值、
   有限像素填充、相位标度及点扩散函数（PSF）。不能以插值制造的自由度冒充硬件自由度。
3. **完善数据覆盖和相机校正。** 增加多带宽训练探针，曝光响应独立留出；
   对加性背景先线性化后拟合，或按曝光拟合，比较跨曝光预测。
4. **模型通过后再改匀化。** 在同一非均匀方斑初相位上比较平滑、低维相位更新、
   加权 GS/混合振幅反馈及可微目标，单独检验“梯度过大”的假设。
5. **零级处理分为指标与光学两层。** 固定规则识别掩码，同时报告去除前后 CV；
   载波扫描使信号与零级分离，结合空间滤波。线性相位只偏转调制光，不消灭零级能量。
6. **深度残差作为后续补充。** 物理模型先合格，再比较小残差网络、混合模型与 U-Net；
   对同一批留出帧、相同曝光和相位族测相关性/CV/EE、参数量和适配耗时。
7. **多帧与多平面方法需对应实验条件。** 时间复用可以测试积分均匀度和速度代价；
   单色静态相干场不能无条件按非相干强度相加，多距离计算本身不会消除真实散斑。

## 4. FAQ

**Q1：是否已实现任意光路一键匀化？** 还没有。已有会话自动化及分阶段工具，
本轮全频随机相位预测仍失败；不能把“自动拒绝”写成“自动完成匀化”。

**Q2：聚焦改善很大，为什么整形仍失败？** 聚焦改善局部集中度；
整形还要求模型准确预测复杂相位下的整个图像。入射振幅、采样、几何和背景仍可能失配。

**Q3：从光斑宽度能直接推算相机移动多少吗？** 不能唯一确定。
扫描得到 SLM 等效补偿焦度，换算相机轴向位移还需要光路传递关系。

**Q4：彗差系数为零是否证明没有该方向彗差？** 否。只代表当前范围和验收规则未保留
非零候选；遮挡、像散或相干杂散光也可能造成不对称。

**Q5：中心标准差约 0.05 px 是否等于绝对定位误差？** 否，这是重复性。
校正还可能改变真实中心，缺少外部位置参考时不能声明绝对准确度。

**Q6：几何相关性 0.85，为何全频随机相位相关性只有约 0.26？** 前者描述少量宽度响应，
后者描述独立图像预测，两者评价对象不同；尺度冲突和不可辨识束腰仍应记录。

**Q7：平均留出相关性大于 0.5 为什么拒绝？** 因为部分相位族仍明显失败。
本轮高信号数据平均约 0.642，但两个全频随机相位仅约 0.241 和 0.277。

**Q8：增加采样或曝光能否解决问题？** 本轮两者后全频随机相位相关性有所提高，仍未合格。
不同运行使用新采集帧，尚不是同帧单变量因果对照。

**Q9：自动曝光为什么还会出现低信号？** 由明亮参考相位推导的工作范围可能限制
弥散相位；应针对相位族复核，并用当前设备范围、画面与响应标定决定工作曝光。

**Q10：只除以曝光就能去除曝光影响吗？** 只有在响应线性且偏置已处理时成立。
饱和、短曝光非线性、黑电平和相干背景都需要另外建模或排除。

**Q11：滤光片衰减很高，可以忽略背景吗？** 可以作为待验证近似，不能替代暗场测量。
本轮没有真实遮光暗场；局部边界中位数也不是逐像素暗场参考。

**Q12：相位校正是否要在每个阶段重复叠加？** 是，但只能叠加一次。
确认几何、训练、留出、候选、重放使用相同基线；检查保存的总相位，避免遗漏或重复。

**Q13：CV 下降是否必然意味着匀化成功？** 否。目标可能变暗、移出 ROI 或被过大掩码
剔除。需要原始信号、完整 CV、去零级 CV、EE、形状与重复测量共同判断。

**Q14：去零级掩码能否每张图自由调整？** 不宜。固定检测规则并保存掩码，
报告剔除面积；不能借掩码排除任意不均匀区域。

**Q15：有 `best_phase.npy` 是否表示该次优化成功？** 否。失败时仍可能保存基线或
此前已验证状态。先读状态、接受轮数和留出拒绝原因，再判断相位文件意义。

**Q16：怎样复用迁移结果？** 先核对设备、相位映射、几何、基线校正及响应约定，
再做快速独立留出。被拒绝目录不能直接作为已验收热启动；历史曝光不可永久继承。

**Q17：本轮 U-Net 是否已完成同帧对照？** 没有。本轮测试集中于低参数物理模型，
没有新增有效的 U-Net 同帧迁移对照；不能将历史指标当作当前光路结果。

**Q18：后续最先做什么？** 先补足照明振幅与多带宽相位数据，解决全频随机相位留出，
再比较不同匀化策略。继续增加 Step B 迭代无法修复错误的正向物理关系。

**Q19：时间戳如何用于速度比较？** 逐条记录采集时间并区分设备等待、曝光、模型拟合
和目标优化耗时；同时报告达到同一 CV/EE 条件的总时间。只有总文件时间不够。

**Q20：换其他相机还需修改什么？** 使用统一相机创建入口，并验证曝光单位、范围回读、
位深、原始帧与稳定采集接口；重新标定响应。固定曝光重放及部分设备探针仍有型号边界，
必须逐项适配验证，不能仅替换型号字符串。
