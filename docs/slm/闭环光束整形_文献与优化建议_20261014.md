# 闭环光束整形：文献检索 × 实验结果 × 优化建议（2026-10-14）

> **本文件性质**：人工撰写，**不含任何新测量**。§1 的全部数字来自本仓库已归档的
> 实验/离线报告（相对链接见各节），§2 文献数字经 CrossRef DOI 逐条核实（文末附验证
> 链接），§3 为**提案**（按收益/成本排序，未在本实验系统逐条验证）。
> **本文档不改任何代码**；§5 的改进清单以 GitHub issue 形式单独立项（见文末 issue 号）。

## 0. 一句话

闭环整形当前的瓶颈**不是 GS/SPGD 搜索本身**（GS 金标已逼近纯相位 SLM 的理论上限，
SPGD 增量可忽略且被慢漂移污染），而是**正向模型的保真度**（freeform 验证集比 Zernike 验证集
低 0.05–0.09、freeform 残差 NRMSE 0.677–0.800）与**几何/像差的静默耦合**（几何误差被
Zernike 拟合吸收后由 Step B 固化）。提效的正确顺序是：先把已有 LUT/串扰标定接进正向模型
（P0-1），再上几何哨兵 + 一致性校验（P0-2/3），然后才谈加迭代/加模型自由度。

**三个根因（按影响排序）**：

1. **几何/像差静默耦合**（[online_recal_efficiency §1](../../report/shape_trials/online_recal_efficiency.md)）：
   Step A 把几何误差"解释"成 Zernike，Step B 再冻结成相位——全程不报错。
2. **freeform 表达力缺口**：Zernike 基（哪怕 n_max=15）填不满 100 px 方形
   （[shape_trials README](../../report/shape_trials/README.md)：最佳 CV 2.46、仅 164/10000 超半峰）；
   全频随机相位验证集相关性系统性更低。
3. **SPGD 梯度被慢漂移污染**：delta 1000× 全扫描 8 档无一收敛，瓶颈是慢漂移而非 delta
   （[H-14]，[slm_pib_bench delta_scan](../../report/slm_pib_bench/delta_scan.md)）；
   夜间热稳后噪声底改善 ~20×。

**文献给出的三条硬结论**：
- **纯相位 SLM 方斑的天花板低于复振幅**（L3/L19）：你仿真 GS 金标 0.8543 已接近该天花板，
  继续堆 GS 迭代收益递减（与你 400 步更差的实测一致）。
- **数据驱动（U-Net）必须配物理/可微模型监督**（L17/L18）：纯网络在真实帧相关性≈0
  是结构必然，不是数据量问题——要改成"物理模型 + 残差网络"。
- **无传感整形应分阶段（低阶→高阶）并做串扰/非线性标定**（L11/L7/L8）：与你"两档参数
  切分 + LUT"的直觉一致，但当前 LUT **未接进** Step B。

## 3. 优化建议（按 P0→P3 排序，每条含依据与验收）

> 全部为**提案**。优先级原则：先消除"静默失效"（几何/标定），再谈"提性能"（迭代/自由度）。
> 每条标注"是否改变默认行为"，与仓库 model_free_ao_survey 的"加法优先"原则一致。

### P0（消除静默失效，低-中风险）

**P0-1 把 LUT + 串扰标定接进正向模型与 Step B**（改变默认行为）
- 现状：`src/ao_shaping/tools/slm/calibration/lut_runner.py`、`calibration.py`、
  `cartographer/phase_grayscale_lut.py` 已实现灰度↔相位 LUT，但 `ForwardBank`
  （`src/ml/shaping/physics.py`）与 `slm_gs_refine` / `slm_model_in_loop` 的相位写入
  **未走 LUT 补偿**，也未建模像素串扰。
- 文献：L7（串扰优化标定）、L8（相位非线性补偿）、L9（模式投影交叉验证）。
- 动作：Step B 下发相位前先经 `lut_inverse`（phase→gray），正向模型加入 crosstalk 低通项；
  用 L7 的随机串扰优化式标定替代纯解析 LUT。
- 验收：**独立运行** freeform 验证集 NRMSE 从 0.677–0.800 降到 Zernike 族水平（<0.524），
  且总相关性不掉。

**P0-2 几何 3 写入门哨兵，驱动已有升级阶梯**（中风险，改运行时）
- 现状：42 点几何 sweep（43 写入）每次全跑；3 写入门哨兵（1 平场 + 2 tilt）便宜 14×。
- 文献：L7（10 图案 ~5 min 标定的量级参照）、[online_recal_efficiency §5.2](../../report/shape_trials/online_recal_efficiency.md)。
- 动作：复用 `SlmModelInLoopConfig` 已有的升级阶梯（probe_count 8 / escalate 2 / max 16 /
  连拒 3 中止），**把触发源从 Step A 像差 loss 换成几何哨兵**。
- 验收：光路未动时省 ~14 帧；光路真动时升级阶梯能触发（不"该升不升"）。

**P0-3 Step A 加几何一致性校验，拒绝"几何被当像差"**（中风险）
- 现状：Step A 的 Zernike 拟合会把几何误差吸收进系数，Step B 再冻结（静默失效）。
- 动作：Step A 后检查倾斜/离焦残差的尺度偏差，超阈**拒绝该轮**（不进 Step B）。
- 验收：构造"几何故意错"的对照，确认校验能拦截（对应 online_recal_efficiency §8 的待办）。

**P0-4 加"形状相似度"验收指标**（低风险，纯加法）
- 现状：`accepted` 只表示综合分高于自身平场，**不代表形状达标**；五角星仅比平场高 0.0228
  也算 accepted。
- 文献：L24（PIB）、L19（CV/EE 权衡）。
- 动作：加 Hausdorff 距离（实测强度轮廓 vs 目标掩模轮廓）或轮廓重合度作为**独立**验收，
  与 CV/EE 并列。
- 验收：五角星/三角形在 Hausdorff 上应显著差于方形（暴露"分数达标但形状不达标"）。

### P1（提性能，中风险）

**P1-1 两档参数切分 + 升级阶梯**（改默认）
- 依据：[fast_recal_adapter §7](../../report/shape_trials/fast_recal_adapter.md)（14 低阶 Zernike
  是低阶赌注）、[online_recal_efficiency §5](../../report/shape_trials/online_recal_efficiency.md)。
- 文献：L11（多阶段 ASPGD）、L5（多阶段加权 GS）。
- 动作：默认 14 低阶 Zernike；几何 2 标量由哨兵（P0-2）触发；加**高阶哨兵**——低阶适配后
  EE90/CV 仍不达标则升 14+2 或更强先验（低阶适配在高阶漂移下会帮倒忙）。
- 验收：低阶漂移 4 帧饱和（Δcorr +0.4）；高阶漂移不误判为"已适配"。

**P1-2 模型候选选择改用独立 freeform 验证集**（改默认）
- 现状：用训练 loss 选模型会选错（[next_steps §2](../../report/shape_trials/model_in_loop_next_steps_20261013.md)）。
- 文献：L17（数据驱动需独立验证集）、L18（可微模型监督）。
- 动作：保留零系数/旧系数/短拟合三候选；用**未参与选择**的 freeform 验证集选择，
  再用另一张新 freeform + 成形相位做最终验收。
- 验收：所选模型在"未参与选择的运行"上 freeform 相关性同时改善（不看训练损失）。

**P1-3 freeform 相位带宽受限 + 残差正则**（改默认）
- 现状：逐像素全频随机相位名不副实（[H-12]），full-per-pixel 自由度过大导致 freeform 验证集系统性低。
- 文献：L3/L19（相位带宽受限是纯相位 SLM 的物理约束）、L21（相位光栅叠加热仿真）。
- 动作：逆设计相位带宽受限（低通 freeform 基）；反馈从纯 Zernike 改 "Zernike + 受限残差"。
- 验收：freeform 验证集相关性从 0.75–0.78 抬到接近 Zernike 族（0.81–0.84），CV 不升。

### P2（仿真保真 + 数据集，中-高风险）

**P2-1 正向模型闭环准入判据**（改验收标准）
- 现状：物理模型 freeform 相关性 0.7965、NRMSE 0.677–0.800，**未达**全频随机相位准入。
- 文献：L17（可微模型是数据驱动的兜底）。
- 动作：正向模型只在"独立运行 freeform 验证集相关性 ≥0.8 **且** NRMSE 低于 Zernike 族"时才
  允许驱动闭环；否则物理模型继续主导。
- 验收：跨运行验证集一致性（不是单次 0.8 就放行）。

**P2-2 ml 仿真注入结构物理，补仿真-硬件差距**（改仿真，不改硬件）
- 现状：正向模型标定到 +0.867，残差为杂散光 + 真实相位分辨率，**非低通可解释**
  （[gs_refine_fwdmodel_calibration §3.2](../../report/shape_trials/gs_refine_fwdmodel_calibration.md)）。
- 文献：L7/L8（串扰/非线性）、L21（相位光栅叠加热）、L17/L18（可微仿真范式）。
- 动作：在 `ml/shaping/physics.py::ForwardBank` 注入：相位非线性/串扰（接 P0-1 的 LUT）、
  相位低通（带宽受限）、零级泄漏、CCD PSF；**用逐运行 freeform 验证集 NRMSE + 形状 CV/EE
  验收**，不用相关性（相关性对尺度/PSF 不敏感，见 fast_recal_adapter §4）。
- 验收：独立运行 freeform 验证集 NRMSE 下降，且方斑 CV/EE 在独立运行上改善。

**P2-3 U-Net 数据集扩容 + 残差/混合架构**（改 ML，暂不进闭环）
- 现状：U-Net 真实帧相关性 ≈0.03，训练集仅 47 历史相位、与 13 测试相位无重合。
- 文献：L17（数据驱动 PSF 需物理监督）、L6（CNN 出初相位 + GS 精修）、L5（hybrid）。
- 动作：扩容跨日、跨相位族训练集 + 独立验证集验证；架构改"物理模型 + 残差 U-Net"
  （网络只学残差，不学整图）；**先不进 Step B**。
- 验收：独立验证集 freeform 相关性显著 >0.03，且 CV/EE 在独立运行上改善，才谈实验门槛测试。

**核心判断**：你的 GS 金标（仿真 0.8543）已逼近纯相位 SLM 上限，**继续堆 GS/SPGD 迭代
收益递减**（实测 400 步更差）。仿真侧的杠杆不在"更多迭代"，而在**让仿真更贴近硬件**
（注入串扰/非线性/带宽），从而让 freeform 验证集 NRMSE 降下来——这才是 100 px 均匀方形
能否实现的关键。
