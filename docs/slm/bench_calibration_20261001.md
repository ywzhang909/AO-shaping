## 3. 本次会话中**被推翻的三个结论** (自我纠错记录)

诚实记录, 因为它们都曾被写进分析:

### 3.1 "激光功率漂移 3×" — **推翻**

我曾根据"同一 0.4 ms 平场在 2 分钟内读数 194 → 64"推断激光漂移 3×。
§2.3 的 62 秒连续测量证明 peak cv 仅 **1.1%**。真实原因是
**`SLM.open()` 后的前几次采集未弛豫**, 不是激光漂移。

### 3.2 "第一个转移矩阵全是噪声" — **推翻 (测量协议错误)**

首次 576 单元转移矩阵测量得出 `cell/flat 比值 = 1.0`, 即"全是噪声"。原因是我
用了**固定 0.3 s 等待 + 1 帧丢弃**。台架事实 4 明确警告: LCOS 翻转时间估计
**低报**(会报 0.0 ms), 同一斜坡相隔 3 s 读出的 FWHM 是 43.2 px vs 12.8 px。
**等待不是稳定化**。改用稳定性判据后, 噪声降至 0.67 counts RMS/px。

### 3.3 "ROI 里 92% 是背景" — **推翻 (分析 bug)**

我曾用 `frame.shape[0]//2` 取框中心, 但 `_img` 是**全帧** (1944×2592), 中心在
y=972, 而光斑在 y≈1026 → **光斑落在框外**, 量的全是背景。
正确结果: 光斑总能量 ≈ **1.66e4** counts, 100 px 框内光斑占 **~61%**;
box sum cv = **0.20%**。

> **教训**: 观测量选错会把好仪器测成坏结果。ROI-wide L2 范数由读噪声主导,
> 而 box sum / 峰值信噪比高得多。

## 4. 2026-10-01 `slm-gsnet spgd` 实机失败的根因

运行参数: `--cam_type daheng --cam-id 0 --exposure_time_ms 1.5 --cam_size 300
--target-side 100 -c shape --zernike_radius 450 --objective quality
--delta 0.2 --lr 0.02 --optimizer_type adamod -e 80 --debug`

| 判据 | 值 | 判读 |
|---|---|---|
| `dec` | 0.487 | 随机游走 |
| `sustained` | **−35.9%** | 变差 |
| `best` | +0.0% @ epoch 0 | **最优就是初始态** |
| CV 项 / EE 项 | +0.0118 / **−0.0792** | 牺牲 6× 环围能量换微小均匀性 |
| `max_brt` | 225 → 17 | 光斑被彻底打散 |

**四个独立缺陷** (均已修复, 见 §6):

1. **满幅随机初始化摧毁起点**。`rng.uniform(-π,π)` 使起始即为最差散斑;
   实测平场是最佳聚焦态 (FWHM 13.6 px), 而随机初始化让 peak 225→17,
   且随机态的 EE (0.158) 反而**高于**搜索找到的任何值。
2. **目标函数无绝对能量项**, 可被"散光换 CV"钻空子。
   `square_encircled_energy` 的**分母是全图**, 所以它对整体变暗完全免疫,
   只能靠"光散到框外"被检出 —— 这正是硬件上发生的事。
3. **无能量门** → 上一条被充分利用。
4. **每轮最后一次写屏是"被否决的 −δ 扰动"**, 面板实际停在离 `_params` 有
   2δ 远的状态, 而循环以为自己在 `_params`。这是状态失配。

> **不是台架的硬限制**: §2.3 台架稳定, §2.4 曝光线性, 且实测**稠密 ±0.5 rad
> 随机相位并不会清空目标框** (box 能量 −0.23% ± 2.58%, FWHM 13.65 px 不变)。
> 换言之 freeform 基底是能控制远场的, 失败在优化器实现。

## 5. 仿真必须对齐的清单

| # | 仿真需修正 | 正确值 / 做法 |
|---|---|---|
| 1 | 光瞳模型 | **不是 450 px 硬边圆盘**。实测相位调制在距光斑中心 1000 px 处仍有响应; 面板照明比标称半径宽得多。需按实测有效光瞳建模 |
| 2 | `PANEL_RES` 约定 | 驱动是 `(1920,1200)` = **(W,H)**, 灰度数组 `(1200,1920)`; 管线 `place_on_panel` 曾当 (h,w) 用 → 转置 bug |
| 3 | 焦距定标 | 用实测 **7400/P**, 不要再用文档里的 132940/P |
| 4 | CCD 像素 | **2.2 µm** (不是 `slm_bench_probe` 注释外的猜测值); 由此 K=7557 |
| 5 | 曝光下限 | 仿真/脚本取曝光 **≥ 0.4 ms**; <0.4 ms 读数紊乱 |
| 6 | 稳定化 | **不能用固定等待**, 必须用"连续两次读数一致"的稳定性判据 |
| 7 | 平场优先 | 任何测量必须**先写平场**, 否则测到上次图案的散斑 |
| 8 | 观测量 | 用 **box sum / 全图 sum** (cv 0.20%), 不要用 peak (不可复现) 或 ROI-wide L2 (读噪声主导) |
| 9 | freeform 基底 | 24×24 → **80×50 px 分块** (`np.kron`), 不是逐像素; 576 DOF 中几何受照约 189 |
| 10 | 方形可达尺度 | **24–92 px**; 小于衍射极限或大于 staircase Nyquist 都不可达 |

## 6. 已实施的修复 (含仿真先行测试)

`sltm_square_shaping.py` 三处修复, 全部有 2f-Fourier 仿真回归测试
(`tests/ao_shaping/optimizer/wfless/test_slm_square_energy_guard_sim.py`, 7 项):

1. **平场初始化** — `init_amplitude_rad` 默认 **0.0** (平场), 原
   `uniform(-π,π)` 改为可选的小幅随机。
2. **ROI 能量门 (显式跳过)** — `max_roi_energy_loss` 默认 **0.6**。
   与 `slm-pib` 不同, 这里**整轮 `continue` 跳过**而不只是给目标减 1e3:
   仅减哨兵值只能保护 best 轨迹, `diff = pos_q - neg_q` 仍会从被惩罚的一对
   构造出巨大的**真实**梯度, 系数照样走向空框。跳过时记录
   `gate="energy"`、`_diff=0`、`_grad=0`、系数不变。
3. **轮末重同步** — 每轮结束重新显示**已接受**的 `_params`, 面板不再停在被否决的
   −δ 扰动上。

> **能量门观测量的重要性质**: `square_encircled_energy` 分母是全图, 因此
> **整体变暗对它完全不可见**; 只有"光被散出框"才会体现。测试用"把光斑移出框"
> 而非"整体变暗"来复现硬件失效模式 —— 后者会让门永远不触发。

验证: 7 项新测试通过; 136 项既有 square/runner 测试无回归; lsp 无诊断。
