# 各阶段报告与图片规范

每个实验阶段都要产出一份自成体系的报告，保证方法可复现、证据分层、历史不被误当作当前事实。报告内容与图片参考 `report/shape_trials/model_in_loop/model_in_loop_live_20261014.md`；该报告是具体实验的事实来源，本文件是通用骨架，不绑定某一次具体实验。

## 为什么每阶段都写报告

规划、实验中、实验后是三个证据层级不同的阶段。只写最终总结会丢失"当时为什么这么定"的判断链，也容易把历史会话的设备 / 几何 / 曝光当成新实验默认。每阶段一份报告，把**当前可信事实**显式钉死，后续阶段和历史读者都能据此复核。

## 通用报告骨架（三阶段共用）

1. **溯源块（必需）**：按本仓库报告溯源要求登记 `provenance:start/end` 块，含生成方式（人工 / 脚本）、数据或关联脚本相对仓库根路径、运行环境（仿真或硬件）、设备身份与状态、关键说明。
2. **阶段目标与待验假设**：这一份报告要回答什么，拒绝什么。
3. **当前可信事实（会话专属，必需）**：设备型号与在线状态、SLM 波长与 LUT、CCD 像元尺寸与格式、光路是否离焦、几何与入射来源、曝光范围与实际读回满量程、已获授权与时长。**逐项标注是本次实测、沿用历史还是待定；历史数值不得作为默认标定。**
4. **数据 / 过程**：表格 + 图片；保留原始索引、标签、曝光与时间顺序。
5. **关键判断与证据**：按诊断表 / 三层证据给出，区分"已实测 / 推断 / 未验证"。
6. **结论、未决问题与下一步最有区分力的实验**。
7. **设备释放状态**（实验中与实验后必填）：是否释放、释放结果、避免下一位操作者误判占用。

## 三阶段的报告差异

### 规划报告（规划阶段产出，实验前）

- 实验目的与可测目标：形状、原生 CCD 尺寸、核心掩膜、零级处理、优化优先级、参考（真值）相位、曝光比较方式、可用时间。
- 最小实验矩阵与对照条件（口径对照与矩阵见 [规划指南](planning.md)）。
- 通过 / 拒绝标准；数据采集目录组织与命名；设备释放预案。
- 不含任何实测结论，只声明假设与计划。

### 实验中记录（实验中阶段产出，可随会话追加）

- 光路与预检：入射 / 面板扫描图、几何与入射来源、曝光上限来源与实测值。
- 闭环结果表：每轮运行目录、条件、预测相关性、实测 CV/EE、分数、接受模式。
- 相位与远场图、X/Y 强度剖面、指标表（见下方图片规范）。
- 漂移与决策：参考重拍、稳定判据、接受 / 拒绝轨迹、失败组保留。
- 设备释放状态。

### 分析报告（实验后阶段产出）

- 三层证据：数值实现 / 当前相位族预测 / 实际整形，分层不互相替代。
- 模型验证、CCD 验收、重拟合与重放分析、对比择优表（同曝光配对，不跨曝光平均后宣称相位效应）。
- 失败假设及其证据；训练 / 选择 / 独立测试分别用了哪些数据。
- 交接：当前检查点、参考相位、已测几何、曝光响应、未验证参数与一条可执行命令。

## 必需图片与渲染规范（参考 20261014）

| 图片 | 用途 | 渲染约定 |
|---|---|---|
| 入射 / 面板扫描图 | 预检定位入射区域与高响应区 | 原始强度或差异图，标注扫描坐标与最佳响应位置 |
| SLM 相位图 | 展示每轮最佳相位 | 相位包装到 [0, 2π)，`twilight` 色图 |
| CCD 远场图 | 展示实际成形 | `inferno` 色图；目标区用青色虚线框 / 轮廓叠加 |
| X/Y 光强剖面 | 判断均匀度与质心 | 过光斑质心（扣除背景后的质心，非图幅中心）的行 / 列剖面 |
| 目标轮廓对照图 | 直观判断形状是否覆盖目标 | 远场 + 理想目标边界（青色虚线）合成图 |
| 指标表 | 量化对比 | CV（固定目标核心）、EE_ROI、均值 / 能量、相对 L2 / 相关性，按相位族与曝光分别报告 |

**严格口径警告（必须写进报告，避免误读）：**

- colormap 渲染图 ≠ 原始强度数组；渲染图近似的 EE / 均匀度**不可**与 runner 在原始 CCD 数据上计算的 CV/EE 直接比较，仅供可视化。
- 5 帧均值的 CV 与逐帧 CV 不是同一数值，明确统计口径。
- 固定标度下比较预测和 CCD，不能逐图 min-max 归一化后再宣布强度一致。
- CV 低但核心均值接近背景是失败信号；纯 CV 目标可能把能量移出目标区，须同时记录 EE 与平均信号。
- 满量程来自像素格式有效位数，不是 NumPy 容器位宽；Mono12 的 uint16 可能右对齐，本次须先验证当前设备格式。

## 图片来源与一致性

- 静态图与 GIF 消费同一份源记录索引；每帧标阶段、标签、曝光和指标。
- 重新渲染只写派生资产，不覆盖原始帧，不默默重选最佳相位。
- GIF 只显示真实采集步骤，优化时段与后续重放明确分段。
- 模型迭代之间没有 CCD 数据时不能插值伪造测量过程。

## 溯源登记

- 每篇报告含 `provenance:start/end` 块；数据、脚本路径相对仓库根，不写绝对路径。
- 引用的历史报告（如 `report/shape_trials/...`）仅作经验来源，其中数值不继承为本次默认。
