# 规划：先定义可验证的问题

## 输出一页实验方案

记录当前设备身份、SLM 波长/LUT、CCD 像元尺寸与实际格式、当前光路是否离焦、透镜已知信息、设备可用时长和已获授权。沿用仍有效的会话信息，不反复询问已明确的条件；缺少会影响实验的事实时先做只读检查。

明确以下口径：

| 项目 | 必须讲清的区别 |
|---|---|
| 目标尺寸 | 原生 CCD px、SLM px、控制网格点数不是同一单位 |
| 均匀度 | 固定目标核心 CV 与整幅拟合窗口 CV 分开 |
| 零级 | 固定识别区剔除只改变指标；离轴载波不等于零级被物理消除 |
| 效率 | EE_ROI 的分子与分母、裁剪范围、饱和处理固定 |
| 初始化 | 平面、随机、几何能量映射、GS、历史相位或预训练先验分别记录 |
| 验收 | 模型选择、CCD 候选验收、最终重放是不同证据 |

目标越大，越要先检查视场和控制带宽。把实际载波二维映射用于目标落点，不能假设 SLM x 对应 CCD x。改变输入网格、FFT 或像素积分时保持物理辐照度标度和相机坐标不变。

## 选最少、能被数据识别的参数

先拟合共享几何、入射高斯振幅中心/宽度、有效二次相位与少量 Zernike；再按残差增加 PSF、曝光偏置或口径模型。保留旧参数作为对照，不同时放开大量互相可替代的参数。

物理预测模型减少深度网络参数量的价值，是将可解释传播留在模型中，让数据只适配低维误差。它不是“无训练成本”或“任意光路已被覆盖”的保证。U-Net 等深度模型与物理预测模型应使用同帧、同曝光、同相位族、同预处理比较。

仿真预训练随机化入射位置、宽度、像差、离焦、响应及几何，范围依据预期光路变化。按光路组合做分组验证；用未参与拟合的相位族检验泛化。匹配仿真中的高指标只证明分布内效果，迁移仍要当前 CCD 数据。冷启动必须审计实际相位来源，`initial_phase=gs` 的元数据不一定代表实际调用过 GS，也不能只凭一个字段宣称无历史先验。

## 最小实验矩阵

采用能区分假设的子集，不机械执行所有行：

| 假设 | 有区分力的数据 | 对照条件 |
|---|---|---|
| 几何/尺度错误 | 两轴正负载波、多个周期 | 固定光路，CCD 原生坐标 |
| 入射偏移/像差变化 | 当前参考、低阶模式、多个新随机探针 | 同一模型共享参数 |
| 曝光偏置 | 固定相位多档曝光，再换至少一种相位 | 固定功率与光路，记录读回值 |
| 模型梯度不可靠 | 当前相位附近多个正负方向 | 同曝光，方向幅度扫描 |
| 局部最优 | 严格与有边界探索同初相位同预算 | 保存历史最佳，最终交错重放 |
| 距离/有限口径 | 新几何、二次相位、位移与功率变化 | 有依据的焦距、口径或距离信息 |

历史 0.4/0.6 ms、50/100 ms、2.2 µm、Mono12、1064 nm 均为特定实验事实。新设备读实际范围和格式；环境上限为 0 或缺省的含义以项目当前实现为准，不能擅自永久固定到历史值。

## 本仓库入口

在仓库根执行对应模块的 `--help` 确认现有选项，再构建命令。优先复用：

- `ao_shaping.tools.slm.transfer`：统一编排与会话 journal。
- `transfer.capture` / `transfer.bootstrap` / `transfer.fit`：采集、标称初始化、少参数迁移。
- `transfer.pretrain`：仿真先验；具体输出类型先检查当前实现。
- `transfer.validate`：冷启动/历史相位、可微优化与可选 CCD 验收。
- `transfer.progress`：已有训练/验证轨迹和检查点选择。

完整操作文档是仓库 `docs/slm/slm_transfer_workflow.md`。本 skill 保存在 `libs/skills/slm-mil-transfer/`，脚本默认只读离线数据；设备动作仍由操作者或获得授权的代理执行。

## 本阶段产出：规划报告

规划阶段结束时产出一份**规划报告**（格式见 [各阶段报告与图片规范](reporting.md)）。它只声明假设与计划，不含实测结论，至少覆盖：

- 实验目的与可测目标：形状、原生 CCD 尺寸、核心掩膜、零级处理、优化优先级、参考（真值）相位、曝光比较方式、可用时间。
- 当前可信事实小节：设备身份、波长、CCD 像元与格式、光路离焦状态、几何来源、曝光范围与满量程、授权与时长；逐项标注实测 / 沿用历史 / 待定。
- 最小实验矩阵与对照条件、通过 / 拒绝标准、采集目录组织、设备释放预案。

历史 0.4/0.6 ms、50/100 ms、2.2 µm、Mono12、1064 nm 等均为**特定实验事实**，写入本报告当前可信事实小节时须以本次实测为准，不沿用为默认。
