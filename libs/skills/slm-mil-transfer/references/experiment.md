# 实验中：把设备时间用于减少不确定性

## 开始与持续确认

根据当前授权使用设备，设备被其他进程占用时不要终止未知进程或强制夺取控制权。设备间歇可用时按短会话获取完整数据块；两次会话之间记录光路/功率变化。一个设备对象只在对应会话内使用，由上下文管理释放。

先加载可追溯参考相位，以当前设备允许的低曝光读取真实帧，查看信号、饱和、坏帧和稳定时间。不要只看 GUI 自动拉伸的显示。曝光上限来源应记录为设备范围、环境设置或本次操作者约束；历史安全档位不是永久上限。

## 把参考插入高价值位置

新光路先测两轴正负载波，验证目标落点和二维尺度，再定位 SLM 入射区域。离焦可用已有离焦扫描找到更可靠的中心；偏心入射不能默认照明位于 SLM 中心。需要估计彗差时，用上下/左右不对称作为线索，随后以模式扫描或正负探针确认，不能仅凭单张强度图唯一反演像差。

在探针序列前后、参数改变后、疑似漂移时重拍完全相同参考。比较同相位的 CV、核心均值、质心与宽度；功率变化不能只靠 CV 检查。出现明显变化时，标记当前段落，先重测参考/几何，避免继续训练吸收整个变化。稳定判据按当前噪声与目标决定，不固化某次实验的百分比。

先取得跨相位族的探针，再把设备交给离线拟合。若设备还可用，优先补充缺少的曝光档、边界相位和未参与拟合的新扰动方向，而不是等待训练日志。仿真/训练可并行，但同一 SLM/CCD 只能有一个明确的控制者。

## 曝光与响应

允许块间自动调整曝光，参考/候选块内保持同曝光；等待曝光切换与 SLM 相位加载稳定，必要时丢弃过渡帧，但保留丢弃原因与诊断数据。每帧记录实际读回曝光，不能只记设定值。

满量程来自像素格式有效位数，不是 NumPy 容器位宽。Mono12 的 uint16 可能右对齐或采用其他编码，先验证；历史 Daheng 数据为右对齐 4095。格式转换不能冒充响应线性化。

固定功率、固定相位多曝光，区分 counts 形式 `g*t*I + b*t + c` 和 counts/ms 形式 `g*I + b + c/t`。将曝光作为模型协变量。多曝光不足时不能唯一分离 b 与 c。不能遮光时可拟合有光条件的有效偏置，但不得命名为已测暗场；高衰减滤光片不消除电子偏置。

CV 很低但核心均值接近背景，是失败信号。纯 CV 目标可将能量移出目标区；记录 EE 和平均信号作为解释依据，即使用户本轮只优化均匀度。剔除饱和零级可以评估核心 CV，但饱和全帧不适合精确效率比较。

## 在线拟合与短块优化

少量探针先更新入射位置、宽度、光轴与有效曲率，必要时再增加残余像差。用训练相位拟合参数，验证相位判断泛化；若验证集参与检查点选择，后面另采最终测试相位。

先在仿真用多个方向和步长做有限差分，再在 CCD 测 `φ+εδ`、`φ−εδ`。前者检验内部导数，后者检验物理局部响应。预测方向错误时优先检查单位、载波、相位重复叠加、局部 Jacobian 和模型误差，不持续放大更新。

冻结物理参数后，用当前 CCD 图像锚定代理 `I_CCD(φ₀)+F(φ)−F(φ₀)` 做短块优化；锚定项修正当前强度，不自动修正模型 Jacobian。按照明加权 RMS 限制相位步长，每块重测参考与候选。验收模式必须记录：

| 模式 | 含义 |
|---|---|
| model_only | 只有模型决定，不能称为 CCD 验收 |
| sequential_ccd | 同曝光顺序 A/B，不能抵消慢漂移 |
| A–B–B–A | 同曝光配对，适用于漂移需要抵消时；预算更高 |
| nonmonotone_ccd | 显式概率探索，另保留历史最佳相位 |

A–B–B–A 在本项目当前默认为关闭；需要时启用。不要为获得更好数字而默默更换验收模式。连续拒绝后检查步长、方向和漂移，再决定缩步、补探针或尝试探索。允许暂时恶化不意味着允许覆盖最佳相位；比较策略用相同起点与预算，最好交错重放、多种随机种子。不要把一次改善称为已经证明逃离局部极小值。

## 结束前最后的设备时间

精确重放初相位、最终相位、历史最佳候选；用相同曝光和固定掩膜对照，允许时增加另一未饱和曝光。对漂移敏感时交错顺序或重复参考。加载已保存的总相位，防止再次叠加静态校正或载波。

立即保存原始帧、完整相位/灰度、曝光、接受决策、每迭代 UTC 与单调时钟起止；相机可提供硬件时间戳时另存，不将主机微秒格式当成触发同步精度。失败组也保留。按已约定的结束相位释放设备，记录释放结果；之后离线生成图表，不为重画 GIF 再占用设备。

## 本阶段产出：实验中记录

实验中阶段产出**实验中记录**（可随会话追加；格式见 [各阶段报告与图片规范](reporting.md)）。除闭环结果表外，必须包含以下图片与口径：

- 入射 / 面板扫描图（预检定位入射区域与高响应区）。
- 每轮 SLM 相位图（包装到 [0, 2π)，`twilight` 色图）与 CCD 远场图（`inferno` 色图，目标区青色虚线框）。
- X/Y 光强剖面：过扣除背景后质心的行 / 列剖面，非图幅中心。
- 指标表：CV（固定目标核心）、EE_ROI、均值 / 能量、相关性，按相位族与曝光分别报告。

严格口径必须写进报告：colormap 渲染图 ≠ 原始强度数组，其近似 EE/均匀度不可与 runner 原始 CCD 计算的 CV/EE 直接比较；5 帧均值 CV 与逐帧 CV 不是同一数值；满量程来自像素格式有效位数，本次须先验证当前设备格式（历史 Daheng 数据为右对齐 4095，但不能默认套用）。
